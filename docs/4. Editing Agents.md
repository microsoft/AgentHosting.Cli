# Editing your Agent

Once an agent has been created, you can work with the agent definition. You can do this in a number of ways:

## VS Code Extension

If you are working with an existing agent definition from clone or remote initialization from a remote repo, VS code is a great way to work with your agent in an IDE your familiar with, and includes VS Code native capabilities to work with the agent alongside the CLI

Documentation can be found here on installing the VS Code extension

## Terminal

You can use the terminal and other methods with AI Agents such as GitHub copilot to create the files based from the CLI help menus, the documentation available and public skills that Microsoft have published here to work with the msagent cli. Learn more here

Check out the 4.1 documentation for using the msagent CLI with Github Coding Agents

## Manually

Developers and advanced makers familiar in YAML and JSON can author their own declarative agent, although it would require familiarity with YAML object model for copilot studio and in some cases, JSON.
