# 11051: Connector does not contain the selected connection

[All error codes](../ErrorCodes.md)

## What happened

The connector selected for removal does not serve the requested connection in the target environment.

## Why this happens

The connector, connection ID, or environment may be incorrect, or the connection may already be absent. The check prevents constructing a deletion against the wrong connector.

## How to fix it

Run the connection-list command printed in the remediation and verify which connector holds the intended connection. Correct the connector or connection selection before retrying removal.

If this occurred while planning removal of a reference and its connection, inspect the current reference state as well. Do not assume a deletion occurred simply because the command was started.

Do not delete a different connection just to make the request succeed.

## How to avoid it

Keep connector IDs together with their connection IDs and environment. Use current listings rather than identifiers copied from unrelated deployments.
