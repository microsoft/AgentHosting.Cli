# 14047: Channel configuration is unavailable

[All error codes](../ErrorCodes.md)

## What happened

Azure Bot Service returned channel configuration that the CLI could not safely use for an update.

## Why this happens

An existing collection or item selector is missing, malformed, or ambiguous.

## How to fix it

Inspect the channel with `msagent deployment channel show` or Azure portal. Correct the configuration
before retrying. If the response remains unusable, report the issue without including credentials.
