# 14045: Required parameter cannot be cleared

[All error codes](../ErrorCodes.md)

## What happened

An OAuth or channel update explicitly supplied an empty value for a required parameter.

## Why this happens

Update distinguishes omission from clearing. Omitting a required field can preserve its existing value, while supplying an empty value requests removal and is rejected. This includes an empty `Key=` assignment and empty dedicated OAuth options where the provider requires a value.

## How to fix it

If you meant to leave the setting unchanged, remove that assignment or option from the command. If you meant to replace it, supply a valid non-empty value.

Consult `msagent deployment oauth list-providers --provider-name <provider-name>` for OAuth requirements, or the selected channel's update help. Optional values may support explicit clearing, but that does not make required values removable.

Do not replace a required secret with a displayed mask or a dummy string.

## How to avoid it

Have scripts omit unchanged fields rather than converting absent input into empty assignments.
