# 11067: Another copy into the project is running

[All error codes](../ErrorCodes.md)

## What happened

Another `msagent agent copy` into the same project was running, so this copy stopped. It wrote nothing and sent nothing.

## Why this happens

Only one copy into a project runs at a time. Each copy holds the project's copy lock while it clears what earlier interrupted copies left under `.config\copy`, prepares the new workspace, and registers the new agent.

## How to fix it

- Wait for the other copy to finish, then run this command again. Retrying is safe.
- The lock is released when the other copy ends, even if it was stopped. The `copy.lock` file that stays in the project afterwards does not by itself mean that a copy is running.

## How to avoid it

Run copies into the same project one at a time, for example by running them in sequence in scripts.
