# 11054: Workflow belongs to a managed solution

[All error codes](../ErrorCodes.md)

## What happened

The selected workflow is part of a managed solution in its environment, so the CLI did not clone or
pull it.

## Why this happens

A managed flow changes only through the solution that installed it. Editing a local copy could never
be deployed back to that environment.

## How to fix it

Clone the workflow from the environment where its solution is unmanaged, or choose a workflow that
`msagent agent list --agent-type MCSWorkflow` shows.

## How to avoid it

Pick workflows from `msagent agent list --agent-type MCSWorkflow`, which lists only unmanaged cloud
flows.
