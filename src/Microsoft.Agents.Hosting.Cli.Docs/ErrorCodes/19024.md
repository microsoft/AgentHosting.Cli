# 19024: Playground endpoint discovery failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not discover the selected playground endpoint.

## Why this happens

Discovery failed without an existing specific CLI authentication or service error.

## How to fix it

Check the selected CLI account, delegated Copilot Studio permissions, published agent, and target selectors before retrying.

## How to avoid it

Verify publication and access for the explicitly selected target; do not guess another endpoint.
