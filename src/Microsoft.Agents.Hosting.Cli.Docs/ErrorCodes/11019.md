# 11019: Sharing needs an agent selection

[All error codes](../ErrorCodes.md)

## What happened

The sharing command has no `--agent-id` or `--agent-name` selection.

## Why this happens

Sharing commands require an explicit agent even when you are working inside a project. They do not infer the target solely from your directory.

## How to fix it

Supply `--agent-id` or `--agent-name` for the intended agent, along with the project selection needed to resolve its managed record.

Use `msagent agent list` to inspect agents, and `msagent agent show` to confirm the local record when needed. Verify that the ID used is appropriate for the command rather than assuming every agent identifier is interchangeable.

Review the target before granting or removing access.

## How to avoid it

Include an explicit, verified agent selector in every sharing script instead of relying on working-directory context.
