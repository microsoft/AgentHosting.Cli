# 19009: npm was not found

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not find npm when playground installation required it.

## Why this happens

npm is missing, unavailable at its detected path, or absent from PATH.

## How to fix it

Install Node.js with npm. Open a new terminal and verify `npm --version`, then retry installation.

## How to avoid it

Ensure npm is available before authorizing installation; a working installed playground does not require npm.
