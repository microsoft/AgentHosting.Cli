# 19009: You cannot write to the agent's repository

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused the change because your account can't write to the agent's GRS repository.

## Why this happens

Registering an agent in a repository, a capture, and a remote deploy to Dev that captures Dev's edits first write to the agent's repository, which needs write access to it. Your account has none, or it was removed.

## How to fix it

Ask the repository's owner to give your account write access in GRS, then run the command again.

## How to avoid it

Check repository access before you hand an agent to a new author.
