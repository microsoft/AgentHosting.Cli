# 19068: AMS already holds the deployment id with other details

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to create a deployment because it already holds a deployment with the same id and other details, such as another name, stage or environment.

## Why this happens

With AMS mode on, msagent creates each deployment in AMS under the id `.config` records for it. AMS answers a repeat of the same create as a success, but refuses one whose details differ.

## How to fix it

Check the deployment's record with `msagent deployment show`, then run the command again with the same inputs.

## How to avoid it

Don't copy `.config` between projects or edit deployment ids in it by hand.
