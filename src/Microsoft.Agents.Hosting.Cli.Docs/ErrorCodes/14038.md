# 14038: OAuth provider was not found

[All error codes](../ErrorCodes.md)

## What happened

The requested OAuth service provider could not be found in the live Azure Bot Service provider catalogue.

## Why this happens

Provider details come from Azure, not only from the connection name or locally known provider names. The requested name or ID may not be present in the target catalogue, or an existing connection may reference a provider the returned catalogue does not include.

## How to fix it

Inspect the live catalogue:

```text
msagent deployment oauth list-providers
msagent deployment oauth list-providers --provider-name <provider-name>
```

Use a provider supported by both the CLI and the target catalogue. Verify the subscription and tenant if the returned catalogue differs from your expectations.

If an existing connection references an unavailable provider, ask the service administrator to investigate the catalogue or connection state before changing credentials or recreating the connection.

## How to avoid it

Check live provider schemas before configuring OAuth. Do not assume provider availability or required parameters from another environment.
