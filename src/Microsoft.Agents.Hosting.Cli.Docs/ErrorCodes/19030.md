# 19030: The operation took too long

[All error codes](../ErrorCodes.md)

## What happened

`msagent` stopped waiting for an operation. The operation may still finish.

## Why this happens

`msagent` waits at most 45 minutes for an operation, and stops sooner when a running operation reports no progress for 10 minutes.

## How to fix it

Run the `msagent agent operation show` command the message prints. If the operation stays stuck, contact support with its operation ID.

## How to avoid it

Pass `--async` for long operations and check on them with `msagent agent operation show`.
