# 19017: The service could not act on your behalf

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service could not run the operation on your behalf.

## Why this happens

A register, remote deploys, captures and the records local deploys send run as you. That needs the Power Platform API gateway to hand the service a ticket for your sign-in. The request reached the service without that ticket, or exchanging it failed, for example because the sign-in expired or a Conditional Access policy blocked it.

The service also refuses a sign-in token that expires before the operation could finish: it allows an operation 20 minutes and keeps 5 minutes of margin. msagent therefore renews a token with less than 35 minutes left before it asks the service to act on your behalf, and when the service still finds the token too short, renews it once more and sends the same request again.

## How to fix it

When the message says your sign-in token expires too soon for the operation, msagent already renewed it and retried once: run `msagent auth login`, then retry.

Otherwise, run `msagent auth login`, then retry. If it persists, check that requests reach the service through the Power Platform API; in end-to-end test shells, point `MSAGENT_AMS_ONBEHALFOF_ENDPOINT` at a gateway host.

## How to avoid it

Keep the sign-in current before long sequences of deploys.
