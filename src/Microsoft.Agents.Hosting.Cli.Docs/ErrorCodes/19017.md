# 19017: Playground installation timed out

[All error codes](../ErrorCodes.md)

## What happened

Installation or its verification exceeded the allowed time.

## Why this happens

npm installation or a post-install playground check did not finish before its deadline.

## How to fix it

Check registry connectivity and npm's global bin directory. Inspect whether installation completed before retrying, then open a new terminal.

## How to avoid it

Keep registry access working and npm's global bin directory on PATH. A timeout does not prove nothing was installed.
