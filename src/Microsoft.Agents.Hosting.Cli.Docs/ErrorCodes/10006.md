# 10006: Agent schema name is unavailable

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not determine the Copilot Studio schema name needed to address the agent.

## Why this happens

The expected project identity could not be read at the searched location, and no usable identity was available for this operation. Running from the wrong directory or using an incomplete workspace can leave the CLI without the agent's schema name.

## How to fix it

Run the command from the agent's project directory, or correct its project path. Check the path shown in the error against the workspace you intended to use.

If the project files are missing, restore them from source control. A settings file that exists but cannot be read or names no `schemaName` is reported as [10022](10022.md) instead.

## How to avoid it

Keep the project identity file with the agent's content. Preserve schema names when copying or restoring a workspace.
