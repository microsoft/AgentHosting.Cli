# 12008: Token requests are being throttled

[All error codes](../ErrorCodes.md)

## What happened

Microsoft Entra ID is limiting token requests from the CLI.

## Why this happens

Too many authentication attempts occurred in a short period. Repeated immediate retries can prolong the throttling period rather than recover the session.

## How to fix it

Wait for the retry interval printed with the error, if one is supplied. Otherwise pause before making another attempt. Stop parallel scripts or automatic retry loops that are repeatedly requesting tokens.

After the pause, retry one operation and check whether authentication succeeds. Signing out and repeatedly signing in is not a useful response to a rate limit. If throttling persists with low request volume, report the time and any correlation details without including tokens.

## How to avoid it

Reuse the CLI's supported cached authentication and space out retries. Coordinate concurrent automation instead of launching many sign-in operations at once.
