# 14010: Draft deployed but publishing failed

[All error codes](../ErrorCodes.md)

## What happened

The MCS deployment pushed content and recorded the deployment, but the requested publish did not complete successfully. The pushed draft remains saved.

## Why this happens

With `msagent agent deploy --publish`, publishing is a separate step after the push and local record updates. A validation, access, service, or connectivity failure at that step is reported without undoing the deployment. A publish request may also have reached the service before a response was lost.

## How to fix it

Read the publish failure and inspect the named agent in the reported environment. Correct any publish validation or access problem. If the outcome is uncertain, check the agent's published state first.

Repeat the same deploy command with `--publish`, or publish the saved draft from the Copilot Studio portal. There is no need to create another deployment or rebuild the agent merely because publication failed.

## How to avoid it

Resolve draft validation issues and verify publishing permissions before promoting changes live.
