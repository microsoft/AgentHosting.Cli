# 13013: Live-test configuration does not identify a valid target

[All error codes](../ErrorCodes.md)

## What happened

The local managed-agent and deployment configuration cannot resolve one consistent live-test destination.

## Why this happens

Records may be missing, duplicated, inconsistent, disabled, or quarantined. Selectors may disagree with records. A live test requires an explicit deployment or exactly one configured default; a sole non-default deployment is not automatically used.

## How to fix it

Run `msagent agent list` and `msagent deployment list` in the intended project. Select the correct agent and deployment using their IDs. Follow the detailed error to correct mismatched schema, environment, tenant, ownership, or duplicate records in the public `agent.config.json` configuration.

Use an enabled, non-quarantined destination. Do not remove quarantine simply to bypass a governance decision. The test uses the deployment's destination, not the agent's home environment.

## How to avoid it

Maintain consistent project records and one intended default per agent. Verify deployment context before running live tests.
