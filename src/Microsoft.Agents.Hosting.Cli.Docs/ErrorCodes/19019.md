# 19019: Playground post-install verification failed

[All error codes](../ErrorCodes.md)

## What happened

Installation did not produce a usable, supported playground tool.

## Why this happens

The tool is absent from PATH, below the minimum, or cannot pass post-install verification.

## How to fix it

Check npm's global bin directory and `agentsplayground --version`. Ensure version 0.2.29 or newer, open a new terminal, and retry.

## How to avoid it

Keep npm's global bin directory on PATH and verify the installed tool after package changes.
