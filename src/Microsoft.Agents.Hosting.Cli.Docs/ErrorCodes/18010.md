# 18010: The evaluation test set is empty

[All error codes](../ErrorCodes.md)

## What happened

The selected test set contains no conversations, so the CLI cannot start an evaluation from it.

## Why this happens

The set may have been created without a successful content write, emptied by another operation, or left incomplete after a failed update.

## How to fix it

Inspect it with `msagent agent eval testset show --testset <name-or-id>`. Add the intended conversations, for example:

`msagent agent eval testset update --testset <name-or-id> --from-csv <file.csv>`

Include the same agent and environment selectors used originally. Read the set again to confirm the expected conversations are stored before starting a charged evaluation.

If a previous update failed, resolve that failure rather than assuming repeating the run will fill the set.

## How to avoid it

Verify stored content after creation or replacement. Treat creating a test-set record and successfully storing its conversations as separate outcomes.
