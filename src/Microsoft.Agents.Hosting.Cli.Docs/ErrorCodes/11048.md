# 11048: AMS rejected the agent creation request

[All error codes](../ErrorCodes.md)

## What happened

AMS returned a recognized create-operation rejection. The message and remediation identify which recovery path applies.

## Why this happens

Causes include invalid create options, missing user identity, tenant or environment mismatch, idempotency-key conflicts, a creation already in progress, concurrent durable writes, or repository-binding failure.

## How to fix it

- For identity or environment errors, follow the reported sign-in or environment-selection guidance.
- For invalid fields, correct the named creation options.
- For an in-progress operation or concurrency conflict, wait briefly and retry the identical request with the same `--idempotency-key`.
- For a key conflict, reuse that key only for its original request; a genuinely distinct agent needs a different key.
- For repository-binding failure, do not retry blindly. Preserve the key and correlation IDs and have the recorded service state inspected.

## How to avoid it

Keep each key associated with one exact request. Retain its options and correlation information until creation is settled.
