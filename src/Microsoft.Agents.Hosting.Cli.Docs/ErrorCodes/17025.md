# 17025: The cloud agent changed while the push was prepared

[All error codes](../ErrorCodes.md)

## What happened

The component service rejected the push because the cloud agent changed after the workspace's synchronization baseline was obtained.

## Why this happens

Another author or process updated the agent during preparation. With overwrite enabled, the CLI can refresh the baseline and retry once; this error can still occur if cloud changes continue.

## How to fix it

Preserve local work, coordinate with other writers, then run `msagent agent pull`. Review the resulting content and any conflict diagnostics before deploying again.

Use the deployment command's `--overwrite` only when replacing cloud content is intentional. This is not general conflict protection: knowledge, prompts, connectors, and workflows can be overwritten by design, and some auxiliary changes may already have occurred before this component rejection.

## How to avoid it

Avoid concurrent deployments and cloud edits. Pull near the start of an editing session and keep recoverable copies before intentional overwrites.
