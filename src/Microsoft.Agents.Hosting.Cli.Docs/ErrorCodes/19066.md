# 19066: AMS already holds the agent id with other details

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to register the agent because it already holds an agent with the same id and other details, or held one that was deleted.

## Why this happens

msagent registers each agent under the id `.config` records for it. AMS answers a repeat of the same registration as a success, but refuses one whose details differ, and never takes the id of a deleted agent again. The record in `.config` may have been copied from another project, or edited.

## How to fix it

Check the agent's record with `msagent agent show`, then run the command again with the same inputs. A record copied from another project, or of an agent that was deleted, can't be registered under its id: create the agent again in this project with `msagent agent create`, which gives it a new id.

## How to avoid it

Don't copy `.config` between projects or edit agent ids in it by hand.
