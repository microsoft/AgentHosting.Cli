# 12013: The token targets a different resource

[All error codes](../ErrorCodes.md)

## What happened

The token's audience does not match the Power Platform API audience required for the selected environment.

## Why this happens

Environment or cloud targeting is stale or inconsistent, or authentication acquired a token for a different resource. The CLI rejects the mismatch rather than continuing with the wrong token.

## How to fix it

Check the intended account and cloud with `msagent auth status`. Run `msagent env list`, then `msagent env select <environment-id>` to refresh the intended environment and its audience.

Retry the command after confirming the selection. If it still fails, report the expected and reported resource identities and CLI version, not the access token. Repeated sign-in alone may not correct the target configuration.

## How to avoid it

Reselect the correct environment after account or cloud changes. Keep authentication and environment context aligned instead of reusing copied configuration from another destination.
