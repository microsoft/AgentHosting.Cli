# 10007: Agent or deployment record changed concurrently

[All error codes](../ErrorCodes.md)

## What happened

The record changed after the command read it but before the command could save its update.

## Why this happens

Another command or process updated the same agent or deployment record. The CLI rejects the stale write instead of overwriting the newer state.

## How to fix it

Wait for other commands using this project to finish, review the current agent or deployment state, and rerun the command.

If the command also performed a cloud operation, review any preceding output before retrying. This error describes the local record conflict; it does not promise that earlier remote work was rolled back. Preserve IDs or other recovery guidance reported by the original operation.

## How to avoid it

Serialize commands that modify the same project configuration. Avoid running overlapping deployment, registration, or deletion jobs against one working copy.
