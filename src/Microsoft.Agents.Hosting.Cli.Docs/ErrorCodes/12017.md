# 12017: The token has the wrong principal mode

[All error codes](../ErrorCodes.md)

## What happened

The PPAPI token's delegated-user/application mode differs from the captured authentication profile.
The token is rejected before use. This is exit 2, with error kind `principal-mode-mismatch`.

Missing captured context, inconsistent context bindings, or missing token-provider
wiring are internal failures reported as [99005](99005.md), not this claim error.

## Why this happens

Required principal markers or delegated permissions contradict the profile's intended mode.
An application token cannot be treated as a delegated user token, or vice versa.

## How to fix it

Inspect `msagent auth who` and the intended credential configuration. Restore the same profile's
correct tenant/application or user method; explicitly create the intended profile when a different
mode is required. Do not silently switch sources or import another tool's token to bypass the check.

## How to avoid it

Keep workload and user registrations, permissions and profiles distinct. Validate the exact intended
principal and target before mutations; never share tokens or token fragments in reports.
