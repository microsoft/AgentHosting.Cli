# 12017: git was not found

[All error codes](../ErrorCodes.md)

## What happened

`msagent auth setup-git` found no git on PATH, so it configured nothing.

## Why this happens

The command writes msagent's credential helper into your global git config by running git, so git must be installed and on PATH. A terminal opened before git was installed still has the old PATH.

## How to fix it

Install git from https://git-scm.com/downloads, open a new terminal, then run `msagent auth setup-git` again.

## How to avoid it

Install git before you set it up to sign in with msagent, and check that `git --version` works in the terminal you use.
