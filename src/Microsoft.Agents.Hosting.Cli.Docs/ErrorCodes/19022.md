# 19022: Playground child process exited unsuccessfully

[All error codes](../ErrorCodes.md)

## What happened

The playground process returned a nonzero exit status.

## Why this happens

The child failed independently of caller cancellation. Its raw process exit status is not this CLI registry code.

## How to fix it

Read the safe exit-status diagnostic and playground-window output. Resolve the child failure before retrying; verify any remote effects separately.

## How to avoid it

Confirm the playground is ready and connected rather than treating process startup as success.
