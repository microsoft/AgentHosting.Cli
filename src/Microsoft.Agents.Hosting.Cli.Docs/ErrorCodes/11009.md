# 11009: Workflow metadata cannot be read

[All error codes](../ErrorCodes.md)

## What happened

The CLI found the workflow's metadata file but could not interpret it. The error names the file and explains the read problem.

## Why this happens

`metadata.yml` may be malformed, incomplete, or contain unresolved merge conflicts. Restoring only part of a workflow can also leave metadata inconsistent with its definition.

## How to fix it

Restore the metadata from a known-good version in source control, or pull the workflow again using the intended workflow and environment.

Before pulling, preserve unpublished local changes. If repairing the file, follow the specific diagnostic and retain the workflow's original identity; do not substitute metadata from another workflow.

Retry the original operation once the workflow files are consistent.

## How to avoid it

Keep metadata and `workflow.json` versioned together. Resolve YAML merge conflicts completely before registering, deploying, or pulling a workflow.
