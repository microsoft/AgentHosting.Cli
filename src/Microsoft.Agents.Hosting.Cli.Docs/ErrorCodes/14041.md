# 14041: Channel operation is not supported

[All error codes](../ErrorCodes.md)

## What happened

The selected channel exists in the CLI catalogue, but the requested operation is not supported. The validation failure occurs before an Azure write.

## Why this happens

The CLI does not allow deleting automatically created Direct Line or Web Chat channels. It also refuses channel updates when the selected definition exposes no parameters, as with `m365extensions`. Retrying the same operation or changing permissions does not remove these restrictions.

## How to fix it

Read the channel and operation named in the message. For a no-parameter channel, use supported create, show, or list operations rather than trying to update nonexistent settings.

If your goal is to disable access rather than remove an automatically created channel, inspect that channel's update help and supported `isEnabled` setting. Confirm the impact on clients before changing it. Direct Line and Web Chat updates write a single-site configuration, so inspect existing sites first.

Do not delete the bot as a workaround.

## How to avoid it

Check the selected channel's supported operations and parameter schema before scripting channel lifecycle changes.
