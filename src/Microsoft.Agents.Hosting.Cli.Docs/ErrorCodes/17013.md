# 17013: The cloud agent exists but the workspace link failed

[All error codes](../ErrorCodes.md)

## What happened

The cloud agent exists, but the local workspace could not be linked to it. The agent was not removed.

## Why this happens

Creation or adoption reached the cloud agent, then workspace attachment failed. The message supplies the agent ID, schema name, and underlying reason when available.

## How to fix it

Record the agent ID and inspect it with `msagent agent list` in the target environment. Preserve the current project files. Use `msagent agent pull --agent-id <agent-id>` into an empty working directory to recover a usable local copy.

Do not rerun creation assuming it failed completely. If you decide the agent is unwanted, inspect it and its dependencies before using the supported delete command with the exact ID.

## How to avoid it

Use a writable workspace and resolve attachment prerequisites before creation. Retain agent IDs from command output so partially completed setup can be recovered without duplicate agents.
