# 11002: Agent ID conflicts with this project

[All error codes](../ErrorCodes.md)

## What happened

Your `--agent-id` does not match the single managed agent registered in this project. The command made no changes.

## Why this happens

An ID from another project or a different kind of identifier was supplied. A managed-agent record ID should not be assumed to be interchangeable with a cloud agent ID.

## How to fix it

Compare the supplied ID with the project's name and ID printed in the error.

- Omit `--agent-id` to use this project's own agent, if that is the intended target.
- Otherwise, run the command against the project that actually holds the selected agent.

Use `msagent agent show` to review the local records before retrying. Do not change the configuration's identity to force the supplied ID to match.

## How to avoid it

Keep project paths and record IDs paired in scripts. Verify selectors before write or delete operations.
