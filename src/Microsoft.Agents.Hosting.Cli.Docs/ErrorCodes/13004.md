# 13004: The environment was not found

[All error codes](../ErrorCodes.md)

## What happened

The requested environment ID is absent from the inventory visible to the active account.

## Why this happens

The ID may be incorrect, the account or cloud may be wrong, the environment may have been removed, or you may lack access. A missing inventory entry does not by itself prove the environment was deleted.

## How to fix it

Run `msagent auth status` and `msagent env list`. Compare the requested ID with the listed environments. Correct the ID or sign in to the account and tenant authorized for the intended destination.

If an administrator confirms the environment exists but it is still absent, ask them to verify your access and the environment's availability.

## How to avoid it

Use environment IDs from current inventory, not display names or IDs copied from another tenant. Recheck access when accounts, tenants, or environments change.
