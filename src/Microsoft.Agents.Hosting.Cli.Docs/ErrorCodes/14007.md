# 14007: Previously deployed target agent is missing

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not find the expected Copilot Studio agent by schema name in a deployment's target environment, although the record shows a previous deployment.

## Why this happens

Connection operations resolve the target agent from the workspace schema, or your supplied schema override. The cloud agent may have been deleted, or the selected deployment or schema may no longer identify the intended agent. A recorded deployment timestamp does not guarantee the remote agent still exists.

## How to fix it

Compare the reported environment and schema with the agent in Copilot Studio. Check `msagent deployment list` and any `--schema-name` override before creating anything.

If the cloud agent really was removed, decide whether to restore it from the intended project or start again with `msagent agent create` or `msagent agent init`, as appropriate to your source. Preserve the workspace and verify ownership before replacing content.

## How to avoid it

Coordinate cloud deletions and schema changes with the project's deployment records.
