# 14013: No selectable deployment records

[All error codes](../ErrorCodes.md)

## What happened

The MCS deployment route could not select a destination because the project has no selectable MCS deployment records.

## Why this happens

An agent record is not itself a deployment destination. The deploy command does not fall back to the active environment. A folder containing only CodeAgent records also does not provide an MCS deployment target.

## How to fix it

Check the project and agent shown in the error, then run `msagent deployment list`. For an MCS agent, create a destination record and deploy to it:

```text
msagent deployment create --deployment-type dev --deployment-name "Development"
msagent agent deploy --deployment-name "Development"
```

Add the relevant project and agent selectors if the folder registers several agents. Creating the record alone changes no cloud content.

For a CodeAgent, use the package-revision route described in `msagent agent deploy --help`. Those AMS options require `AmsFeatures`; a local project alone cannot deploy a CodeAgent.

## How to avoid it

Create and explicitly select a deployment destination before an MCS push.
