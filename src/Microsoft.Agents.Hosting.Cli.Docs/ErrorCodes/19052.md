# 19052: The project folder is not its repository's root

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` or `msagent agent init` with AMS mode on was refused because the project folder is inside a git repository whose root is another folder. The message names that root. Nothing was changed.

## Why this happens

With AMS mode on, a project folder is the root of its git repository, and each agent is a top-level folder of both, so that the agents' folders in the project match their folders in the GRS repository AMS registers.

## How to fix it

Use the repository's root as the project folder, or a folder outside any git repository.

## How to avoid it

Keep each AMS project at the root of a repository of its own.
