# 11022: Sharing removal was not confirmed

[All error codes](../ErrorCodes.md)

## What happened

The service accepted the revoke request but reported a different sharing state, so removal of the requested access cannot be confirmed.

## Why this happens

Sharing is written as a whole state. Some requested changes may have landed while others did not, or the returned state may differ in another entry. Do not assume access was fully removed or that everything stayed unchanged.

## How to fix it

Run `msagent agent share show` for the same agent before making any further access changes. Compare the actual state with the differences named in the error.

If the user still has the unwanted direct share, correct that specific entry after reviewing current access. For urgent access concerns, verify the state in Copilot Studio with the responsible administrator.

## How to avoid it

Serialize access-management changes and verify revocations rather than relying solely on request acceptance.
