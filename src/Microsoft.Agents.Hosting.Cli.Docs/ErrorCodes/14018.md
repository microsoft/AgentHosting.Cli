# 14018: Package file is empty

[All error codes](../ErrorCodes.md)

## What happened

The file supplied for package upload contains zero bytes. The CLI rejected it before sending an upload request.

## Why this happens

The selected file may be an empty placeholder, the wrong output, or an archive whose producing process has not finished. A filename ending in `.zip` does not establish that the file contains a package.

## How to fix it

Finish or rerun the process that produces your package and select its non-empty output with `--package <file>`. Verify that you are using the intended path before repeating `msagent agent package upload`.

The upload command requires `AmsFeatures` and sends the selected bytes; it does not build a package for you. Deployment subsequently selects the returned Package Revision, not a local package path.

## How to avoid it

Do not start uploading until artifact production has completed successfully and the output has a nonzero size.
