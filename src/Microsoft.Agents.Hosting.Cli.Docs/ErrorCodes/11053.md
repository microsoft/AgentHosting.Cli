# 11053: Sharing recipient lookup failed

[All error codes](../ErrorCodes.md)

## What happened

Microsoft Graph could not resolve the supplied recipient address to a usable Entra user
identity. This is a failed lookup, not confirmation that the user does not exist.

## Why this happens

The directory request can fail because of permissions, throttling, service availability,
or connectivity. The response can also lack the valid object ID or sign-in address needed
to identify a user safely. The accompanying error message gives the reported cause.

## How to fix it

Read the directory error and correct the reported problem. For a permission denial, ask
an administrator to confirm the required directory permissions and consent. For
throttling or temporary service problems, wait before retrying.

Alternatively, supply the intended user's Entra object ID instead of their email address
to avoid address resolution. This does not bypass permissions required by the sharing
operation or guarantee that later directory requests will succeed.

## How to avoid it

Use verified Entra object IDs in automation where appropriate. Maintain the directory
permissions required by your workflow, avoid repeated requests during throttling, and
treat failed lookups separately from users that were successfully confirmed absent.
