# 18005: The evaluation run is still active

[All error codes](../ErrorCodes.md)

## What happened

The run cannot be deleted because it has not reached a terminal state.

## Why this happens

The evaluation service is still processing the run. Deletion is reserved for runs that have finished or otherwise reached a terminal outcome.

## How to fix it

Inspect it with `msagent agent eval show --run-id <run-id>`. If you want the evaluation to finish, wait and check again.

If you intend to stop it, run `msagent agent eval cancel --run-id <run-id>`, then verify its state before requesting deletion again. Preserve any results or diagnostics you need before deleting a finished run.

Do not submit another evaluation as a workaround for an active run you cannot yet delete.

## How to avoid it

Separate cancellation from cleanup in scripts. Confirm a terminal state before deletion rather than assuming a client timeout or closed terminal stopped service-side work.
