# 14008: Agent has not been deployed

[All error codes](../ErrorCodes.md)

## What happened

The operation needs a remote Copilot Studio agent, but the selected agent or deployment does not yet provide one.

## Why this happens

Registering a local agent or creating an MCS deployment record does not create cloud content. Connection resolution also uses this error when the target schema cannot be found and the deployment has no recorded deployment time. Sharing can fail this way when there is no cloud agent ID.

## How to fix it

Run `msagent deployment list` first. If a suitable MCS deployment already exists, deploy to that record:

```text
msagent agent deploy --deployment-name "Development"
```

If needed, first create the record:

```text
msagent deployment create --deployment-type dev --deployment-name "Development"
```

Use the correct project and agent selectors when more than one agent is registered. Retry the original operation after deployment succeeds.

## How to avoid it

Complete deployment before binding target connections, sharing, or other operations that require an existing cloud agent.
