# 14042: Parameter is not declared by the provider or channel

[All error codes](../ErrorCodes.md)

## What happened

A supplied OAuth or channel parameter is not declared by the selected definition. The CLI refused the configuration before writing it.

## Why this happens

Parameter names are checked against the live OAuth provider schema or the CLI's channel catalogue. Names are case-insensitive, but misspellings and settings copied from another provider or channel remain invalid. Common OAuth settings use dedicated options rather than arbitrary generic parameters.

## How to fix it

For OAuth, inspect `msagent deployment oauth list-providers --provider-name <provider-name>`. Use the dedicated `--client-id`, `--client-secret`, and `--scopes` options for common settings, and `--parameters` only for declared provider-specific values.

For channels, inspect the relevant create or update help with `--channel <channel-name>`. Remove or correct the undeclared assignment named in the error.

Do not invent a parameter to force Azure to accept an undocumented setting.

## How to avoid it

Generate assignments from the selected definition, not examples for a different provider or channel.
