# 11035: Connection was not created

[All error codes](../ErrorCodes.md)

## What happened

The connection-creation or consent experience did not produce a usable new connection for the requested connector.

## Why this happens

Sign-in or consent may have been canceled, refused, or otherwise failed. The error includes the reason reported for the connector and environment.

## How to fix it

Resolve the reported authentication or consent issue and run the command again to sign in.

If you already have an appropriate working connection, use the binding command printed in the remediation instead of creating another one. Supply the actual connection ID and confirm that it belongs to the intended connector and environment.

Do not assume dependent references became ready just because a consent page opened. Review the connection listing after recovery.

## How to avoid it

Complete sign-in with the intended account and confirm connection readiness. Reuse a suitable existing connection when that meets your access requirements.
