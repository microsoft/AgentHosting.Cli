# 19054: The project folder's remote is not a GRS repository

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` or `msagent agent init` with AMS mode on was refused because the project folder's git remote isn't a GRS repository. Nothing was changed.

## Why this happens

AMS deploys agents only from GRS repositories, and msagent takes the project's repository from its `origin` remote, or from its only remote when none is named `origin`. That remote's url isn't the git url of a GRS repository on a Power Platform git host of your cloud, or the folder has several remotes and none is named `origin`.

## How to fix it

Use another folder, or remove the remote with `git remote remove <name>` and run the command again: msagent then adds the GRS repository as `origin`.

## How to avoid it

Keep AMS projects in clones of their GRS repositories.
