# 15013: Source contains the generated package envelope

[All error codes](../ErrorCodes.md)

## What happened

The package builder found `agenthosting.package.v0.json` at the source root and refused to build an ambiguous package.

## Why this happens

The builder generates that transport envelope itself. A root source file with the same name, compared case-insensitively, conflicts with the generated entry. This file is not the separate developer-authored `agent.manifest.json` runtime manifest.

## How to fix it

Inspect the named source file and preserve anything you need before moving the conflicting generated envelope outside the package source. Then rerun your packaging step. Do not rename or remove your runtime manifest to fix this error.

Building a package is local work and does not publish it. The current `msagent agent package upload` command sends an existing file; it does not rebuild or repair the source tree.

## How to avoid it

Keep generated package envelopes inside finished archives, not checked into the source root as input to the next build.
