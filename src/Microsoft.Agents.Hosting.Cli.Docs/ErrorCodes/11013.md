# 11013: Local folder contains a different workflow

[All error codes](../ErrorCodes.md)

## What happened

The workflow found on disk has a different workflow ID from the selected managed-agent record.

## Why this happens

The workspace content may have been replaced, copied from another workflow, or restored independently from its configuration. A deployment uses the files' workflow identity, so proceeding would act on a different workflow from the one selected.

## How to fix it

Compare the registered workflow ID and folder workflow ID in the error.

Restore the files for the registered workflow, or register the workflow actually on disk using `msagent agent init --agent-type MCSWorkflow` with the correct source.

Preserve both sets of files and the configuration while deciding which identity is intended. Do not change IDs merely to suppress the mismatch.

## How to avoid it

Restore workflow files and registry records together. Keep separate workflows in distinct workspaces instead of swapping folder contents beneath an existing registration.
