# 14040: Channel definition is unknown

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not find a channel definition for the supplied channel name or the channel type returned by Azure.

## Why this happens

Channel operations use a built-in catalogue to interpret supported parameters and safely display returned settings. A spelling mismatch, a channel unknown to this CLI version, or an unexpected Azure channel type can prevent that lookup.

## How to fix it

For an input name, inspect `msagent deployment channel create --help` and use the supported short channel name. Supported configurable types include `directline`, `webchat`, `msteams`, `m365extensions`, and `slack`.

If listing or reading existing channels fails, the problem may be a service-returned type rather than your input. Keep the reported channel name and CLI version and report the compatibility issue. Do not delete the channel just because this CLI cannot interpret it.

## How to avoid it

Use channel names from the installed CLI's help and keep the CLI compatible with your Azure channel configuration.
