# 14037: OAuth connection is not configured

[All error codes](../ErrorCodes.md)

> [!IMPORTANT]
> **CodeAgent: future state - do not use.** This page preserves an implementation
> error contract, not supported public-preview OAuth configuration instructions.
> Do not run its CodeAgent command examples.

## What happened

The requested OAuth connection was not found on the selected CodeAgent deployment's Azure bot.

## Why this happens

OAuth show and update need an existing connection setting. A wrong connection name, a different deployment, or a connection removed in Azure can cause the lookup to return nothing. OAuth connections are distinct from MCS deployment connection references.

## How to fix it

List the settings on the intended deployment:

```text
msagent deployment oauth list --deployment-id <deployment-id>
```

Use the returned connection name with `--connection <name>` and repeat the original operation. If the connection genuinely does not exist, configure it with `msagent deployment oauth create`, selecting the provider and its required settings.

Use `msagent deployment oauth list-providers` to inspect the live provider requirements. Do not paste credentials into troubleshooting reports or reuse masked values as secrets.

## How to avoid it

List connections before updating them, and keep connection names associated with their owning deployment.
