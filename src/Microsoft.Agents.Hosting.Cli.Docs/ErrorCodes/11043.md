# 11043: Agent creation was canceled

[All error codes](../ErrorCodes.md)

## What happened

Agent creation was canceled while the request transport was in progress. The operation may still have reached AMS.

## Why this happens

Canceling the CLI's wait does not establish that the service canceled its durable create operation. If the request was received, the agent may be reserved or created even though no success result was displayed.

## How to fix it

Preserve the exact idempotency key shown in the remediation.

If you still want this agent, retry the same request and options in the same environment using `--idempotency-key` with that value. Quote or escape it for your shell. Do not choose a new key for recovery of this attempt.

If you no longer want to create it, verify the service's recorded outcome with the available correlation information before assuming nothing exists.

## How to avoid it

Allow creation to finish when possible and retain the recovery key whenever canceling leaves the outcome uncertain.
