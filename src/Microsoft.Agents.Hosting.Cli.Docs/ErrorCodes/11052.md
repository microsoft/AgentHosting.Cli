# 11052: Sharing recipient email matches multiple users

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not select a unique user for the sharing operation. The supplied address
matched more than one user in the tenant directory.

## Why this happens

The CLI first tries the address as a user sign-in name. If that does not identify a user,
it searches Microsoft Graph for users with that email address. Multiple accounts,
including guest accounts, can share an email address. The CLI refuses to choose one
arbitrarily and reports matching sign-in addresses.

## How to fix it

Confirm which account should receive or lose access. Repeat the operation using that
account's full sign-in address or Entra object ID in the user selector. Verify the tenant
and identity before changing access; similar email addresses do not prove two records
represent the same account.

## How to avoid it

Use an Entra object ID when an email address is shared by multiple accounts, particularly
for guest users or automated sharing workflows. Do not rely on the directory's result
order to choose a recipient.
