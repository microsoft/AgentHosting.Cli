# 11027: Clone source agent was not found

[All error codes](../ErrorCodes.md)

## What happened

The clone operation could not resolve the requested source agent in the source environment.

## Why this happens

The schema name or cloud agent ID may be wrong, the agent may belong to another environment, or it may have been deleted. A managed-agent record ID is not necessarily the cloud ID needed for cloning.

## How to fix it

Run `msagent agent list --environment-id` with the source environment's ID to verify the available agents.

Correct the clone source name, or use `--mcs-clone-agent-id` with the intended cloud agent ID. If needed, correct `--mcs-clone-environment-id` as well.

Confirm the source before retrying; creating a new agent is not necessary to resolve a mistaken clone selector.

## How to avoid it

Keep source agent IDs paired with their environment IDs and refresh them from the current environment listing before cloning.
