# 12015: The token belongs to a different tenant

[All error codes](../ErrorCodes.md)

## What happened

The acquired token does not identify the tenant required by the operation, or the required target tenant is unknown.

## Why this happens

The selected environment or deployment belongs to a different tenant, guest-account acquisition returned the wrong tenant, or saved environment context lacks tenant information.

## How to fix it

Compare the tenant IDs in the message with the intended destination. If target tenant information is missing, run `msagent env select <environment-id>` to refresh it.

For a known target tenant, run `msagent auth create --tenant <tenant-id>` for the intended cloud using an account authorized there. If the account is correct but the destination is not, select the intended environment or deployment instead.

Do not change a target solely to make an authentication check pass.

## How to avoid it

Check account, tenant, and destination together before cloud operations, especially when using guest accounts or deployments across tenants.
