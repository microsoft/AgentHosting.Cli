# 13014: The live-test target is unsupported

[All error codes](../ErrorCodes.md)

## What happened

The requested live-test destination is outside the target types supported by this operation.

## Why this happens

Live MCS testing requires public cloud and MCS agent and deployment records. Sovereign or custom destinations, CodeAgent records, and AHRG records are not supported by this target resolver.

## How to fix it

Select the intended public-cloud MCS agent and its matching MCS deployment. Use `msagent agent list` and `msagent deployment list` to inspect available project records before changing selectors.

If the resource you actually need to test is unsupported, use its appropriate supported testing mechanism instead. Do not relabel a non-MCS record or change its cloud metadata to make validation pass; that does not convert the destination.

## How to avoid it

Check the operation's supported target types when designing tests. Keep different hosting types and cloud destinations explicitly distinguished in project configuration.
