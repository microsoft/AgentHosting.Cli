# 12001: Authentication failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not complete an authentication or account-selection operation. The accompanying message identifies the particular failure.

## Why this happens

This is the general authentication error. For example, an account selector can match no stored accounts or more than one account, or an account requested for activation may no longer exist.

## How to fix it

Run `msagent auth status` to inspect stored accounts. If several accounts match, use the home-account ID shown there when switching accounts. If the intended account is absent, run `msagent auth login` and choose it. Follow any more specific remediation printed with the error.

Do not share access tokens or token-cache contents when reporting a persistent problem.

## How to avoid it

Use an unambiguous stored account identity and check the active account before running commands that change cloud resources.
