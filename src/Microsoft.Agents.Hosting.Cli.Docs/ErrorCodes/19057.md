# 19057: The agent's folder already exists in the repository

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` with AMS mode on, for a project of an existing repository, was refused because the repository's `main` already holds a folder with the new agent's folder name. Nothing was created.

## Why this happens

Each agent is a top-level folder of its repository, and a new agent can't take a folder that already exists there, which may belong to an agent someone else registered.

## How to fix it

Create the agent under another name, or, to work on the agent that folder holds, clone the repository and run `msagent agent init` in the clone.

## How to avoid it

Pull the repository's latest commits before you create agents in a shared repository.
