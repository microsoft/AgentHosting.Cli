# 19055: --repository-id differs from the project's repository

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` or `msagent agent init` with AMS mode on was refused because `--repository-id` names another repository than the project's: the one the project folder's git remote names, or the one that holds the agents `.config` registered. Nothing was changed.

## Why this happens

A project's agents share one GRS repository.

## How to fix it

Drop `--repository-id` to use the project's repository, or use another folder for the other repository.

## How to avoid it

Pass `--repository-id` only for a folder that isn't linked to a repository yet.
