# 19053: The project folder holds files that are not part of the project

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` or `msagent agent init` with AMS mode on, in a folder that isn't a git repository yet, was refused because the folder holds files or folders that aren't part of the project. The message names up to five of them. Nothing was changed.

## Why this happens

msagent turns the project folder into a git repository whose `origin` is the agents' GRS repository, so the folder must hold only the project: `.config`, the agents' folders, the collection folders they declare, and git's own files.

## How to fix it

Move the files the message names out of the folder, or use an empty or new project folder.

## How to avoid it

Keep each project in a folder of its own.
