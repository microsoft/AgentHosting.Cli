# 19011: npm probe failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not safely complete the npm prerequisite probe.

## Why this happens

The executable cannot start or returned an unsuccessful probe result.

## How to fix it

Verify `npm --version` and executable access. Repair npm or PATH, then retry.

## How to avoid it

Check npm availability before attempting global package installation.
