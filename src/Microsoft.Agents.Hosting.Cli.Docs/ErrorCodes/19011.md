# 19011: The repository cannot hold MCS agents

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to use the repository for an MCS agent or standalone workflow.

## Why this happens

The repository isn't an active native GRS repository of the agent's home environment. It may belong to another environment.

## How to fix it

Make the repository's environment the agents' home environment, or use another repository. Without `--repository-id`, in a folder without a remote, `msagent agent create` and `msagent agent init` create a new repository in the home environment.

## How to avoid it

Use repositories of the environment the project's agents live in.
