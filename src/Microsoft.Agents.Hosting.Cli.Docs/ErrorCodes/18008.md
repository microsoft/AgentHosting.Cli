# 18008: Evaluation conversations exceed a supported limit

[All error codes](../ErrorCodes.md)

## What happened

The supplied conversations, or their total with conversations already stored, exceed a supported evaluation limit.

## Why this happens

A test set holds at most 20 conversations. Each conversation must contain at least one exchange and no more than six question-and-answer pairs. A question can contain at most 1,000 characters, including spaces.

An append operation also counts conversations already in the set.

## How to fix it

Read the exact limit named in the error. Split large inputs across multiple test sets, shorten questions, or reduce exchanges while preserving the test's meaning.

Inspect existing contents before appending. If replacement is intentional, the test-set update command supports `--replace`, but it discards existing conversations; export them first if needed.

## How to avoid it

Check conversation counts and lengths when preparing CSV or generated inputs. Account for stored content rather than validating incoming conversations alone.
