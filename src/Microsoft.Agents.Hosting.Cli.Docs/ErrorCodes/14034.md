# 14034: CodeAgent deployment was not found

[All error codes](../ErrorCodes.md)

## What happened

The CodeAgent deployment could not be resolved locally, or its backing Azure Bot Service resource returned not found.

## Why this happens

The selected project may not hold the deployment record, the ID may be stale, or the bot may have been removed in Azure. Some operations need the local record even when the cloud resource exists. A show or cloud update that receives a bot-not-found response removes the stale local deployment record.

## How to fix it

Check `msagent deployment list` in the intended project and verify the bot in the intended subscription and resource group. Correct a mistaken selector before provisioning anything.

If the deployment is genuinely missing, use `msagent deployment create` with the intended agent and deployment name. The direct-ARM create path derives the same deployment ID from those inputs and can adopt an existing bot at the resolved coordinates.

CodeAgent create, show, update, and delete require `AzureBotServiceFeatures`; consult the command's `--help`.

## How to avoid it

Keep project records with the deployment and coordinate Azure resource deletion with project maintenance.
