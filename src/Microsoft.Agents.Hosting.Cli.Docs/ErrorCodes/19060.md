# 19060: The project folder is itself an agent's folder

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent init` with AMS mode on was refused because the project folder is itself an agent's folder: it holds the agent's files directly rather than in a folder of their own. Nothing was changed.

## Why this happens

With AMS mode on, each agent is a top-level folder of the project and of its GRS repository, which AMS registers as the agent's folder.

## How to fix it

Run `msagent agent init` from the parent folder, which makes the agent's folder a top-level folder of the project.

## How to avoid it

Keep each agent in a folder of its own inside the project folder, as `msagent agent create` makes it.
