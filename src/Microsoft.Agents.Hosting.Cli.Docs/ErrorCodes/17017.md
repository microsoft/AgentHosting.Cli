# 17017: Copilot Studio reported an operation failure

[All error codes](../ErrorCodes.md)

## What happened

A Copilot Studio or Dataverse operation failed, or the target did not confirm the requested result.

## Why this happens

This general error covers multiple service paths. The operation and detail printed with it are important: the service may reject a request, return an unusable response, or fail to confirm that connection references match their declarations.

## How to fix it

Read the named operation and service detail. Verify environment access, permissions, and any connection requirements. Inspect the target before retrying a create, delete, sharing change, or deployment; an error is not a guarantee that all earlier steps were undone.

For a transient service issue, wait and retry after inspection. If it persists, report the operation, non-secret identifiers, and CLI version. Never include credentials or token-cache contents.

## How to avoid it

Validate prerequisites and use a compatible build. Review warnings and actual cloud state rather than treating a command exit status as a complete transaction history.
