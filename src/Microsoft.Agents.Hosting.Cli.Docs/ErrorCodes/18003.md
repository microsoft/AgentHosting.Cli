# 18003: A test set already has this name

[All error codes](../ErrorCodes.md)

## What happened

The requested test-set name is already in use. The CLI did not silently replace its conversations.

## Why this happens

You tried to create a named set that already exists, or started an evaluation from supplied conversations under an existing name without explicitly requesting an update.

## How to fix it

Inspect the existing set with `msagent agent eval testset show --testset <name-or-id>`.

To evaluate its existing conversations, use `msagent agent eval run --testset <name-or-id>`. To intentionally replace conversations while starting a run from CSV or generated input, the run command supports `--update-testset`. Review or export the existing set before choosing replacement; it changes stored test content and a resulting run may be charged.

For a separate set, choose a new name instead.

## How to avoid it

Decide explicitly whether to reuse, replace, or create test data. Check inventory before repeating a creation attempt.
