# 11038: Clone content could not be downloaded locally

[All error codes](../ErrorCodes.md)

## What happened

The source agent's content could not be written into the selected project directory. No clone was registered and nothing was sent to Copilot Studio.

## Why this happens

Downloading or materializing the clone failed before registration. The reported cause may identify a service problem, file access issue, or other failure affecting the destination.

## How to fix it

Resolve the underlying problem, then rerun the same clone command. Check that the destination is accessible and writable if the failure concerns local files.

Inspect any files left by the failed attempt before reusing the path. Preserve unrelated or valuable content rather than clearing the project indiscriminately. The source cloud agent does not need to be deleted or recreated.

## How to avoid it

Use a suitable destination with working file permissions and verify source-environment access before cloning. Keep existing work outside a new clone's destination.
