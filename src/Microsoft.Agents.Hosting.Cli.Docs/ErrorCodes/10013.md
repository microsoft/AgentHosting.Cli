# 10013: Workspace schema name cannot be read

[All error codes](../ErrorCodes.md)

## What happened

Initialization could not read a usable `schemaName` from the workspace's project file.

## Why this happens

The project file may be missing, malformed, or lack its schema name. Without that identity, registration cannot reliably associate the workspace with the agent it deploys as.

## How to fix it

Check the workspace path shown in the error. Restore the project file or its correct `schemaName` from source control, resolving any merge conflicts or formatting errors. Use the schema name belonging to this agent, not a new name chosen merely to satisfy validation.

Run `msagent agent init` again after repairing the project file.

## How to avoid it

Preserve project identity files alongside workspace content. Review merges that affect schema names, especially when copying folders between projects.
