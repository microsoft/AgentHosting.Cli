# 11037: Clone registration was rolled back

[All error codes](../ErrorCodes.md)

## What happened

The clone could not finish recording its local registration. The newly added managed-agent record was removed.

## Why this happens

The agent record was added, but saving the associated deployment failed. The CLI rolls back that record so the registry does not retain a half-created clone registration. The error includes the original write failure.

## How to fix it

Resolve the reported configuration-write or storage problem, then rerun the clone operation.

Downloaded files may still be present even though the registration was rolled back. Inspect the destination before retrying, preserve useful content, and use a fresh destination if existing content prevents another clone. Do not delete the source cloud agent; this failure concerns local clone registration.

## How to avoid it

Ensure the project configuration is writable and avoid concurrent registry changes during cloning. Review both downloaded content and registration results after a failed clone.
