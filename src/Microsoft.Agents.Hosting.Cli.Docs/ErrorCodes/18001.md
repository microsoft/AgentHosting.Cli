# 18001: The evaluation test set was not found

[All error codes](../ErrorCodes.md)

## What happened

No evaluation test set matches the supplied name or ID for the selected agent and environment.

## Why this happens

The selector may be wrong, the set may have been deleted, or the command may target a different agent or environment. A set can also disappear between lookup and a later read.

## How to fix it

Run `msagent agent eval testset list` with the same agent and environment selectors. Confirm the destination and use a listed test-set ID or exact intended name.

If the set should exist but is absent, check whether another author removed it before creating a replacement. Do not start a new evaluation merely to test whether a selector works; evaluation runs can be charged.

## How to avoid it

Record test-set IDs alongside their agent and environment. Coordinate deletion with other users and refresh inventory before operations on older test sets.
