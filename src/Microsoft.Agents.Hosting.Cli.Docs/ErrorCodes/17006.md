# 17006: Connection readiness could not be recorded locally

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not write the workspace's connection state. That state is needed to decide whether a workflow can be enabled.

## Why this happens

The workspace may be read-only, inaccessible, or locked by another process. The error includes the workspace location and file-system reason.

## How to fix it

Close programs holding the affected workspace and restore write permissions for your current user. Resolve any reported storage problem, then run the same command again.

Do not manually create readiness records or assume that a cloud connection alone means a workflow is ready. Inspect current connection and workflow state if earlier steps completed; a local recording failure does not automatically undo cloud changes.

## How to avoid it

Work in a writable project directory and avoid competing processes updating its state. Let supported connection commands record readiness before enabling dependent workflows.
