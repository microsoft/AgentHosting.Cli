# 99002: Invalid command usage

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not proceed with the supplied command, arguments, or context. The error
message explains which requirement was not met.

## Why this happens

Examples include an unknown command or option, a missing required argument, an invalid
option value, or an incomplete command group. Some operation-specific input checks also
use this general usage code.

Application identity options on `auth create` are unavailable while
`appusersupport` is disabled (the default). Their long names and local aliases
are rejected before authentication or profile mutation.

## How to fix it

Read the error message and run `msagent --help`, or add `--help` to the relevant command.
For example, use `msagent agent create --help` to check the supported options for creation.
Supply the missing value, correct the option, or choose a listed subcommand.

If the message identifies missing project, account, or environment context, correct that
context as instructed rather than repeatedly submitting the same arguments. Recheck the
command before retrying.

For user sign-in, omit application credential options. If application profile
creation is explicitly approved for a developer session, enable `appusersupport`
as described in the [authentication reference](../Command_Auth.md#msagent-auth-create).
Existing application profiles do not require this creation flag for use.

## How to avoid it

Use the help from the installed CLI version when writing scripts. Quote argument values
that contain spaces and check required options before submitting a command. Command
availability can depend on enabled features.
