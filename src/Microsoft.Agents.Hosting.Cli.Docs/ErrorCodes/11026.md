# 11026: Sharing state contains duplicate principals

[All error codes](../ErrorCodes.md)

## What happened

The service returned more than one sharing entry for the same principal, so the CLI refused to change access.

## Why this happens

A change cannot safely identify which duplicate entry should be modified. Because sharing is written as a whole state, changing one entry could also rewrite another entry for that person.

## How to fix it

Inspect the duplicates listed in the error and resolve the duplicate access in Copilot Studio. Confirm the intended effective role and organization-wide sharing rather than removing unrelated users.

Once the access state is unambiguous, rerun the original CLI command. Use `msagent agent share show` to review the resulting access.

Do not clear all sharing entries as a shortcut.

## How to avoid it

Avoid overlapping access-management operations and review existing shares before making changes through multiple tools or sessions.
