# 19072: A commit that never synced lacks the commit Copilot Studio synced from

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent pull` with AMS mode on was refused because the commit the agent's or collection's folder holds has never synced with Copilot Studio and doesn't contain the commit Copilot Studio was last synced from. The message names both commits with their branches. Nothing was pulled.

## Why this happens

A pull merges what changed in Copilot Studio since the folder's last sync into the folder's files. msagent keeps Copilot Studio's side of each sync for the commit the folder held then, and finds none for this commit or any commit it builds on. The commit Copilot Studio was last synced from is on a branch this commit doesn't contain, so the folder's files can't be brought to it without losing this branch's work.

## How to fix it

Merge the commit the message names, for example with `git merge 1a2b3c4`, then run `msagent agent pull` again.

## How to avoid it

Merge the branch you last deployed from your folder before you pull on another branch.
