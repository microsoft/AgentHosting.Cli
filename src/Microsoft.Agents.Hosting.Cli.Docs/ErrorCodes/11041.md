# 11041: Agent creation redirect was refused

[All error codes](../ErrorCodes.md)

## What happened

The creation endpoint returned an HTTP redirect. The CLI did not follow it.

## Why this happens

Authenticated creation sends a delegated authorization token only to the configured host. Redirecting to another address could expose that token or use unintended service routing, so redirect responses are not accepted.

## How to fix it

Verify the selected environment and any configured Agent Management Service endpoint with the deployment administrator. Use the actual supported create endpoint rather than a redirecting alias, sign-in page, or proxy address.

Do not manually forward the authorization token to the redirect destination.

Preserve any idempotency key and correlation identifiers shown with the failure. If retrying the same create attempt after routing is fixed, reuse its key rather than creating a distinct request.

## How to avoid it

Configure authenticated endpoints directly and verify routing changes before creation operations.
