# 14012: Deployment push did not finish

[All error codes](../ErrorCodes.md)

## What happened

A push stage failed after the CLI had connected to, created, or adopted the target Copilot Studio agent. The deployment has not been recorded as completed.

## Why this happens

Deployment can push component collections before the main workspace. A later push failure does not roll back earlier cloud changes or remove a newly created agent. The message describes the target and includes the underlying failure chain.

## How to fix it

Inspect the named agent and environment, then fix the reported problem. Preserve both local work and any cloud changes that need review.

Repeat the same deploy against the same deployment and schema. Existing target agents are adopted rather than duplicated, so creating a new record or changing the schema is not necessary for recovery. Do not add `--overwrite` unless replacing cloud changes is intentional.

## How to avoid it

Verify workspace readability, collection connections, and target access before deploying. Do not interpret a missing completion timestamp as proof that no remote content changed.
