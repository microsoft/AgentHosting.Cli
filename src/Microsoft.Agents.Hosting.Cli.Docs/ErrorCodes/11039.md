# 11039: Cloud agent deleted but local records remain

[All error codes](../ErrorCodes.md)

## What happened

The cloud agent was deleted, but the CLI could not remove its local managed-agent and deployment records.

## Why this happens

Cloud deletion succeeded before the local registry update failed. File access, concurrent configuration changes, or another registry-write problem can leave records pointing at an agent that no longer exists.

## How to fix it

Resolve the configuration problem named in the error, then rerun `msagent agent delete` for the same selected record.

An absent cloud agent can be handled by deletion paths that resolve the target through its deployment. However, a connected `msagent agent delete` can fail while rereading the deleted agent for ownership verification. If that happens, preserve the remaining records and seek support for local cleanup. Check the project, agent, and deployment selectors carefully before any retry.

Do not recreate the cloud agent or manually clear the entire configuration to finish this cleanup.

## How to avoid it

Keep the configuration writable and avoid overlapping operations against the same project. Check local cleanup as well as cloud deletion in command results.
