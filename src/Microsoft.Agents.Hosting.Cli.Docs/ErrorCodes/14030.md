# 14030: Deployment read timed out before update

[All error codes](../ErrorCodes.md)

## What happened

The CLI timed out while reading the current deployment. No package-revision update request was sent.

## Why this happens

The update route first reads the deployment's identity and current Package Revision. That read must complete before the CLI can safely submit the update with the expected current revision. A slow service or stalled connection prevented it from finishing.

## How to fix it

Check access to the configured AMS control-plane endpoint and the service's health. Once it is responsive, repeat the same `msagent deployment update` command with the intended agent, deployment, and existing `--package-revision`.

You do not need to upload package bytes again or create a replacement deployment. Keep any correlation IDs if the read continues to time out and report them to the service owner.

## How to avoid it

Confirm service availability before beginning a revision update. Do not confuse this read-only failure with an indeterminate submitted update.
