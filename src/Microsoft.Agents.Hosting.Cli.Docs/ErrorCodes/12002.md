# 12002: Sign-in is required

[All error codes](../ErrorCodes.md)

## What happened

The command needs a signed-in account, but no usable active sign-in profile is available.

## Why this happens

You have not signed in with this CLI, have signed out, or are using a different operating-system account or configuration location. A non-interactive command cannot open sign-in UI to resolve this.

## How to fix it

Run `msagent auth list` and select the intended existing profile with `auth select --name <name>`
or `--index <position>`. If none exists, use `auth create` with the approved user/workload method
and intended tenant/cloud. Check `auth who`/`auth status`.

For automation, configure an eligible workload method; explicit interactive authentication always
fails with 12007 / exit 3 under `--non-interactive=true`. A sign-in in another tool is not an
automatic substitute for a selected msagent profile.

## How to avoid it

Check authentication in the actual user context used by your script rather than assuming a session from another terminal or machine is available.
