# 14019: Package exceeds the upload size limit

[All error codes](../ErrorCodes.md)

## What happened

The package file is larger than the upload contract allows. The CLI stopped before uploading it.

## Why this happens

The current package upload limit is 128 MiB (134217728 bytes). This checks the actual file length, not the size of individual source files. The error reports the selected file's size and the allowed maximum.

## How to fix it

Review the artifact's contents and remove unnecessary build output, caches, vendored files, or other material that does not belong in the delivered package. Preserve required runtime content, then regenerate the artifact within the limit.

Repeat the gated `msagent agent package upload` command with the smaller file. There is no upload flag that increases the service's request-body limit. Splitting the archive into unrelated uploads is not a substitute for a valid package.

## How to avoid it

Measure the finished artifact in your packaging process and check for unexpectedly large content before uploading.
