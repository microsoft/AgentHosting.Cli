# 17019: The component collection was not found

[All error codes](../ErrorCodes.md)

## What happened

A requested component collection could not be resolved in the target environment.

## Why this happens

The collection selector may be misspelled, belong to another environment, or identify a collection that is unavailable to the account. Collection schema names and display names are not interchangeable.

## How to fix it

Confirm the collection's identity and environment with its owner or in Copilot Studio. Supply its schema name or its GUID. Where the command accepts several collection IDs, separate the GUIDs with `;` and quote the value in shells that interpret semicolons.

Verify the target before repeating the operation. Do not substitute a similarly named collection without checking that it contains the intended content.

## How to avoid it

Record stable collection identities with the environment they belong to. Check access and collection availability before using them in automated clone or synchronization workflows.
