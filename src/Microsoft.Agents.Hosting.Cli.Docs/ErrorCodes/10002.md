# 10002: Agent configuration is invalid

[All error codes](../ErrorCodes.md)

## What happened

The CLI found `agent.config.json`, but could not read or validate its contents.

## Why this happens

The file may contain invalid JSON, unresolved merge conflicts, missing required values, duplicate records, or relationships that do not satisfy the registry's rules. The message identifies the file and the specific problem.

## How to fix it

1. Preserve the current file before changing it, especially if it contains recent deployment records.
2. Fix the reported JSON or record problem, or restore a known-good version from source control.
3. Reconcile any newer agent or deployment entries rather than replacing the file with an empty configuration.
4. Retry the original command.

Do not delete the configuration just to bypass validation: it may be the only local copy of your deployment history.

## How to avoid it

Let CLI commands manage registry changes. Review configuration merges carefully and keep recoverable versions in source control.
