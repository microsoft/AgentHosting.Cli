# 19067: A git command failed

[All error codes](../ErrorCodes.md)

## What happened

A git command msagent ran with AMS mode on failed, such as `git clone`, `git fetch`, `git commit` or `git push`. The message names the command, the folder it ran in, and git's reason.

## Why this happens

With AMS mode on, `msagent agent create` and `msagent agent init` clone, link, commit and push the project's GRS repository with git, which signs in with msagent's credential helper. git may lack access to the repository, find the folder in a state it can't change, such as a merge in progress, or lose its connection.

## How to fix it

Fix the problem git reports, then run the command again. When git can't sign in, run `msagent auth login`, and check that the repository's owner gave you access.

## How to avoid it

Keep the project folder's git state clean before you run msagent, and stay signed in with `msagent auth login`.
