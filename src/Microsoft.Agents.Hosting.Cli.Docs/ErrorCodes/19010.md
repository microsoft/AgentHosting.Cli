# 19010: npm version could not be validated

[All error codes](../ErrorCodes.md)

## What happened

The npm prerequisite probe returned an unusable version.

## Why this happens

The selected executable returned malformed version output.

## How to fix it

Check `npm --version`, correct stale PATH entries, or repair npm with your Node.js installation.

## How to avoid it

Use the npm distributed with a supported Node.js installation.
