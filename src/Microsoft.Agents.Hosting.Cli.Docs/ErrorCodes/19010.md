# 19010: The repository was not found

[All error codes](../ErrorCodes.md)

## What happened

The repository the command named doesn't exist in the agent's home environment, or your account can't read it.

## Why this happens

The `--repository-id` value, or the repository the project folder's git remote names, may be wrong, the repository may have been deleted, or your account has no access to it.

## How to fix it

Check `--repository-id` and the project folder's `origin` remote, and ask the repository's owner to share it with you in GRS. Without `--repository-id`, in a folder without a remote, `msagent agent create` and `msagent agent init` create a new repository for the project.

## How to avoid it

Keep repository ids with the projects that use them, and check access before you script against a shared repository.
