# 13011: The target API request failed

[All error codes](../ErrorCodes.md)

## What happened

A target API request failed outside the more specific authentication, audience, permission, and consent categories.

## Why this happens

The HTTP status and service code identify the cause. Possibilities include an unavailable resource, invalid input, throttling, a service problem, or an unusable response. The failure is not necessarily transient.

## How to fix it

Read the operation, HTTP status, service code, and any supplied remediation. Correct the resource identity or input when indicated. For throttling or service unavailability, wait before retrying.

If Azure Bot Service reports `LocationNotAvailableForResourceType`, follow the specific instruction to use `--location global` on the affected provisioning command.

For a mutating or multi-step command, inspect current cloud state before repeating it; a failed response does not prove nothing changed.

## How to avoid it

Validate destination and inputs first, respect service retry guidance, and retain non-secret operation details for troubleshooting persistent failures.
