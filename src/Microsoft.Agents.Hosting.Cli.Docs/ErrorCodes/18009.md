# 18009: Waiting for the evaluation run timed out

[All error codes](../ErrorCodes.md)

## What happened

The CLI reached its wait limit without observing the evaluation run finish.

## Why this happens

The service-side evaluation is asynchronous and can take longer than the client's polling window. Expiration of that window does not cancel the run.

## How to fix it

Retain the run ID printed in the message. Check the same run later with `msagent agent eval show --run-id <run-id>`, using the original agent and environment selectors.

If you no longer want it to continue, inspect its state and use `msagent agent eval cancel --run-id <run-id>` while it is still cancellable.

Do not start another run merely because waiting ended: the original can still be active and charged.

## How to avoid it

Choose an appropriate `--timeout-minutes` when using the run command's `--watch` mode. Track run identity separately from the client process so interrupted waiting does not cause duplicate evaluations.
