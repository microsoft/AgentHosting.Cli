# 12020: Owned credential cleanup is incomplete

[All error codes](../ErrorCodes.md)

## What happened

Owned credential finalization or cleanup could not finish without another typed primary failure.
This cleanup-only code is exit 1. When cleanup accompanies a primary error, that primary numeric
code/exit is retained instead; caller cancellation remains 130.

## Why this happens

Protected storage may be inaccessible, an owned reference may still have an in-flight lease, or a
cleanup operation was interrupted. Recoverable owned references are retained for another attempt.

## How to fix it

Read the safe `metadataCommitted`/`cleanupIncomplete` guidance. Inspect `msagent auth list` and
`msagent auth who` before another mutation: a committed change was not rolled back. Restore the
same user's protected storage access or wait for in-flight owned use to finish. Retry
`msagent auth clear` only when clearing that owned msagent state is intended.

Do not remove PAC/Azure/broker accounts or source certificate files. Do not expose owned credential
references, passwords, caches or exception response bodies when reporting the problem.

## How to avoid it

Ensure protected storage is available before mutations and coordinate concurrent owned-reference
use. Treat cancellation/partial failure as an observable state to inspect, not a rollback guarantee.
