# 17034: Copilot Studio was still provisioning the classic agent

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy`, `msagent agent push` or `msagent agent publish` waited for Copilot Studio to finish provisioning a classic agent, and the agent was still provisioning when the wait ran out. Nothing was pushed into the agent and no publish was requested. The agent itself is kept.

## Why this happens

Copilot Studio provisions a new classic agent in the background after it is created, and it cannot take content or a publish until that finishes. The command reads the agent's provisioning status and template before its first write and before a publish, and waits up to 5 minutes for a classic agent's status to clear. Provisioning usually takes seconds, but it can take longer when the environment is busy.

An agent created from the CLI agent template is provisioned by its first publish instead, so the command neither waits for it nor reports this code.

## How to fix it

Wait a few minutes, then run the same command again. It reuses the same agent rather than creating another one, and it pushes or publishes once Copilot Studio reports the agent as provisioned.

## How to avoid it

Allow a few minutes between creating an agent in a new environment and deploying to it in automated release steps, and retry the deploy when it reports this code.
