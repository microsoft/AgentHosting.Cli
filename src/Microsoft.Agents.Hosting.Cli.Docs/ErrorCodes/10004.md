# 10004: More than one workspace can be registered

[All error codes](../ErrorCodes.md)

## What happened

Registration found several unregistered Copilot Studio workspaces beneath the project root and could not choose one.

## Why this happens

A project can contain multiple workspace folders. When more than one eligible folder is not yet represented in the registry, automatic discovery is ambiguous. The error lists the candidate locations.

## How to fix it

Run `msagent agent init` again with `--mcs-agent-source` pointing at the workspace you intend to register. Check that the selected folder contains the intended agent, not a sibling workspace or an unrelated copy.

Register additional workspaces separately if you want each one represented. There is no need to remove other folders to make discovery choose one.

## How to avoid it

Supply the workspace source explicitly when registering within a multi-agent project. Keep agent names and folder locations distinct so later selections remain clear.
