# 13006: Saved environment state cannot be used

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not read, validate, or save its persisted environment selection.

## Why this happens

The selection file may be corrupt, unsupported, unreadable, or unwritable. The CLI deliberately reports this rather than silently forgetting which environment you selected.

## How to fix it

Read the accompanying file-system or validation reason. Restore appropriate access to the CLI configuration directory and close programs holding its files.

Use `msagent env list` to confirm the intended environment, then run `msagent env select <environment-id>` to record a valid selection. If the supported command cannot recover the state, report the failure and configuration location to support.

Do not delete configuration blindly: losing selection can cause later commands to target a destination you did not intend.

## How to avoid it

Manage selection through CLI commands and preserve normal user access to the configuration directory. Avoid copying saved state between incompatible installations.
