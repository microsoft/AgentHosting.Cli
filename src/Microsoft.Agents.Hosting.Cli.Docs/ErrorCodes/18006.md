# 18006: The evaluation run can no longer be canceled

[All error codes](../ErrorCodes.md)

## What happened

The requested evaluation run has already reached a state that cannot be canceled.

## Why this happens

Only queued or in-progress runs can be stopped. The run may have finished between your last status check and the cancellation command.

## How to fix it

Read the state printed with the error and inspect the result with `msagent agent eval show --run-id <run-id>`.

If the run has completed, there is no active work left for cancellation to stop. Review or preserve its results before deciding whether to delete it through the supported command. Cancellation is not a way to reverse an already completed evaluation or its charges.

## How to avoid it

Check the latest state when cancellation matters and request cancellation while a run is still active. Make automation tolerate a run finishing naturally before its cancellation step executes.
