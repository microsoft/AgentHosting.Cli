# 12006: Secure token storage is unavailable

[All error codes](../ErrorCodes.md)

## What happened

The CLI cannot persist tokens securely and refused to silently store them in plaintext.

## Why this happens

The platform secret store is unavailable: Windows DPAPI, macOS Keychain, or Linux Keyring. An unsupported operating system also causes this error. Headless Linux sessions may not have an accessible keyring.

## How to fix it

Use Windows, macOS, or Linux and restore access to that platform's secret store. Prefer fixing secure storage or running in a supported user session.

Only if your security policy explicitly permits plaintext token storage, `AH_CLI_ALLOW_UNPROTECTED_CACHE=true` opts into an unprotected cache when secure storage is unavailable. This exposes reusable credentials to anyone who can read the cache; it is not the recommended routine fix. It does not add support for other operating systems.

## How to avoid it

Provision and unlock secure credential storage before authentication, including in automated execution environments.
