# 17004: The agent sharing state could not be read

[All error codes](../ErrorCodes.md)

## What happened

The service did not return a complete, readable sharing state for the requested operation.

## Why this happens

The response may be incomplete or incompatible with the contract this CLI build understands. Sharing is written as a whole state, so replacing it without reading existing access could remove other people's permissions.

## How to fix it

Run `msagent agent share show` with the same agent and environment selection. Inspect the actual access before attempting another sharing change.

If that read also fails, stop making sharing changes through this build and report the operation and CLI version. Do not repeatedly write a guessed sharing state. If the failed operation was a write, verify access in Copilot Studio because a response failure is not proof that no change occurred.

## How to avoid it

Use a compatible CLI build and verify sharing snapshots before sensitive access changes, particularly after service or client upgrades.
