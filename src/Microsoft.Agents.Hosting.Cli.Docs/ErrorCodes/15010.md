# 15010: Uploaded package digest does not match

[All error codes](../ErrorCodes.md)

## What happened

The service-reported SHA-256 digest differs from the digest of the package bytes sent by the CLI.

## Why this happens

This is an integrity mismatch between the local artifact and the remote result. It is different from a local archive changing after build: the disagreement is with the service's description of what it received or persisted.

## How to fix it

Do not treat the artifact as successfully published or deploy its unverified revision. Keep the exact local package unchanged and retain both reported digests.

Ask the service owner to investigate transfer, request routing, and persisted-artifact integrity before deciding whether to retry. Compare operation details using safe correlation information; do not attach the package or credentials to a public report.

Uploading a modified archive immediately would obscure which bytes produced the mismatch.

## How to avoid it

Use stable artifacts and trusted service routing. Keep digests with release artifacts and require a matching upload result before deployment.
