# 19002: Playground tool check failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not safely inspect the playground tool.

## Why this happens

A PATH candidate or its version probe failed unexpectedly.

## How to fix it

Check PATH and the installation. In your terminal, check `agentsplayground --version` and repair the package if it is unusable.

## How to avoid it

Keep PATH entries valid and use a supported playground installation.
