# 19002: This commit cannot be deployed to this stage

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote --commit-id <commit>` to a Test deployment named a commit that no Dev deployment of the agent has deployed, so nothing was deployed.

## Why this happens

A Test deployment takes only a commit that the agent's Dev deployment deployed, through a remote deploy or through a local deploy of a pushed commit without local changes. Without `--commit-id`, a Test deploy takes the commit Dev deployed last.

## How to fix it

Deploy the commit to Dev first with `msagent agent deploy --remote --deployment-name <dev-deployment> --commit-id <commit>`, then deploy it to Test again, or drop `--commit-id` to deploy the commit Dev deployed last. With AMS mode on, `msagent deployment list` shows the commit each deployment deployed last.

## How to avoid it

Deploy each commit to Dev before you promote it to Test.
