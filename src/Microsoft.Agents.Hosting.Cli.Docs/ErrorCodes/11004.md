# 11004: Command does not support this agent type

[All error codes](../ErrorCodes.md)

> [!IMPORTANT]
> **CodeAgent: future state - do not use.** Any CodeAgent-specific behavior below
> is retained as implementation reference, not a supported public-preview workflow.

## What happened

The selected managed-agent record is not a Copilot Studio agent type supported by this command.

## Why this happens

Some commands apply only to `MCSAgent`; others support both Copilot Studio agents and standalone workflows. A CodeAgent or another unsupported record cannot use that operation just because it appears in the same registry.

## How to fix it

Review the command named in the error and the selected agent's type with `msagent agent show`.

Select a supported Copilot Studio record using `--agent-id` or `--agent-name`.
Do not switch to a future-state CodeAgent route to bypass this restriction.

Do not change the record's type in configuration to bypass the restriction; that does not convert the underlying agent.

## How to avoid it

Keep type-specific commands associated with the correct agent records in scripts and deployment instructions.
