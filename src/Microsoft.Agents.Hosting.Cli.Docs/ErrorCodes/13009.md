# 13009: The account lacks target permissions

[All error codes](../ErrorCodes.md)

## What happened

The target API returned HTTP 403 because the signed-in account lacks permission for the requested operation.

## Why this happens

Authentication succeeded, but the account does not have the necessary Azure role or directory permission at the relevant scope. Signing in successfully is not authorization to change every resource.

## How to fix it

Confirm the intended account with `msagent auth status`. Ask the resource or tenant administrator for the least-privileged role or permission needed for the operation named in the message.

For Azure requests, check the subscription, resource group, and resource scope; for Graph requests, check the required directory or application-registration permissions. Allow permission changes to propagate and refresh sign-in if required.

Inspect earlier successful steps before repeating a multi-step operation.

## How to avoid it

Verify operation-specific access at the actual destination before provisioning or changing resources, rather than relying on access in another subscription or tenant.
