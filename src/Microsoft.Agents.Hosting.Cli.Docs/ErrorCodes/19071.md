# 19071: A commit that never synced holds uncommitted changes

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent pull` with AMS mode on was refused because the agent's or collection's folder has uncommitted changes, and the commit it holds has never synced with Copilot Studio. The message names the folder and the commit. Nothing was pulled.

## Why this happens

A pull merges what changed in Copilot Studio since the folder's last sync into the folder's files. msagent keeps Copilot Studio's side of each sync for the commit the folder held then, and finds none for this commit or any commit it builds on. To pull, msagent would first bring the folder's files to the commit Copilot Studio was last synced from, and uncommitted changes would be mixed up with Copilot Studio's.

## How to fix it

Commit or stash the changes, for example with `git stash`, then run `msagent agent pull` again.

## How to avoid it

Commit your changes before you pull on a branch that has never synced with Copilot Studio.
