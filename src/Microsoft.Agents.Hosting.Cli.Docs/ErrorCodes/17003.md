# 17003: The Copilot Studio management endpoint is missing

[All error codes](../ErrorCodes.md)

## What happened

The environment inventory did not advertise the Copilot Studio management endpoint needed to reach its agents.

## Why this happens

Environment information may be stale or incomplete, or the selected environment does not advertise a usable Copilot Studio endpoint. Operations such as sharing and evaluation require that endpoint.

## How to fix it

Run `msagent env select <environment-id>` to refresh the inventory for the intended environment. Check the account and environment if the endpoint is still absent.

Ask the environment administrator to confirm that Copilot Studio is available there. If it should be available but inventory continues omitting the endpoint, report the environment ID and CLI version. Do not substitute an endpoint from a different environment.

## How to avoid it

Verify service availability before automating agent-management tasks. Refresh environment context after provisioning changes and use inventory-discovered destinations rather than guessed URLs.
