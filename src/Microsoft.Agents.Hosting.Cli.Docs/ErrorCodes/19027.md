# 19027: Playground installation prompt failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not complete its installation-consent prompt.

## Why this happens

The prompt failed rather than receiving an explicit refusal.

## How to fix it

Rerun in a working interactive terminal. For an intended unattended installation, explicitly use `--install-playground`.

## How to avoid it

Use a terminal that supports confirmation or provide the documented unattended installation opt-in.
