# 19027: This command needs the on-behalf-of endpoint

[All error codes](../ErrorCodes.md)

## What happened

The command needs the Agent Management Service to act on your behalf, but the test-only data-plane override points at a host that cannot do that. Nothing was sent.

## Why this happens

`MSAGENT_AMS_DATAPLANE_ENDPOINT` sends data-plane calls straight to a service host, which never receives the gateway ticket that on-behalf-of calls such as `agent deploy --remote` and `agent capture` need, and `MSAGENT_AMS_ONBEHALFOF_ENDPOINT` is not set.

## How to fix it

Set `MSAGENT_AMS_ONBEHALFOF_ENDPOINT` (and `MSAGENT_AMS_ONBEHALFOF_AUDIENCE` when it differs) to a gateway host that carries the ticket, or unset `MSAGENT_AMS_DATAPLANE_ENDPOINT` to use the Power Platform API.

## How to avoid it

Set both overrides together in end-to-end test shells.
