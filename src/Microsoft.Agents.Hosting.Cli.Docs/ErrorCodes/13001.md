# 13001: The environment endpoint is not trusted

[All error codes](../ErrorCodes.md)

## What happened

The CLI rejected an environment endpoint, organization URL, or malformed inventory identifier before using it as a trusted destination.

## Why this happens

The address may not be absolute HTTPS, its host may fall outside the selected cloud's allowed hosts, or inventory data may be malformed. HTTPS alone does not establish that a host belongs to Power Platform.

## How to fix it

Run `msagent env list` to refresh the inventory. Verify the active account and cloud, then select the intended environment with `msagent env select <environment-id>` if its inventory is valid.

If the service continues returning an untrusted address, stop and report the inventory problem. Do not bypass endpoint validation, edit stored endpoints, or redirect credentials to a host merely because it uses HTTPS.

## How to avoid it

Use environments discovered through the CLI and the correct cloud configuration. Refresh selection after changes instead of copying saved endpoint data.
