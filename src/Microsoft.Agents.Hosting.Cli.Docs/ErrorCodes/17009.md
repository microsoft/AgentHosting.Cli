# 17009: Cloud component changes must be retrieved

[All error codes](../ErrorCodes.md)

## What happened

The component synchronization check found remote changes that must be retrieved before this push can proceed without overwrite.

## Why this happens

A tracked component changed or was deleted in the cloud, or a newly created remote component overlaps a local change. This is not limited to components edited on both sides.

## How to fix it

Preserve your local work, then run `msagent agent pull`. Review the updated files and any conflict diagnostics, resolve the intended content, and deploy again.

If replacing cloud content is deliberate, the deployment command supports `--overwrite`. Use it only after reviewing what will be replaced and coordinating with other authors.

This check is not general conflict protection for knowledge files, prompts, connectors, or workflows. Those resources can be overwritten during synchronization by design.

## How to avoid it

Pull before authoring and coordinate cloud edits. Keep recoverable copies of local and cloud content before choosing overwrite.
