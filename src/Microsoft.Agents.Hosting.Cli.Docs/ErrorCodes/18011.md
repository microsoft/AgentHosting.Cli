# 18011: No evaluation conversations were generated

[All error codes](../ErrorCodes.md)

## What happened

Copilot Studio returned no generated conversations. There was nothing to store or evaluate, so this operation did not change the test set.

## Why this happens

The conversation-generation request completed without usable generated content. An empty result is not a successful populated test set or a completed evaluation.

## How to fix it

Check the intended agent and generation settings, then try generation again. If generation repeatedly returns nothing, prepare conversations yourself using the Copilot Studio CSV format and supply them through the affected command's `--from-csv` option.

Inspect stored test data before starting an evaluation and confirm it actually covers the scenarios you intend. Do not substitute an unrelated agent solely to obtain a nonempty result.

## How to avoid it

Review generated conversations before relying on them. Keep reviewed CSV test data available for important regression scenarios instead of making every run depend on fresh generation.
