# 19038: The Dev deployment has no Copilot Studio agent or workflow yet

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent capture` was refused because the agent's Dev deployment has no Copilot Studio agent, or for a standalone workflow no cloud flow, to capture. No commit was created.

## Why this happens

A deployment gets its Copilot Studio agent or cloud flow when it is first deployed. Until then, Copilot Studio holds nothing to capture.

## How to fix it

Deploy to the agent's Dev deployment with `msagent agent deploy --agent-id <agent-id> --deployment-name <dev-deployment>`, then capture.

## How to avoid it

Deploy before you capture.
