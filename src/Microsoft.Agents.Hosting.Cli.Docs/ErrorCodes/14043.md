# 14043: Required configuration parameter is missing

[All error codes](../ErrorCodes.md)

## What happened

The selected OAuth provider or channel requires a parameter that was not supplied with a usable value.

## Why this happens

Create requires every declared required parameter explicitly, even if a catalogue entry has a default. For example, Direct Line and Web Chat require a site name. OAuth requirements depend on the live provider schema, so examples for another provider may omit values your selected provider needs.

## How to fix it

Read the option or parameter named in the error. For OAuth, inspect `msagent deployment oauth list-providers --provider-name <provider-name>` and supply common settings through their dedicated options.

For channels, inspect the selected channel's help and provide the required `--parameters Key=Value` assignment. Do not supply masked secret placeholders as real credentials or include secrets in support reports.

Retry after the required values are available; this validation does not complete the requested write.

## How to avoid it

Validate required fields against the actual provider or channel definition before creating or updating settings.
