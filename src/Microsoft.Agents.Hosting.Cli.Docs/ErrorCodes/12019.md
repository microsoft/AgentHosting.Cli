# 12019: This operation requires a user principal

[All error codes](../ErrorCodes.md)

## What happened

A user-specific operation received an application profile. It stopped before performing that user
operation. This is exit 2, with error kind `user-principal-required`.

## Why this happens

Workload authentication does not create a delegated user identity. Some product operations require
a signed-in operator even when application credentials can authenticate to PPAPI.

## How to fix it

Confirm that the intended operation is authorized for a user. Use `msagent auth list` and explicitly
`auth select --name <name>` or `--index <position>` for that approved user profile; if absent, create
it interactively. Do not silently switch identities in automation or claim workload support for a
user-only operation.

## How to avoid it

Match the operation's principal requirements to the selected profile before starting mutations.
Profile creation alone is not proof of downstream product authorization.
