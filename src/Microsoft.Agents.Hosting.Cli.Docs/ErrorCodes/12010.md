# 12010: The operating-system broker could not sign in

[All error codes](../ErrorCodes.md)

## What happened

The operating-system authentication broker could not complete sign-in or did not hold the requested account.

## Why this happens

The broker can be unavailable or return an authentication failure. The message includes the broker's reported reason and may include an error code or correlation ID.

## How to fix it

For accounts allowed to use a non-broker flow, run `msagent auth login --device-code` and follow the displayed instructions. If the CLI already offers device-code fallback, complete that flow instead of starting competing sign-ins.

If your organization's policy requires broker authentication, resolve the broker issue with your device or identity administrator instead. An available fallback does not override organizational policy.

## How to avoid it

Keep operating-system work-account integration healthy. In environments without a usable broker, choose a supported sign-in flow appropriate to your account's policies.
