# 11040: Agent creation endpoint is not usable

[All error codes](../ErrorCodes.md)

## What happened

The configured Agent Management Service Data Plane endpoint override failed validation, so the create request could not use it.

## Why this happens

`AH_CLI_AMSDP_ENDPOINT` must be an absolute HTTPS address without embedded user credentials. A relative address, another URI scheme, or credentials in the URI is rejected to protect the delegated authorization token.

## How to fix it

Check the variable named in the error. If an override is intentional, obtain the correct endpoint from the deployment administrator and set an absolute HTTPS address without embedded credentials.

If you do not need a direct Data Plane override, remove the unintended override so creation uses the selected environment's normal API endpoint.

Do not switch to HTTP or put sign-in credentials into the address.

## How to avoid it

Keep endpoint overrides limited to deployments that require them, and verify inherited environment variables when changing environments or shells.
