# 19069: The agent's AMS record changed during the delete

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent delete` with AMS mode on was refused because the agent's record in the Agent Management Service changed between msagent's read and its delete. AMS kept the agent, and nothing was removed from `.config`.

## Why this happens

msagent deletes the AMS record only while it is still the one it read, so that a concurrent change, such as a deploy that just finished, isn't lost silently.

## How to fix it

Run the same command again.

## How to avoid it

Delete an agent while no deploy or capture is running for it.
