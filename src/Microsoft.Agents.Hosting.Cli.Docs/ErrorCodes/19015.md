# 19015: Playground installation permission failure

[All error codes](../ErrorCodes.md)

## What happened

npm could not install the global playground package because of access permissions.

## Why this happens

The configured global npm prefix or package files are not writable by the current user.

## How to fix it

Use a user-owned npm prefix or correct the specific directory permissions, then retry. Do not change the selected CLI account or cloud to fix a local filesystem issue.

## How to avoid it

Use a writable, user-owned global npm prefix.
