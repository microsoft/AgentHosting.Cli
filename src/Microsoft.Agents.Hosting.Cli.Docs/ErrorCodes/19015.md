# 19015: The agent source is too large

[All error codes](../ErrorCodes.md)

## What happened

A capture, or a remote deploy to Dev that first captured Dev's edits, made a commit larger than the agent's repository accepts, so nothing was committed.

## Why this happens

GRS limits the size of a commit, and the commit with Dev's edits exceeds it, for example because the edits add large knowledge files.

## How to fix it

Remove large or unneeded files from the agent and its collection folders, then run the command again.

## How to avoid it

Keep build output and large assets out of agent and collection folders.
