# 11005: Selected agent is not a standalone workflow

[All error codes](../ErrorCodes.md)

## What happened

The command requires an `MCSWorkflow` record, but the selected record has another type.

## Why this happens

A standalone workflow command was aimed at a regular Copilot Studio agent or another agent type. An agent containing workflow components is not automatically a standalone workflow record.

## How to fix it

Use `msagent agent show` to identify the intended record, then select a record registered or created with `--agent-type MCSWorkflow`.

If the workflow files exist but are not registered, register the workflow through `msagent agent init --agent-type MCSWorkflow` with the appropriate source selection.

Do not relabel an unrelated record in configuration; its files and workflow identity must actually match.

## How to avoid it

Use clear names for standalone workflows and select their record IDs explicitly when multiple agent types share a project.
