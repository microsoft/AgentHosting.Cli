# 14002: Target agent is read-only

[All error codes](../ErrorCodes.md)

## What happened

The deployment stopped before pushing content because the target Copilot Studio agent belongs to a managed solution.

## Why this happens

The CLI checks both an agent already connected to the workspace and an existing agent found under the intended schema name. If that agent is managed, this deployment path cannot write to it. This is not a missing permission that `--overwrite` can bypass.

## How to fix it

Verify the environment and schema name reported in the error. Select a deployment targeting an environment where this agent is not installed from a managed solution. Run `msagent deployment list` to inspect the project's recorded targets.

If your organization distributes this agent as a managed solution, coordinate changes through that solution's release process instead of replacing the installed agent with a workspace push.

## How to avoid it

Keep editable development targets separate from managed-solution installations. Confirm the destination before promoting workspace content.
