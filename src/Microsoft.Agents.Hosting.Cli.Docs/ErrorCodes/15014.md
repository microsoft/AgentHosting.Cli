# 15014: Built archive exceeds the package limit

[All error codes](../ErrorCodes.md)

## What happened

The local package builder determined that the archive would exceed its size limit, or detected an oversized archive after writing it.

## Why this happens

The version-zero limit is 128 MiB (134217728 bytes), including the generated envelope and ZIP metadata. Entries are stored without compression, so a large source tree produces a correspondingly large archive. The limit is not based only on compressed file sizes from another ZIP tool.

## How to fix it

Review the source tree for unnecessary build output, caches, or vendored content and move unneeded material outside the package source. Keep required runtime files, then rebuild.

The builder uses fixed exclusions; it does not read `.gitignore`. Adding an ignore pattern alone will not solve the size problem. There is no supported upload flag to raise the deployed request bound.

## How to avoid it

Keep packaging input focused on deliverable content and check the finished archive's total size before attempting upload.
