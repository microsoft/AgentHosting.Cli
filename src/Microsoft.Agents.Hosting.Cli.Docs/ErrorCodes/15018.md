# 15018: Package source could not be read

[All error codes](../ErrorCodes.md)

## What happened

The local package builder could not enumerate a source directory or open a source file.

## Why this happens

Access restrictions, unavailable storage, an incompatible file lock, or files disappearing during the build can interrupt source collection or reading. The error names the affected source path; it does not mean an upload reached the service.

## How to fix it

Check that the named directory or file still exists and is readable by the account running packaging. Restore required files from their intended source, wait for concurrent writers to finish, and resolve storage availability or access problems.

Rerun the packaging step against a stable working copy. Keep the intended source intact rather than deleting unreadable files simply to make the error disappear.

Package building and upload are separate: `msagent agent package upload` requires an already completed artifact.

## How to avoid it

Avoid editing or regenerating source while packaging, and use reliable storage with narrowly scoped read access.
