# 11042: Agent creation timed out

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service create request timed out before a complete response was available. The create outcome may be unknown.

## Why this happens

The service or network took longer than the request allowed. AMS may already have received the request and reserved or created the agent even though the CLI could not report success.

## How to fix it

Preserve the exact idempotency key printed in the remediation and the client request ID.

Retry the same create request with that key through `--idempotency-key`, keeping the same creation options and target environment. Quote or escape the value correctly for your shell. The key lets AMS resume its durable reservation instead of creating a separate agent.

If timeouts persist, use the correlation information with the service administrator. Do not switch to a new key just to get past the timeout.

## How to avoid it

Use a stable network and retain create-attempt keys whenever the result is uncertain.
