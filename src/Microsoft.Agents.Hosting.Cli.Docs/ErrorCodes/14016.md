# 14016: Agent Hosting service endpoint is unusable

[All error codes](../ErrorCodes.md)

## What happened

An AMS endpoint override failed validation, so the CLI did not send the service request.

## Why this happens

`AH_CLI_AMSDP_ENDPOINT` (data plane) and `AH_CLI_AMS_ENDPOINT` (control plane) are test-only overrides that point AMS calls at a direct service endpoint instead of the Power Platform API. When set, each must be an absolute HTTPS URL with a host and no embedded username or password, query, or fragment. A relative address, HTTP URL, malformed URL, embedded user information, query, or fragment is rejected. The error names the affected variable without echoing its value.

## How to fix it

Correct the named variable to the deployed data-plane or control-plane URL, or unset it to use the Power Platform API, then repeat the original command.

Do not remove HTTPS protection, put credentials into the URL, or substitute an unrelated reachable host. The CLI will attach a delegated token to these service requests.

These AMS routes require `AmsFeatures`; use the command's `--help` to check availability.

## How to avoid it

Set these variables only while testing against a specific AMS deployment, and clear them afterwards.
