# 14016: Agent Hosting service endpoint is unusable

[All error codes](../ErrorCodes.md)

## What happened

The configured AMS endpoint failed validation, so the CLI did not send the service request.

## Why this happens

`AH_CLI_AMSDP_ENDPOINT` and `AH_CLI_AMS_ENDPOINT`, when needed by the operation, must be absolute HTTPS URLs with a host and no embedded username or password. A relative address, HTTP URL, malformed URL, or embedded user information is rejected. The error names the affected setting.

## How to fix it

Ask your service administrator for the correct deployed data-plane or control-plane URL. Correct the named setting in the CLI's environment, then repeat the original command.

Do not remove HTTPS protection, put credentials into the URL, or substitute an unrelated reachable host. The CLI will attach a delegated token to these service requests.

These AMS routes require `AmsFeatures`; use the command's `--help` to check availability.

## How to avoid it

Keep approved endpoint configuration with your environment setup and validate it when switching service deployments.
