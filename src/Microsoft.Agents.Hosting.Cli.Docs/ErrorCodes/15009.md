# 15009: Package upload response is invalid

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not validate the service's package upload response as the expected terminal operation result.

## Why this happens

A successful response must include valid operation and agent identities, digest, positive size, timestamps, status, and a Package Revision for success. Malformed JSON, missing fields, incompatible status, or inconsistent dates can cause rejection. A failure response identifying a different agent is also rejected.

## How to fix it

Do not treat the package as uploaded or deploy a revision taken from the invalid response. Preserve correlation IDs and ask the service owner to inspect the operation and confirm that the target implements the v1 terminal Package Upload Operation contract.

Check authoritative package state before another upload; the original bytes may already have been stored. Repeating a request will not repair a consistently incompatible response contract.

## How to avoid it

Use compatible CLI and service deployments, and require a verified terminal result before beginning deployment.
