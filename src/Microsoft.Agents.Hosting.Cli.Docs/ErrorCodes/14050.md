# 14050: Agent created but not recorded before push

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy` created the Copilot Studio agent, or connected the workspace to an existing one, but could not update the agent's record in the project configuration. Connecting the agent may already have provisioned the custom connectors, connection references, workflows, and AI prompts the workspace declares, but the deploy stopped before pushing the agent's components.

## Why this happens

A deploy that creates or connects its target agent records it in `agent.config.json` before it pushes the agent's components. A local write failure or a concurrent change to the configuration can interrupt that step. The cloud agent exists, but the project does not record it yet and the deployment is not marked as deployed.

## How to fix it

- Keep the agent ID, environment, and deployment name from the error.
- Resolve the reported configuration problem, such as an unwritable file or another command writing the project.
- Run `msagent agent deploy` again for the same deployment. It records the agent and pushes its content.

There is no need to delete the cloud agent or create a new deployment.

## How to avoid it

Keep the project configuration writable, and avoid running other commands against the same project during a deploy.
