# 18012: Only some conversations were stored

[All error codes](../ErrorCodes.md)

## What happened

The service acknowledged fewer conversations than the CLI sent. The message states whether partial additions remain or were removed and the previous set restored.

## Why this happens

Conversation writes can be partially accepted. During replacement, recovery depends on whether old conversations had to be removed first to stay within the service limit.

## How to fix it

Run `msagent agent eval testset show --testset <name-or-id>` with the same destination selectors. Compare actual contents with the source.

If partial additions remain, send only missing content or intentionally replace the reviewed set; blindly resending everything can duplicate conversations. If the message confirms restoration, verify the set and retry after resolving the failure.

Do not evaluate until the stored set is correct. A run is charged for whatever conversations it finds, not for the input you hoped to store.

## How to avoid it

Check stored counts and content after every write, and retain source conversations for reconciliation.
