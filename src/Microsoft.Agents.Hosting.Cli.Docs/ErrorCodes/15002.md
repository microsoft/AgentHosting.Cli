# 15002: Package publication endpoint is unusable

[All error codes](../ErrorCodes.md)

## What happened

The publication endpoint was rejected as a destination for a credential-bearing request.

## Why this happens

The package publication path requires a usable, approved service endpoint. The error detail explains which endpoint condition failed. A reachable website or agent messaging URL is not necessarily an Agent Management Service upload endpoint.

## How to fix it

Ask the service owner to verify the configured publication endpoint and correct the reported issue. Do not weaken transport protections, put credentials in URLs, or substitute an address from an untrusted response.

Retry the original operation only after its target is confirmed. Changing package contents does not resolve endpoint validation.

In the current workflow, package bytes are sent by `msagent agent package upload`, which requires `AmsFeatures`; deployment commands select an already uploaded revision rather than accepting those bytes.

## How to avoid it

Use centrally approved service configuration and review it when switching environments. Do not guess credential destinations from similar-looking URLs.
