# 99004: Request timed out

[All error codes](../ErrorCodes.md)

## What happened

The operation timed out before the target returned a response. This is different from
explicitly cancelling the command.

## Why this happens

The target may be slow or temporarily unavailable, or a network connection may have
prevented the response from reaching the CLI before its timeout. A timeout does not prove
that the service rejected the request.

## How to fix it

Check connectivity to the target and any relevant service-health information.

Before retrying an operation that can create, update, or delete resources, inspect the
target and the local project. The original request may have completed even though the CLI
did not receive its response. Do not create a duplicate resource or repeat a destructive
action simply because the command timed out.

If the intended change has not completed and retrying is safe, retry the operation. If
timeouts persist, report the affected command and target context without credentials.

## How to avoid it

Use a stable network connection and avoid repeatedly submitting changes while a service
is degraded. In automation, inspect uncertain results before retrying mutating operations.
