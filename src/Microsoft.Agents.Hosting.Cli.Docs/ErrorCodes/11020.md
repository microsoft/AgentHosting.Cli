# 11020: Role does not apply to organization-wide sharing

[All error codes](../ErrorCodes.md)

## What happened

The request supplied `--role` without a user to whom that role applies.

## Why this happens

Organization-wide sharing grants use access to everyone in the organization. It does not accept a role and cannot use this option to grant organization-wide edit access.

## How to fix it

For organization-wide access alone, remove `--role` and use the supported organization-sharing option.

For an individual grant, supply `--user` with the intended sign-in address or Entra object ID, then choose the appropriate `use` or `edit` role.

Check the scope before retrying: dropping the role should not accidentally broaden an intended individual grant into organization-wide access.

## How to avoid it

Keep per-user role assignments distinct from organization-wide use sharing. Review both the recipient selector and role when constructing a request.
