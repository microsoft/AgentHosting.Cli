# 17018: Publishing was not confirmed before the wait expired

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not confirm that the named agent finished publishing within the allowed wait.

## Why this happens

Publishing is asynchronous. The service may still be processing, or the published state may not yet reflect completion. A timeout does not prove the publish was rejected or canceled.

## How to fix it

Check the agent and its publishing state in Copilot Studio. If publishing is still underway, wait for that operation rather than submitting competing publishes or redeploying the agent.

Review any service-reported validation failures and correct them if publishing actually failed. If you need to adjust waiting behavior, use only options documented by the affected command's help.

## How to avoid it

Allow adequate time for publishing and verify completion before testing the published experience. Keep deployment success distinct from publish success when designing automated release checks.
