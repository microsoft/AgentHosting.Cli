# 17018: Copilot Studio did not finish publishing within the wait

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --publish` asked Copilot Studio to publish the agent, but Copilot Studio did not report that the publish finished within 5 minutes. The deploy was recorded before the publish was requested.

## Why this happens

Copilot Studio publishes asynchronously. The command waits for Copilot Studio to report a new finished publish, and stops waiting after 5 minutes. The publish is not cancelled: it keeps running in Copilot Studio and may still complete, or may still fail.

## How to fix it

Run the same deploy command again to confirm the publish finished. If the agent's state in Copilot Studio shows the publish still running, wait for it to finish first rather than requesting competing publishes.

## How to avoid it

Allow for publishing time in automated release steps, and treat a deploy as live only when the command reports the content published.
