# 14015: Agent Hosting service endpoint is not configured

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not begin the AMS operation because a required service endpoint is missing from its configuration.

## Why this happens

Package upload needs the Agent Management Service data plane. Package-revision deployment needs both data-plane and control-plane targets; deployment package updates need the control plane. The error identifies the missing setting: `AH_CLI_AMSDP_ENDPOINT` or `AH_CLI_AMS_ENDPOINT`.

## How to fix it

Obtain the deployed endpoint from the person responsible for your service environment and configure the named setting in the process running the CLI. Use the actual HTTPS service endpoint, not the agent's messaging endpoint or a URL copied from an untrusted message.

Retry only after confirming the configuration belongs to the intended service deployment. Endpoint resolution fails before the remote operation begins.

The AMS commands and options require `AmsFeatures`. Check the relevant command's `--help` for availability.

## How to avoid it

Set service endpoints consistently in your approved run configuration. Do not guess a destination for a request carrying your delegated credentials.
