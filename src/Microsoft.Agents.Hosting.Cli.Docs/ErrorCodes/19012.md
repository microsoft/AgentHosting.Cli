# 19012: npm probe timed out

[All error codes](../ErrorCodes.md)

## What happened

The npm prerequisite check exceeded its deadline.

## Why this happens

The discovered npm executable did not return its version in time.

## How to fix it

Check `npm --version` and resolve blocked executable access or stale wrappers. Retry from a new terminal.

## How to avoid it

Keep npm version checks independent of slow network-dependent wrappers.
