# 19012: The repository folder already belongs to another agent

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to register the agent because another AMS agent already holds the agent's folder in the repository. The message names that agent.

## Why this happens

Each agent owns one top-level folder of its repository, named after its folder in the project, and another agent of the repository already has that folder.

## How to fix it

Give the agent another name, so that its folder gets another name, then run the command again. To work on the agent that holds the folder, clone its repository and run `msagent agent init` in the clone.

## How to avoid it

Give agents that share a repository distinct names.
