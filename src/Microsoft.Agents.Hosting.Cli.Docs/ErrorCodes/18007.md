# 18007: The conversation CSV is invalid

[All error codes](../ErrorCodes.md)

## What happened

The conversation file could not be read as a valid evaluation input. The message names the file and the specific parsing or content problem.

## Why this happens

The file may be inaccessible, empty, incorrectly quoted, missing required columns, or contain invalid conversation numbers or blank questions.

## How to fix it

Start from the Copilot Studio CSV template. Include `conversationNumber` and `question` columns; `response` is optional when no expected response is supplied.

Use integer conversation numbers. Rows with the same number form one conversation, with exchanges kept in row order. Supply a nonempty question for every exchange and quote fields correctly when they contain commas, quotes, or line breaks.

Correct the indicated file problem before importing again. Keep a copy of the source file rather than editing cloud state to compensate for bad input.

## How to avoid it

Use template-compatible CSV exports and validate spreadsheet output before importing, especially after changing column names or multiline questions.
