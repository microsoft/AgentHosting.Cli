# 19018: The operation failed in Copilot Studio

[All error codes](../ErrorCodes.md)

## What happened

A remote deploy or a capture ran and failed. The message names the operation and its failure, with the detail Copilot Studio reported when there is one.

## Why this happens

The operation reached Copilot Studio, which couldn't complete it, for example because a component is invalid or a dependency is missing.

## How to fix it

Run `msagent agent operation show --agent-id <agent-id> --operation-id <operation-id>` for the full record, fix the reported problem, commit and push, then run the command again. A failure that reports `SchemaNameMissing` found no schema name for the agent: add it to the agent's settings, commit and push, then run the command again.

## How to avoid it

Deploy changes from your clone to Dev and check them there before you promote them.
