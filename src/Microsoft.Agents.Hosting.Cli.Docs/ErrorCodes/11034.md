# 11034: Incomplete sign-in left a connection behind

[All error codes](../ErrorCodes.md)

## What happened

Sign-in for a newly created connection did not complete, and automatic cleanup could not remove that connection.

## Why this happens

Connection creation can precede completion of consent or authentication. If sign-in fails or is interrupted and cleanup also fails, a half-created connection remains in the environment. The error names that connection and explains both problems.

## How to fix it

Use the exact connection-removal command printed in the remediation to delete this leftover connection before retrying creation. Verify the environment and connection ID so you remove only the incomplete connection named by the failure.

Resolve the sign-in or cleanup problem first if it would also prevent the next attempt. Then retry the original operation and complete consent.

Do not delete other connections or references as a general reset.

## How to avoid it

Complete the consent experience and keep its CLI session running. Investigate cleanup failures before starting another connection-creation attempt.
