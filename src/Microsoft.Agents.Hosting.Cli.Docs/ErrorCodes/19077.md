# 19077: The project folder can't join the AMS agent that holds the Copilot Studio agent

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` with AMS mode on cloned a Copilot Studio agent or flow that another AMS agent already holds, which joins that agent, but the project folder can't join it: the folder is a clone of another repository, the agents its `.config` holds are in another repository, `--repository-id` names another repository, or the folder is a clone of the holder's repository that lacks the holder's folder. The message names the holder, its repository and its folder. Nothing was changed.

## Why this happens

A join makes the project folder a clone of the holder's repository, and a project's agents share one GRS repository. A clone that hasn't pulled the commit that added the holder's folder has no folder to restore the holder in.

## How to fix it

In a clone of the holder's repository that lacks its folder, run `git pull`, then the same command again. Otherwise, run the same command with `--project` set to an empty folder, without `--repository-id`.

## How to avoid it

Clone an agent that AMS already holds into an empty folder, or into an up-to-date clone of its repository.
