# 14036: Deployment bot resource identifier is invalid

[All error codes](../ErrorCodes.md)

> [!IMPORTANT]
> **CodeAgent: future state - do not use.** CodeAgent recovery below is retained
> implementation reference, not supported public-preview provisioning guidance.
> Do not provision or enable the route to follow those examples.

## What happened

The CLI could not obtain a valid Azure Bot Service resource ID for the selected deployment.

## Why this happens

Deployment operations parse the bot resource ID to locate its subscription, resource group, and bot name. A missing, malformed, or incorrect resource ID in deployment metadata cannot safely identify the bot to read or change.

## How to fix it

Verify the selected deployment and project first. Preserve the configuration before investigating damaged metadata; do not replace the ID with one copied from an unrelated bot.

The supported recovery is to rerun `msagent deployment create` with the intended CodeAgent and deployment inputs to provision or adopt the backing bot, then retry. If the existing damaged record prevents create itself from resolving the resource, restore a known-good project configuration or seek support instead of guessing an ID.

CodeAgent provisioning requires `AzureBotServiceFeatures`.

## How to avoid it

Keep deployment metadata under normal project management and avoid hand-editing Azure resource identifiers.
