# 13012: Live-test input is invalid

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not resolve a live-test destination from the supplied input. Destination validation happens before authentication, network access, or configuration writes.

## Why this happens

A selector may be blank, an identifier may contain path or traversal characters, the tenant may not be a GUID, or `--agent-harness` may have an unsupported value.

## How to fix it

Correct the specific input named in the error. Omit optional selectors rather than supplying empty values. Use actual environment and schema identifiers, not URLs, and a tenant GUID for `--tenant`.

The supported `--agent-harness` values are `standard` and `github-copilot`. Keep all selectors consistent with the intended agent and deployment.

## How to avoid it

Validate script variables before invoking live tests. Use identifiers from your project and environment inventory rather than constructing them from display text or endpoint URLs.
