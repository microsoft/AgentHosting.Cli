# 14014: Deployment destination must be selected

[All error codes](../ErrorCodes.md)

## What happened

Deployment records exist, but the MCS deploy command was not given a destination selector.

## Why this happens

`msagent agent deploy` requires `--deployment-id` or `--deployment-name`. It does not infer a destination from the active environment, even if one deployment appears obvious. This protects you from pushing to an unintended environment.

## How to fix it

Run `msagent deployment list` in the intended project. Check the owning agent and environment, then pass the selected ID:

```text
msagent agent deploy --deployment-id <deployment-id>
```

Alternatively, use `--deployment-name <name>` with an agent selector when needed. Keep any original `--project`, `--publish`, or other intentional options.

Do not create another record just because the destination was omitted. The records listed in the error may already include the destination you need.

## How to avoid it

Make deployment selection explicit in scripts and release instructions. Use IDs when names are repeated across agents.
