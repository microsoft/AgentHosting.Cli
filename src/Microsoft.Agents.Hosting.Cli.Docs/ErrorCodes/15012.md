# 15012: Service rejected package publication

[All error codes](../ErrorCodes.md)

## What happened

AMS returned a classified rejection for the package publication request. The accompanying error kind explains the actionable category.

## Why this happens

Recognized causes include missing user identity, a tenant mismatch, package publication disabled on the target deployment, no upload binding for the agent, and an invalid request body. A body rejection may mean excessive size or an incompatible media-type or request contract.

## How to fix it

Follow the specific message:

- Sign in with `msagent auth create` for the intended account and cloud when identity is missing.
- Correct the selected environment or signed-in tenant for a tenant mismatch.
- Ask the service owner to enable publication if the route reports it disabled.
- Select an existing repository-bound CodeAgent if no upload binding exists.
- Reduce an oversized package below the 128 MiB limit.

For a media-type or contract mismatch, have the service deployment corrected before retrying. Changing deployment revision cannot repair an upload contract.

## How to avoid it

Check service enablement, agent binding, tenant selection, and artifact size before uploading.
