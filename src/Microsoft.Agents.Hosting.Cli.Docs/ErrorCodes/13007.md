# 13007: The target rejected authentication

[All error codes](../ErrorCodes.md)

## What happened

The target API returned HTTP 401 because authentication was missing, invalid, or expired.

## Why this happens

A previously acquired token may no longer be accepted, even when a local account profile still exists. This classification is used for direct-target requests such as Azure Resource Manager or Microsoft Graph.

## How to fix it

Run `msagent auth create` with the intended account and cloud, check `msagent auth status`, and retry after confirming the destination.

If the operation had several steps, inspect any resources already created or changed before repeating it. A rejected request does not undo earlier successful requests.

If fresh authentication still fails, include the target API, status, service error code, and time in a support report. Do not include tokens.

## How to avoid it

Refresh expired or revoked sessions before unattended work and keep account, tenant, and destination aligned.
