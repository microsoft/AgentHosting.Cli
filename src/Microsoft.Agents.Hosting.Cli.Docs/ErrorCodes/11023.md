# 11023: Sharing target is missing from the deployment environment

[All error codes](../ErrorCodes.md)

## What happened

The managed agent could not be found in the environment selected for sharing.

## Why this happens

Sharing uses the most recently deployed environment when available, otherwise the agent's home environment. The local record may exist even though the expected Copilot Studio agent was deleted or never reached that target successfully.

## How to fix it

Run `msagent deployment list` to review where the agent has been deployed and confirm the environment named in the error.

If the agent should exist there, run `msagent agent deploy` with the correct deployment selection before sharing it. Verify the target rather than deploying to an unintended environment just to satisfy the lookup.

Do not assume switching an unrelated environment setting changes the deployment history used by sharing.

## How to avoid it

Confirm successful deployment and the current cloud agent before managing its access. Keep deployment records aligned with intended targets.
