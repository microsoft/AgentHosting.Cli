# 13010: Administrator consent is required

[All error codes](../ErrorCodes.md)

## What happened

The target API returned HTTP 403 with a consent-related error for the requested scope.

## Why this happens

The CLI application's required API permission has not received the necessary tenant administrator consent. A user's resource role and an application's delegated permission are separate requirements.

## How to fix it

Ask a tenant administrator to review the target API and required scope named in the error and grant appropriate consent to the CLI application. Then refresh authentication with `msagent auth login` as needed and retry.

Do not grant broad permissions just to suppress the error; use the permission required for your intended task. Repeated unattended sign-ins cannot approve administrator-restricted consent.

## How to avoid it

Review application permissions and tenant consent during setup, before starting automated or multi-step cloud operations. Recheck consent after application-registration or tenant-policy changes.
