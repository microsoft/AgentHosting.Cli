# 17016: The agent did not become ready in time

[All error codes](../ErrorCodes.md)

## What happened

Readiness polling reached its maximum wait while the named agent was still not ready.

## Why this happens

Cloud initialization or another service-side operation may still be progressing, or the agent may have a problem that prevents readiness. A polling timeout alone does not distinguish those cases.

## How to fix it

Inspect the agent in Copilot Studio using the ID in the error. Check whether processing is still active or whether there is an actionable service diagnostic.

Wait for ongoing processing instead of recreating the agent. If the affected command supports a longer maximum wait, consult its help before changing that setting. Correct any reported readiness issue before starting dependent operations.

## How to avoid it

Allow cloud setup to finish before chaining operations that require readiness. Base automation on observed state, not a fixed assumption that creation and readiness happen simultaneously.
