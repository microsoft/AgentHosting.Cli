# 12012: The access token cannot be read

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not read the Power Platform API token's claims, so it could not check whether the token belongs to the intended target.

## Why this happens

The token is empty, is not a compact signed JWT, has an unreadable payload, or is encrypted in a format this client cannot inspect. This check does not mean you should inspect or repair the token yourself.

## How to fix it

Inspect `msagent auth who` and the intended method/target. Restore the configured credential or
explicitly recreate the same intended profile with `auth create`, including its intended cloud.
Do not clear unrelated tool caches or supply/export raw tokens.

If a fresh session has the same problem, report the error and CLI version to support. Never include a token, token fragment, or token-cache file in a report.

## How to avoid it

Use supported authentication flows and a current compatible CLI build. Do not replace cached credentials with manually supplied token material.
