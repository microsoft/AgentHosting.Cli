# 15011: Package publication response identifies another target

[All error codes](../ErrorCodes.md)

## What happened

The publication response contains an identity that does not match the requested target.

## Why this happens

The CLI must establish that the returned package operation belongs to the intended agent. An identity disagreement can indicate incorrect service routing, mismatched agent configuration, or an incompatible response. It is not safe to accept a response simply because the upload request received success.

## How to fix it

Do not treat the package as published or use the returned revision for deployment. Verify the selected agent and home environment, and ask the service owner to inspect routing and the authoritative upload operation.

Retain the requested and returned identifiers and any correlation IDs. Reconcile existing package state before retrying; an upload may already have been persisted, even though the response cannot be trusted for the intended target.

## How to avoid it

Keep agent IDs and environment configuration together, and verify response identity before promoting a package into a deployment.
