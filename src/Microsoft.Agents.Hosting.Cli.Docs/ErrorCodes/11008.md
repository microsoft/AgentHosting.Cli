# 11008: Workflow source contains multiple workflows

[All error codes](../ErrorCodes.md)

## What happened

The selected directory contains more than one workflow, so the CLI cannot choose one for this record.

## Why this happens

Standalone workflow registration expects one workflow per record. A source containing several workflow folders leaves the intended identity ambiguous.

## How to fix it

Use `--mcs-workflow-source` to select a source root containing only the intended workflow beneath its `workflows` folder. Preserve the required workflow definition and metadata together.

If you need several workflows registered, prepare distinct sources and register each separately. There is no need to delete the original multi-workflow project; use separate copies or appropriately scoped source directories while preserving all existing content.

## How to avoid it

Keep standalone workflow sources unambiguous and give each registered workflow a clear record name and workspace location.
