# 14020: Selected agent cannot accept package deployment

[All error codes](../ErrorCodes.md)

## What happened

The AMS agent read succeeded, but the agent does not meet the requirements for package upload or package-revision deployment.

## Why this happens

The selected agent must be a `CodeAgent` with repository binding status `Bound`, a non-empty valid repository ID, and a declared language and language version. An MCS agent, an incomplete repository binding, or missing runtime metadata is not compatible.

## How to fix it

Confirm that the selected agent ID and home environment identify your intended CodeAgent. If repository provisioning is still in progress, check its state with the service owner and wait for a successful binding. Resolve failed provisioning or missing language metadata before retrying.

Do not create replacement deployments or re-upload the archive to repair agent metadata. This check runs before the upload or deployment creation request.

## How to avoid it

Complete CodeAgent provisioning and repository binding before using the `AmsFeatures`-gated upload and deployment routes. Use the MCS deployment route for Copilot Studio workspaces.
