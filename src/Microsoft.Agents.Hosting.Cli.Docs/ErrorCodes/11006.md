# 11006: Workflow record has no usable workflow ID

[All error codes](../ErrorCodes.md)

## What happened

The selected standalone workflow record does not contain a usable Dataverse workflow identifier.

## Why this happens

The workflow ID may be missing, invalid, or empty. The CLI cannot address the remote workflow safely without it, even when the managed-agent record itself has an ID.

## How to fix it

Preserve the project configuration and local workflow files. Verify which workflow the record is meant to represent, then re-register the workflow using `msagent agent init --agent-type MCSWorkflow` and the correct source.

If an existing registration blocks this, review its records and the supported deletion behavior before replacing it. Do not guess a workflow ID or copy one from another workflow.

## How to avoid it

Register workflows through the CLI using complete source files, including their metadata. Preserve the workflow's identity when restoring configuration from source control.
