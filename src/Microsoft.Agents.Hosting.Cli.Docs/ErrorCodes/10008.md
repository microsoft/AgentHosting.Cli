# 10008: No existing project to register

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent init` could not find an existing Copilot Studio project in the directory it inspected.

## Why this happens

Initialization registers existing project content; it does not scaffold a new agent. The selected directory may be empty, point at the wrong level of the folder tree, or contain an incomplete copy without its project files.

## How to fix it

- Point initialization at the project that already contains your agent's files.
- Restore missing project content from source control if the checkout is incomplete.
- If you intended to start a new project, use `msagent agent create` in an appropriate empty destination instead.

Creating an empty `agent.config.json` does not supply the missing Copilot Studio project.

## How to avoid it

Use creation for new agents and initialization for existing workspaces. Verify the source directory before registering it.
