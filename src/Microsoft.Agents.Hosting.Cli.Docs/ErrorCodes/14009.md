# 14009: Cloud deployment succeeded but local recording failed

[All error codes](../ErrorCodes.md)

## What happened

Content was pushed to the cloud, but the CLI failed while updating the local deployment or agent records. The command's failure does not mean the cloud is unchanged.

## Why this happens

After a push, the CLI records deployment time and agent information in the project configuration. A local write failure or concurrent change can interrupt this step. Some record updates may already have succeeded. A requested MCS publish has not yet run at this point.

## How to fix it

Keep the cloud agent ID, environment, and deployment name from the error. Resolve the reported configuration-write problem, such as an unwritable file or another command writing the project.

Repeat the same `msagent agent deploy` command against the same deployment. The push is idempotent for content the service already holds. Do not create a new deployment or delete the cloud agent to repair a local record.

## How to avoid it

Keep project configuration writable and avoid simultaneous deployment commands against the same project.
