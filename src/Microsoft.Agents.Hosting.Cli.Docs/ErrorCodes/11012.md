# 11012: Workflow connections must be bound first

[All error codes](../ErrorCodes.md)

## What happened

The workflow already exists in the target environment, but the environment refused its update because a named connection reference has no usable connection.

## Why this happens

An existing workflow depends on connection references that must be bound before the service will accept changes. Having a reference declaration is not enough; it needs an appropriate working connection in that environment.

## How to fix it

Run `msagent deployment connection update` for the intended deployment and bind the connection reference named in the error. Complete sign-in or consent if a new connection is required.

Then deploy again. Do not delete the existing workflow or declare duplicate references to bypass the dependency.

If several references are involved, inspect the deployment's connection listing and resolve the remaining unready bindings.

## How to avoid it

Prepare and verify target-environment connections before updating existing workflows, especially after moving an agent to another environment.
