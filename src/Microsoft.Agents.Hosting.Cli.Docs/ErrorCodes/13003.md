# 13003: No environment is selected

[All error codes](../ErrorCodes.md)

## What happened

The command requires a Power Platform environment, but no active environment is available for it.

## Why this happens

An environment has not been selected in this execution context, or the command was run without a supported explicit destination.

## How to fix it

Run `msagent env list` to see environments available to the signed-in account. Then run `msagent env select <environment-id>` using the intended environment's ID and repeat the original command.

Check that the environment is the one you actually want to change, not simply the first available result. If the list is empty or missing your environment, verify authentication and access rather than choosing an unrelated destination.

## How to avoid it

Select and verify environment context when setting up a workstation or script. Do not assume a selection from another user, machine, or tool carries over to this CLI.
