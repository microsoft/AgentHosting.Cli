# 11046: Agent creation returned an invalid success response

[All error codes](../ErrorCodes.md)

## What happened

The service reported HTTP success, but its response did not provide a usable agent-create result.

## Why this happens

The response must contain nonempty agent ID, tenant ID, environment ID, display name, and repository ID values. Invalid JSON, wrong value types, or missing fields prevent the CLI from confirming creation.

## How to fix it

Do not treat the agent as successfully created. Ask the deployment administrator to verify that the target implements the expected agent-create response contract and that routing reaches the intended service.

Preserve any idempotency key and correlation information in the error. Investigate the service's recorded state before retrying blindly. When retrying this same create attempt, keep its exact key through `--idempotency-key`; do not mint another agent to work around the response problem.

## How to avoid it

Use compatible CLI and service deployments. Verify service routing and response compatibility when introducing endpoint overrides or upgrading infrastructure.
