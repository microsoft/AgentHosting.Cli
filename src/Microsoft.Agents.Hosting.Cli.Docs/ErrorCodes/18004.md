# 18004: The evaluation run was not found

[All error codes](../ErrorCodes.md)

## What happened

The requested evaluation run ID does not resolve in the selected agent and environment.

## Why this happens

The ID may be wrong, belong to another destination, or identify a run that has been deleted. A run can also disappear while it is being watched.

## How to fix it

Run `msagent agent eval list` using the original agent and environment selectors. Compare the listed run IDs and inspect the intended run with `msagent agent eval show --run-id <run-id>`.

If the run is missing, check destination context and whether another user deleted it. Do not start another evaluation merely because lookup failed; the original may exist elsewhere and new runs can incur charges.

## How to avoid it

Retain the run ID and destination from start output. Coordinate run cleanup, and use IDs rather than display names when inspecting or canceling evaluations.
