# 19070: The service refused a value msagent sent

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused a request because a value msagent sent is missing or not valid. The message quotes the service's detail, which names the value and why it was refused.

## Why this happens

AMS validates what msagent sends, such as the agent folder when msagent registers an agent, against the limits of AMS.

## How to fix it

Correct the value the service detail names, then run the command again.

## How to avoid it

Keep agent folder names portable: no Windows device name, such as `CON` or `NUL`, and no control character.
