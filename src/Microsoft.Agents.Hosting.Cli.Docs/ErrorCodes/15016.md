# 15016: Package source contains a link

[All error codes](../ErrorCodes.md)

## What happened

The local package builder found a linked source entry and refused to follow it.

## Why this happens

Symbolic links and reparse points, including linked directories, can resolve differently across machines or bring in content outside the source tree. The builder rejects them so the same source produces the same package bytes. Link checks occur before normal exclusion checks, so a linked entry is not safe merely because its name usually looks excluded.

## How to fix it

Inspect the path named in the error. If its contents belong in the package, replace the link with an appropriate real file or directory inside the source, after verifying what it contains. Otherwise, move the link outside the package source.

Do not blindly copy the entire target: it may contain unrelated files or sensitive material.

## How to avoid it

Use ordinary files in packaging input and check linked dependency or workspace layouts before building an archive.
