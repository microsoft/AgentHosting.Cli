# 19001: Unsupported playground invocation

[All error codes](../ErrorCodes.md)

## What happened

The playground rejected an unsupported mode or option combination before starting.

## Why this happens

Playground rejects `--json`. Direct Line also rejects target selectors, non-interactive mode, and redirected input/output.

## How to fix it

Remove unsupported options. Run `msagent test playground --help` and use an interactive terminal for `--target directline`.

## How to avoid it

Use the documented transport-specific options; playground does not support all `test ask` output modes.
