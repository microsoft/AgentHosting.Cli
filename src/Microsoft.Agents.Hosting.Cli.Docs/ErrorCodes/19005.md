# 19005: Node.js version could not be validated

[All error codes](../ErrorCodes.md)

## What happened

The Node.js probe did not return a usable version.

## Why this happens

The discovered executable returned malformed version output.

## How to fix it

Verify `node --version` in a new terminal. Correct PATH to a genuine Node.js installation and retry.

## How to avoid it

Avoid conflicting executable names and stale wrappers on PATH.
