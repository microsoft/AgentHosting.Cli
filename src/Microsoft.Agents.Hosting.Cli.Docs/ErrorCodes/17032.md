# 17032: A required connection reference is absent from the destination

[All error codes](../ErrorCodes.md)

## What happened

The component push names a connection reference that the destination does not hold, even after its baseline was reread.

## Why this happens

An action or workflow may still use a reference that was never declared, was removed, or could not be created in this environment.

## How to fix it

Run `msagent deployment connection list` to inspect the deployment's declared references. Declare the missing reference using `msagent deployment connection add` with the correct connector and selectors, or remove the component that should no longer use it. Bind it if required, then deploy again.

Read any earlier refusal warnings. The component push did not complete and left the agent definition unchanged, but earlier auxiliary-resource operations may already have succeeded; there is no whole-command rollback guarantee.

## How to avoid it

Keep component usages and connection declarations synchronized. Validate required references in each destination rather than assuming another environment's connection setup is available.
