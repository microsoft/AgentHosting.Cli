# 10005: Registered workspace is missing

[All error codes](../ErrorCodes.md)

## What happened

The selected agent's recorded workspace location does not resolve to the required local project or workflow files.

## Why this happens

The workspace may have been moved, omitted from a checkout, or deleted while its managed-agent record remained. The recorded location is interpreted relative to the owning project, so using the wrong project root can produce the same symptom.

## How to fix it

1. Check the agent ID, project root, and workspace location printed in the error.
2. Restore the workspace at its recorded location from source control or your backup.
3. If the record is intentionally obsolete, use `msagent agent delete` only after reviewing the selected agent and the command's deletion behavior. Do not delete a valid cloud agent simply to repair missing local files.

## How to avoid it

Move and restore workspace content together with its project configuration. Include workflow files and agent project files in your checkout.
