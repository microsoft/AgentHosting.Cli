# 99003: Operation not implemented

[All error codes](../ErrorCodes.md)

## What happened

The CLI recognized the requested operation, but this build does not implement the behavior
needed to perform it.

## Why this happens

Some command surfaces can exist before their underlying implementation is available.
The error message identifies the operation that reached an unimplemented boundary.
Recognizing a command or displaying its help does not guarantee that every operation is
implemented in the installed build.

## How to fix it

Check whether a newer supported CLI build implements the named operation. Upgrade if
appropriate, then consult that build's help and release information before trying again.

If the operation is still unavailable, use a documented supported workflow or contact
support to confirm availability. Changing credentials or repeatedly retrying the same
build will not implement the missing behavior.

## How to avoid it

Confirm that the required operation is supported by the CLI build used in your workflow,
especially before depending on it in automation.
