# 10020: Workspace is already connected

[All error codes](../ErrorCodes.md)

## What happened

The operation tried to connect a workspace that already has a cloud-agent binding, but retargeting was not permitted for this attempt.

## Why this happens

The workspace is already attached to an agent. Connecting it again without an allowed retargeting path could change which cloud agent receives future writes.

## How to fix it

Deploy to the deployment this workspace is already bound to if that is your intended target.

If you intentionally need another environment, use a deployment in that environment through the normal deployment workflow. Preserve local edits and verify the environment before rebinding.

Do not remove or hand-edit hidden connection state simply to bypass this check. A separate working copy can help keep different targets clear.

## How to avoid it

Review the workspace's current target and deployment records before connecting or deploying it elsewhere.
