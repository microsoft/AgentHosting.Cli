# 17020: The quarantine operation lacks administrative permission

[All error codes](../ErrorCodes.md)

## What happened

The quarantine API rejected the operation with HTTP 403.

## Why this happens

Quarantine is an administrative operation. A tenant or Power Platform administrator directory role is necessary but not sufficient: the signed-in token must also contain the administrative permission required by the endpoint.

## How to fix it

Verify the intended account and agent. Ask the tenant administrator to check both the operator's role and the CLI application's registration, required API permission, and consent.

Refresh authentication after the authorized permission change and inspect the agent's current governance state before retrying. Do not change app permissions broadly or switch identities merely to bypass a quarantine policy.

## How to avoid it

Provision the specific administrative access required for governance tasks before running them. Test administrative readiness separately from ordinary agent authoring, since successful authoring does not prove quarantine permission.
