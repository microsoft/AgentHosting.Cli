# 11045: Agent creation response could not be decoded

[All error codes](../ErrorCodes.md)

## What happened

AMS answered the create request, but the CLI could not decode the response content. Creation may already have taken place.

## Why this happens

The response could not be read as text using its content information. This is different from a validly read response that lacks required fields. A service or intermediary may have returned response metadata or content the client cannot decode.

## How to fix it

Preserve the exact idempotency key and client request ID shown in the error. Have the service or deployment administrator investigate recurring response problems using those identifiers.

If retrying, repeat the same create request and environment with the original key through `--idempotency-key`. Quote or escape the key for your shell.

Do not assume the unreadable response means no agent exists, and do not start a new create attempt with a different key as a recovery shortcut.

## How to avoid it

Use the supported service route and retain correlation information and recovery keys for uncertain results.
