# 14001: Deployment cloud agent deletion failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not delete the Copilot Studio agent targeted by a deployment. It kept that deployment record so you can recover.

## Why this happens

You requested `deployment delete` with `--delete-deployed-mcs-agent`, and deleting the cloud agent failed. The accompanying message identifies the environment, cloud agent, and underlying problem. An already-absent agent is handled separately and does not cause this error.

## How to fix it

Check the named agent in Copilot Studio and resolve the reported access, connectivity, or service problem before retrying the same deletion. If several deployments were selected, earlier deletions may already have completed; inspect `msagent deployment list` first.

If your intention is only to forget the local deployment record, omit `--delete-deployed-mcs-agent`. This leaves the cloud agent in place; it does not finish the cloud deletion.

## How to avoid it

Review the deletion confirmation, including each target environment and cloud agent. Use a narrowly selected deployment and verify your permissions before requesting cloud deletion.
