# 15008: Recorded upload operation did not confirm success

[All error codes](../ErrorCodes.md)

## What happened

AMS returned a durably recorded package upload operation, but did not confirm a successful Package Revision.

## Why this happens

The service response identifies an operation with status such as `Accepted` or `Failed`, rather than terminal success. The CLI preserves the operation ID and status as partial results. An accepted operation is not a completed upload you can safely deploy.

## How to fix it

Keep the operation ID, status, and client and service request IDs. Ask the service owner to inspect that specific operation and its package persistence state.

Do not immediately submit the archive again: a recorded operation may need investigation or may still account for the request. Decide whether another upload is needed only after reconciling that state.

Proceed to deployment only with a confirmed successful Package Revision for the intended agent and bytes.

## How to avoid it

Treat the durable operation result, not merely request acceptance, as the upload checkpoint in your release process.
