# 10015: Configuration is busy

[All error codes](../ErrorCodes.md)

## What happened

The command could not acquire the write lock for the project's agent configuration within its waiting period.

## Why this happens

Another CLI process is writing the same configuration. The lock prevents overlapping registry updates from silently losing agent or deployment records.

## How to fix it

Wait for the other command using this project to finish, then rerun this command. Check your running terminals and automation for overlapping work.

If the other command appears stuck, investigate that specific process rather than deleting configuration files or trying to remove a supposed lock file. This lock is not repaired by clearing project data.

Review preceding output if this command performed remote work before needing the configuration update.

## How to avoid it

Run configuration-changing operations sequentially for one working copy. Give concurrent automation separate project copies when appropriate.
