# 19058: Linking the repository would overwrite local files

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent create` or `msagent agent init` with AMS mode on was refused while it linked the project folder to an existing GRS repository, because checking out the repository's `main` would overwrite what the folder holds: files that exist in both, or the folder's own git history, which is unrelated to the repository's. The message names them. Nothing was overwritten.

## Why this happens

Linking a folder to a repository that already has commits checks out its `main` into the folder, keeping the folder's other files.

A repository that `msagent agent create` or `msagent agent init` has just created is linked the same way, because GRS starts it with a `README.md`. There, the same check is a warning rather than this error, because AMS already holds the agent: msagent takes the link back, commits nothing, and the warning names the git commands that finish the link once the files are moved.

## How to fix it

Move the files the message names out of the folder, or use an empty folder, which msagent fills with a clone of the repository.

## How to avoid it

Start work on an existing repository from an empty folder.
