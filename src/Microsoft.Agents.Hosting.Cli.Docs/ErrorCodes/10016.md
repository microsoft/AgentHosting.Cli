# 10016: Copilot Studio workspace not found

[All error codes](../ErrorCodes.md)

## What happened

No Copilot Studio workspace was found at or above the directory used by the command.

## Why this happens

The working directory or supplied project path may be outside the workspace. You may also have agent records or source files without a downloaded, usable Copilot Studio workspace.

## How to fix it

Run the command from the intended workspace directory, or correct the project path.

If the cloud agent's content has not been downloaded, use `msagent agent pull` with the appropriate agent selection to bring it into a suitable destination. Use an empty directory for a fresh download and preserve any local edits in the current location.

Do not create hidden workspace files manually to make discovery succeed.

## How to avoid it

Keep track of the workspace root separately from other repository folders. Use explicit paths in scripts that operate outside that directory.
