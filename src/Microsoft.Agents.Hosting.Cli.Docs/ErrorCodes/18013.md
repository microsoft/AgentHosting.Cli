# 18013: Another writer changed the test set during replacement

[All error codes](../ErrorCodes.md)

## What happened

Unexpected conversations appeared while the CLI was replacing a test set. It stopped rather than deleting another writer's additions.

## Why this happens

Replacement involves several service operations, not one transaction. Another user or process changed the set between the initial read and the post-write check.

## How to fix it

Pause competing writers and inspect `msagent agent eval testset show --testset <name-or-id>`.

If no space had to be freed first, previous conversations were kept. If the error reports removals made to stay within the 20-conversation limit, those conversations were not put back. New additions may also be present.

Preserve or export the current contents, reconcile them with the intended source, then deliberately replace the set again. Do not run an evaluation until that reconciliation is complete.

## How to avoid it

Serialize updates to each test set and retain source CSV. Coordinate replacements rather than relying on concurrent writers to merge conversations automatically.
