# 16007: Azure Policy denied provisioning

[All error codes](../ErrorCodes.md)

## What happened

An Azure Policy restriction prevented the requested provisioning operation.

## Why this happens

Organizational policy can limit resource types, locations, SKUs, or resource configuration. ABS preview reports Azure Policy as unknown because there is no read-only simulation of its single resource write. Passing other preflight checks does not establish policy compliance.

## How to fix it

Use the reported policy information and target resource coordinates to ask your Azure administrator which requirement was not satisfied. Adjust the request to approved settings, or follow your organization's policy-exception process.

Review the revised request before applying it. Do not disable policy, move to an unauthorized subscription, or repeatedly change resource names to bypass governance.

If the failure happened during apply, inspect Azure state before assuming every earlier action was undone.

## How to avoid it

Confirm approved regions, SKUs, and resource settings with the subscription owner before provisioning. Treat policy review as separate from sign-in and RBAC permissions.
