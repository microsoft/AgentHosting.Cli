# 19063: A Prod deploy takes no --commit-id

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote --commit-id <commit>` to a Prod deployment was refused, so nothing was deployed.

## Why this happens

A Prod deployment always takes the commit its Test deployment deployed last, so it accepts no other commit.

## How to fix it

Drop `--commit-id`. To put another commit in Prod, deploy it to Test first.

## How to avoid it

Promote to Prod only what Test runs.
