# 19065: The commit is not in the repository

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote` was refused because the commit it named isn't in the agent's GRS repository, or doesn't hold the agent's folder. Nothing was deployed.

## Why this happens

A remote deploy reads the agent's folder at the commit from GRS, and a commit you made in your clone reaches GRS only when you push it. In a clone, msagent resolves a short `--commit-id` with git; outside one, or when git can't resolve it, msagent sends the value as given.

## How to fix it

Push the commit with `git push`, or pass another `--commit-id`, such as one that `git log origin/main` shows.

## How to avoid it

Push before you deploy remotely.
