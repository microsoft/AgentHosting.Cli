# 14005: Deployment selection is ambiguous

[All error codes](../ErrorCodes.md)

## What happened

The CLI found more than one deployment that could be meant and refused to choose a target for you.

## Why this happens

A deployment name may be reused by different agents in one project. Selection without sufficient agent context can therefore match several records. Some operations also require an explicit selection when an agent has multiple deployments.

## How to fix it

Run `msagent deployment list` to inspect the records and their owners. Repeat the original command with the intended `--deployment-id <id>`. If you prefer selecting by name, also identify the owner with `--agent-id <id>` or, on MCS routes, `--agent-name <name>`.

Do not rename or remove deployments merely to make a selection unique. Use the ID when the existing names accurately describe your environments.

## How to avoid it

Carry deployment IDs into automation rather than relying on a shared name. Include the project and agent explicitly when several agents share a workspace.
