# 12009: This corporate account requires broker sign-in

[All error codes](../ErrorCodes.md)

## What happened

A browser-based sign-in returned a Microsoft corporate account that must authenticate through the operating-system broker.

## Why this happens

This check applies to browser-interactive results for users in the Microsoft corporate tenant whose sign-in name ends in `@microsoft.com`. Broker and device-code flows are exempt from this particular check; separate organizational sign-in policies still apply.

## How to fix it

Use a platform with the supported operating-system broker, such as Windows WAM, and run `msagent auth create` for the intended cloud through that broker. Resolve any broker problems with your device or identity administrator.

Switching to another browser or repeatedly trying a browser-only flow does not satisfy this policy. Do not substitute another identity merely to bypass the requirement for the corporate account you intend to use.

## How to avoid it

Use a broker-capable, correctly configured corporate device for this account, and verify that the sign-in flow actually uses the broker before starting cloud work.
