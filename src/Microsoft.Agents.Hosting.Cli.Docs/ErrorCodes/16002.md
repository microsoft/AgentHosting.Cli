# 16002: Required provisioning context is missing

[All error codes](../ErrorCodes.md)

## What happened

Provisioning could not resolve a required argument, Azure resource, application, or permission definition.

## Why this happens

ABS commands require explicit tenant, subscription, resource group, location, bot name, endpoint, and application ID. CodeAgent deployment creation can also find no accessible subscription or resource group. Identity provisioning uses this code when a selected application, resource service principal, or requested permission is unavailable in the target tenant.

## How to fix it

Follow the specific missing item in the message. Supply missing ABS arguments; for deployment creation, verify `--subscription` and `--resource-group` and the signed-in account's access.

For identity creation, verify the target tenant and application ID. Ask the tenant administrator to provision or enable a missing resource service principal or investigate its permission catalogue. Do not omit an application selector casually: doing so may create a new application.

Identity failures may include partial provisioning progress. Inspect existing resources before retrying.

## How to avoid it

Validate context and tenant prerequisites before provisioning, and retain identifiers for resources already created.
