# 17002: The environment has no Dataverse organization URL

[All error codes](../ErrorCodes.md)

## What happened

The selected environment does not provide a linked Dataverse organization URL required by Copilot Studio operations.

## Why this happens

Saved environment information may be incomplete, or the environment genuinely has no Dataverse organization. Selecting an environment does not create Dataverse for it.

## How to fix it

Run `msagent env select <environment-id>` again to refresh the environment information.

If the URL is still missing, ask the environment administrator to confirm that this is the correct environment and that it has the necessary Dataverse organization. Use an appropriately provisioned environment for the task. Do not invent an organization URL or copy one from another environment.

## How to avoid it

Confirm Dataverse availability when choosing an environment for Copilot Studio work. Refresh selection after environment provisioning or changes instead of relying on older saved information.
