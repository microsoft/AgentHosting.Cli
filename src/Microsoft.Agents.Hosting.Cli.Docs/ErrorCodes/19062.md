# 19062: AMS doesn't know the agent

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote`, `msagent agent capture` or `msagent agent operation show` was refused because the agent's record in `.config` has no AMS registration, so the Agent Management Service doesn't know the agent. Nothing was sent.

## Why this happens

An agent created or initialized while AMS mode was off isn't registered in AMS. A local deploy of such an agent runs as it does without AMS, with a warning that names `msagent agent init`.

## How to fix it

Run `msagent agent init` in the project folder the message names, to register the agent, then run the command again.

## How to avoid it

Enable `AmsMcsAgents`, which turns AMS mode on, before you create agents you want to deploy through AMS.
