# 12007: Sign-in or consent needs interaction

[All error codes](../ErrorCodes.md)

## What happened

A cached session exists, but the CLI cannot acquire the required token silently. The current operation cannot open the interaction needed to continue.

## Why this happens

A refresh token may have expired, a session may have been revoked, or a new permission or Conditional Access requirement needs consent or sign-in. Some resource-specific operations deliberately require silent authentication.

## How to fix it

Run `msagent auth login` interactively, then retry. If the error specifically requests resource consent, rerun the operation interactively so that the required consent can be requested. Ask your tenant administrator for help when consent is restricted by policy.

Follow the resource-specific remediation printed with the error; repeated non-interactive retries cannot satisfy an interactive requirement.

## How to avoid it

Refresh sign-in and obtain required permissions before unattended work. Do not assume an existing account profile guarantees every resource token can be renewed silently.
