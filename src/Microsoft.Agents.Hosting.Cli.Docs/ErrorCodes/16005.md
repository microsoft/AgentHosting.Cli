# 16005: Azure Bot Service provider is not registered

[All error codes](../ErrorCodes.md)

## What happened

ABS apply refused to change Azure because the subscription's `Microsoft.BotService` provider-registration preflight failed.

## Why this happens

Azure Bot Service resource operations require that resource provider to be registered for the target subscription. The ABS plan checks registration before its confirmed write. A failed registration check blocks apply even if the other supplied settings are valid.

## How to fix it

Verify the subscription in the plan. Ask an authorized subscription administrator to register `Microsoft.BotService` through the Azure portal, or complete an existing registration. Wait until registration is complete.

Rerun `msagent abs preview` with the same intended inputs and confirm the provider check passes before applying. The `abs` group requires `AzureBotServiceFeatures`; apply without `--force` only previews.

Do not switch to an unrelated subscription merely because its provider is already registered.

## How to avoid it

Include provider registration in subscription preparation and verify it before planning bot resources.
