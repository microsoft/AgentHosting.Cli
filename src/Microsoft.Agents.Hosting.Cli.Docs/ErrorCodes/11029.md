# 11029: Connection reference is not declared

[All error codes](../ErrorCodes.md)

## What happened

The workspace has no connection-reference declaration matching the logical name supplied to the command.

## Why this happens

The name may be incomplete or misspelled, belong to another workspace, or identify a reference that has already been removed. A connector name and a connection-reference logical name are not interchangeable.

## How to fix it

Use the full declared logical name suggested in the error, if it is the intended reference. Otherwise run the connection-list command printed in the remediation, or `msagent deployment connection list` with the same deployment selection.

Check the project and deployment before retrying. If the reference was already intentionally removed, do not create it again just to satisfy a removal request.

## How to avoid it

Copy logical names from the workspace's current connection listing rather than abbreviating them or inferring them from connector names.
