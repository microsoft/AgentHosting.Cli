# 15015: Package contains too many entries

[All error codes](../ErrorCodes.md)

## What happened

The package source would create more archive entries than the local builder allows.

## Why this happens

Version zero allows 10000 entries in total, including the generated root envelope. That leaves room for at most 9999 source-file entries. Large vendored trees, generated output, or caches can exhaust this limit even if the total bytes are small.

## How to fix it

Review the package source and move unnecessary generated or vendored files outside it. Preserve all files actually needed by the agent, then rerun packaging.

The builder uses a fixed exclusion list and does not consult `.gitignore`. Ignoring a directory in Git alone will not exclude it from this package. Reducing individual file sizes also will not solve an entry-count failure.

The current package upload command sends a completed archive rather than rebuilding the source for you.

## How to avoid it

Keep dependencies and generated artifacts out of packaging input unless they are genuinely required deliverables.
