# 99001: Unexpected or unclassified error

[All error codes](../ErrorCodes.md)

## What happened

The command encountered an error that does not have a more specific error code. This is a
fallback classification, not a diagnosis of the underlying problem.

## Why this happens

An unexpected exception reached the command's error handler, or the operation reported an
error without assigning a specific code. The accompanying error message may describe a
file, network, service, or configuration problem.

## How to fix it

Read the complete error message and any remediation printed with it. Correct the specific
problem it identifies before retrying.

If the command could have created, updated, or deleted something, inspect the target and
local project first. This code does not guarantee that the operation made no changes.

If the cause is unclear or the error repeats, report the command, CLI version, error code,
and a redacted error message to the CLI support channel or issue tracker. Do not include
tokens, credentials, or private project contents.

## How to avoid it

Keep the CLI current and resolve any identified configuration or connectivity problems.
There is no single preventive action for this fallback code; repeated occurrences need
investigation of the underlying message.
