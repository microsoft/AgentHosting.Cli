# 19020: Invalid playground launch configuration

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not safely prepare the playground launch.

## Why this happens

The tool, target, client/tenant identifier, or isolated launch directory is invalid. Unexpected client-configuration setup failures also use this code.

## How to fix it

Use the printed safe guidance to repair the selected target or local installation. Specific CLI authentication/configuration errors retain their own codes.

## How to avoid it

Use supported targets and a valid tool; do not inject credentials into launch arguments or configuration.
