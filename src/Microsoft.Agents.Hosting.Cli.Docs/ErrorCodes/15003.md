# 15003: Publication package could not be read

[All error codes](../ErrorCodes.md)

## What happened

The package selected for publication could not be read from the reported local path.

## Why this happens

The file may be missing, inaccessible, locked by another process, or still being changed by the process producing it. A directory or another unsuitable source cannot be sent as a regular package file.

## How to fix it

Confirm the path and ensure the intended artifact is a readable regular file. Wait for packaging to finish and resolve storage or access failures without broadening permissions unnecessarily. Keep the file unchanged while it is being read.

Retry the upload step with the correct file after fixing local access. Do not create or update a deployment merely to recover from a local file-read failure.

The current upload command is `msagent agent package upload`, available with `AmsFeatures`; it sends an existing artifact rather than building one.

## How to avoid it

Publish completed, stable artifacts from reliable storage, not files concurrently written by another process.
