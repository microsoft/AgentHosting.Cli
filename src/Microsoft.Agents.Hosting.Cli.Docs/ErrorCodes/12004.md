# 12004: Local sign-in profiles cannot be used

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not safely read or save its local authentication profiles. It did not treat the problem as an ordinary signed-out session.

## Why this happens

The profile store may contain invalid JSON, an unsupported version, duplicate identities/names,
an invalid owned credential reference, or an active reference with no matching profile. Access,
write or optimistic revision conflicts can also cause this error. Unsafe state is not treated as signed out.

## How to fix it

Read the accompanying reason first. For an access failure, close programs holding the configuration files and restore access to the CLI configuration directory.

For corrupt metadata, `msagent auth clear` is the supported owned-state repair. It does not clear
shared PAC/Azure/broker accounts or source certificates. Ensure the required credential can be
recreated before clearing. If an operation reports committed metadata or incomplete cleanup,
inspect its safe guidance and `auth list` before another mutation. Restore storage access and retry
intended cleanup; do not assume cancellation rolled back committed metadata.

## How to avoid it

Use CLI profile commands, avoid concurrent conflicting edits, and never edit/copy protected
authentication stores between users, machines or incompatible builds.
