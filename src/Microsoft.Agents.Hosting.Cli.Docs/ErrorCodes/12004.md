# 12004: Local sign-in profiles cannot be used

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not safely read or save its local authentication profiles. It did not treat the problem as an ordinary signed-out session.

## Why this happens

The profile store may contain invalid JSON, an unsupported version, duplicate accounts, or an active-account reference with no matching profile. File access or write failures can also cause this error.

## How to fix it

Read the accompanying reason first. For an access failure, close programs holding the configuration files and restore access to the CLI configuration directory.

For corrupt or inconsistent profiles, use the supported reset operation, `msagent auth logout`, then run `msagent auth login`. This resets local sign-in state; ensure you can sign in again before doing so. If reset fails, report the error without sharing credential files.

## How to avoid it

Use CLI authentication commands to manage accounts. Do not edit or copy authentication stores between users, machines, or incompatible builds.
