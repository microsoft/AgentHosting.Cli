# 15005: Package publication redirect was rejected

[All error codes](../ErrorCodes.md)

## What happened

The publication service returned an HTTP redirect. The CLI refused to follow it with your delegated authorization header.

## Why this happens

The configured publication endpoint is redirecting rather than answering the request directly. An outdated endpoint or service routing problem may be involved. Following that redirect could send credentials to an unapproved destination.

## How to fix it

Have the service owner verify the configured Agent Management Service endpoint and supported upload routing. Do not manually replay the request with a token to the redirect target, and do not change configuration solely because a response supplies another URL.

Before repeating a publication request that was already sent, check remote package state or service correlation. A rejected redirect is not confirmation of a usable Package Revision, nor a guarantee that nothing was persisted.

## How to avoid it

Use the approved non-redirecting HTTPS upload endpoint and review proxy or front-door changes before publishing packages.
