# 19016: Playground installation registry/network failure

[All error codes](../ErrorCodes.md)

## What happened

The playground package could not be installed because registry access failed.

## Why this happens

npm reported a recognized registry, network, or certificate-related installation failure.

## How to fix it

Check npm registry and proxy/certificate configuration and registry connectivity. Resolve the failure, then retry installation.

## How to avoid it

Configure npm registry access for the terminal and account used by the CLI.
