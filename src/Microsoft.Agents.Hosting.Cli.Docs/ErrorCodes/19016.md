# 19016: The repository checks rejected the source

[All error codes](../ErrorCodes.md)

## What happened

The repository's checks rejected a commit the Agent Management Service tried to make, so nothing was committed.

## Why this happens

The content holds something the repository doesn't accept, such as a secret or an oversized file. The message names what was found when the service reports it.

## How to fix it

Remove the reported content, then run the command again. Rotate any secret that was about to be committed.

## How to avoid it

Keep secrets in connection references and secret environment variables rather than in agent files.
