# 14028: AMS request connection failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not complete the transport exchange for an AMS request (an agent or deployment read, list, or change). It did not receive a usable complete response.

## Why this happens

An HTTP transport failure can occur while connecting or receiving the response. Network, proxy, TLS, or service availability problems may be involved. The phase and client request ID help distinguish a read failure from a possibly submitted change.

## How to fix it

For a read or a list, restore connectivity to the approved service endpoint, then retry. Do not disable TLS validation to work around the failure.

For a change (create, update, deploy, or delete), follow the message's indeterminate-outcome warning. Check the current state with `msagent agent show` or `msagent deployment show`, and ask the service owner to inspect the request, before resubmitting. A lost connection is not evidence that the mutation never reached the service.

Avoid switching deployment names or uploading another package just to obtain a different result.

## How to avoid it

Use stable approved network access and retain request IDs when a mutation loses its response.
