# 14028: AMS request connection failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not complete the transport exchange for an agent read or deployment creation. It did not receive a usable complete response.

## Why this happens

An HTTP transport failure can occur while connecting or receiving the response. Network, proxy, TLS, or service availability problems may be involved. The phase and client request ID help distinguish a read failure from a possibly submitted deployment.

## How to fix it

For an agent read, restore connectivity to the approved service endpoint, then retry. Do not disable TLS validation to work around the failure.

For deployment creation, follow the message's indeterminate-outcome warning. Ask the service owner to inspect the request and current deployment state before resubmitting. A lost connection is not evidence that the mutation never reached the service.

Avoid switching deployment names or uploading another revision just to obtain a different result.

## How to avoid it

Use stable approved network access and retain request IDs when a mutation loses its response.
