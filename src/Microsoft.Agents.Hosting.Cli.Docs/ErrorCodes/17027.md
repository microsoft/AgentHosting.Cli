# 17027: The push response could not be read

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not read the service's response after its allowed attempts. It cannot determine how much of the push was stored.

## Why this happens

The service returned an unreadable or unexpected response. Losing confirmation is different from the service rejecting every change.

## How to fix it

Preserve your local content before inspecting the destination. Run `msagent agent pull` to reread what the environment actually holds, review differences, then deploy the intended remaining content.

Some or all components may already be present. Connectors, connection references, workflows, and prompts can also have been processed earlier. Do not recreate the agent or assume the command rolled back.

Coordinate with other authors before retrying because auxiliary resource and knowledge synchronization can overwrite content by design.

## How to avoid it

Use a compatible build and stable service connectivity. Verify actual cloud content after an ambiguous response rather than using blind repeated pushes as a status check.
