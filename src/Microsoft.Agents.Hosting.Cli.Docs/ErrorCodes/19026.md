# 19026: A test-only endpoint override is not usable

[All error codes](../ErrorCodes.md)

## What happened

One of the `MSAGENT_AMS_*` environment variables, or `MSAGENT_GIT_HOST`, holds a value `msagent` cannot use. The message names the variable. Nothing was sent.

## Why this happens

These variables exist only for end-to-end tests against aliased service deployments. Each endpoint must be an absolute `https` URL without embedded user information, query, or fragment, an audience variable cannot be set without its endpoint, and `MSAGENT_GIT_HOST` must be a host name alone, without a scheme, port, or path. The checks protect the delegated sign-in token.

## How to fix it

Correct the named variable, or unset it to use the Power Platform API.

## How to avoid it

Set these variables only in end-to-end test shells, and clear them afterwards.
