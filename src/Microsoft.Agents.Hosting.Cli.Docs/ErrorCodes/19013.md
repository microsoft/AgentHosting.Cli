# 19013: Playground prerequisites could not be established

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not establish a supported Node.js/npm prerequisite set.

## Why this happens

Prerequisite detection failed without a more specific known condition.

## How to fix it

Verify Node.js 22.17.1 or newer and `npm --version`. Correct PATH and open a new terminal before retrying.

## How to avoid it

Install and verify prerequisites before launching or installing playground.
