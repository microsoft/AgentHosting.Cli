# 12016: The token lacks a required permission

[All error codes](../ErrorCodes.md)

## What happened

The acquired Power Platform API token does not carry the delegated permission required for this operation.

## Why this happens

The CLI application registration may lack the permission, consent may not have been granted, or the current session predates a permission change. The error identifies the required permission.

## How to fix it

Ask the application or tenant administrator to verify that the CLI registration has the named delegated Power Platform API permission and the necessary consent. Then sign in again with `msagent auth create` for the intended cloud and retry.

Grant only the permissions needed for the intended operation. A directory role alone does not insert a missing delegated scope into an existing token, and repeatedly retrying the same cached session cannot grant consent.

## How to avoid it

Configure required delegated permissions and consent during installation. Refresh authentication after an administrator changes permissions rather than reusing an older token indefinitely.
