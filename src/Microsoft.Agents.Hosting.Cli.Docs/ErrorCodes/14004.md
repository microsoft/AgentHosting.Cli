# 14004: Deployment selector matched nothing

[All error codes](../ErrorCodes.md)

## What happened

The deployment ID or name you supplied did not match a deployment registered in the selected project and agent scope.

## Why this happens

Deployment selection uses local project records. A deployment visible in another project, or belonging to a different agent, will not match here. A misspelled name, stale ID, or incorrect working directory can produce the same result. Supplying an ID takes precedence over a name.

## How to fix it

Run `msagent deployment list` from the intended project, or specify `--project <directory>`. Choose an ID from that output and repeat the original command with `--deployment-id <id>`. Where appropriate, narrow the agent with `--agent-id` or `--agent-name`.

If no intended MCS record exists, create it with `msagent deployment create` before deploying. Creating an MCS record alone does not push cloud content.

## How to avoid it

Use deployment IDs from the current project's list, and keep the project and agent selectors consistent across commands.
