# 14033: AMS operation was rejected or unconfirmed

[All error codes](../ErrorCodes.md)

## What happened

AMS rejected an agent or deployment request, or returned an agent-read or deployment-create response that the CLI could not validate.

## Why this happens

The accompanying message distinguishes authentication, authorization, service failures, missing revisions, and update concurrency conflicts. A success HTTP status can also lead here if the response cannot describe the expected bound agent or persisted deployment.

## How to fix it

Follow the specific remediation rather than repeating every request:

- For a package revision not found, use the revision returned by `msagent agent package upload` for this same agent.
- For a concurrency conflict, review the current deployment and repeat `msagent deployment update` only if you still intend the change.
- For sign-in or access failures, correct the account, environment, or permissions first.

For invalid creation responses or an indeterminate update, inspect authoritative state using the correlation IDs before retrying. A remote change may already exist.

## How to avoid it

Use compatible service contracts, keep revisions with their owning agent, and coordinate concurrent deployment updates.
