# 11057: Unpublished workflow draft blocks the deploy

[All error codes](../ErrorCodes.md)

## What happened

The workflow has a draft version that was saved in Copilot Studio but not published, and the
environment refuses a deploy while that draft exists.

## Why this happens

Saving a workflow in Copilot Studio without publishing it leaves a draft beside the published
version. The environment does not accept an update until the draft is published or replaced.

## How to fix it

Publish the draft in Copilot Studio, then run `msagent agent pull` to get it before deploying.

If you intentionally want your local copy to replace the draft, repeat the deploy with `--overwrite`.
That option discards the draft.

## How to avoid it

Publish or discard drafts in Copilot Studio before deploying from the CLI, and pull after publishing.
