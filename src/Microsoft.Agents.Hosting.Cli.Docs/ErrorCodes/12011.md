# 12011: Sign-in was canceled

[All error codes](../ErrorCodes.md)

## What happened

The operating-system broker reported that sign-in was canceled. The CLI stopped instead of silently falling back to another flow.

## Why this happens

The sign-in dialog was dismissed or the broker returned a cancellation result. This is different from a broker failure that may permit fallback.

Caller cancellation (for example Ctrl+C) instead preserves exit **130**. If a profile operation
already committed metadata or encountered incomplete owned cleanup, its safe state guidance is
still reported; cancellation is not a rollback guarantee.

## How to fix it

When ready, run `msagent auth create` again for the intended cloud and complete the account selection and required prompts. For an account whose policies allow it, `msagent auth create --deviceCode` offers a code-based sign-in instead.

If you did not cancel deliberately, note the broker reason in the message and check whether device policy or another dialog interrupted the interaction.

## How to avoid it

Allow the sign-in interaction to finish before closing the dialog or terminal. Start authentication when you can complete any account selection, consent, and policy prompts.
