# 16009: Azure provisioning response is invalid

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not accept an Azure Bot Service response or the ARM request destination derived from configuration.

## Why this happens

Deployment adapters expect specific resource fields and safe ARM request URLs. A malformed response, missing required resource information, incompatible API response, or URL outside the configured HTTPS ARM origin can trigger this failure. The message identifies the rejected detail.

## How to fix it

Verify the deployment metadata, approved ARM endpoint, and target resource in Azure. Do not follow an unexpected URL or disable endpoint validation to make the request proceed.

For a read-only failure, retry after a transient service issue clears. If creation or an update may already have reached Azure, inspect the resource before retrying or choosing another name.

If the problem persists, report the safe error detail and CLI version so support can check the Microsoft.BotService API-version compatibility.

## How to avoid it

Keep endpoint configuration and tooling compatible with the target Azure cloud, and preserve valid deployment metadata.
