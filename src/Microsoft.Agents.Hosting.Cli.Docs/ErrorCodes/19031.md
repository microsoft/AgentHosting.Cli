# 19031: The agent has no Dev deployment yet

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent capture` was refused because the agent has no Dev deployment, so there was nothing to capture.

## Why this happens

A capture commits the edits made in the Copilot Studio agent or cloud flow of the agent's Dev deployment. `msagent agent create` and `msagent agent init` create no deployment, and deleting the Dev deployment leaves the agent without one.

## How to fix it

Run the commands the error prints: `msagent deployment create --agent-id <agent-id> --deployment-name development --deployment-type dev`, then `msagent agent deploy --agent-id <agent-id> --deployment-name development`.

## How to avoid it

Create the Dev deployment and deploy to it before you edit the agent in Copilot Studio.
