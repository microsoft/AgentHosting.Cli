# 11018: Sharing needs a user selection

[All error codes](../ErrorCodes.md)

## What happened

The sharing operation requires a user, but `--user` was not supplied.

## Why this happens

A per-user grant or revoke cannot identify whose access to change without a sign-in address or Entra object ID. Omitting the user does not mean all users.

## How to fix it

Supply `--user` with the intended person's sign-in address or Entra object ID, keeping the required agent selection.

If you only intend to change organization-wide sharing, use `--share-with-org` without a user through the supported sharing operation. Confirm that broad organization access is actually intended before doing so.

For a revoke, identify the specific user rather than treating the missing selector as a request to remove every share.

## How to avoid it

Keep user and organization-wide sharing changes explicit and separate in your scripts and access-management procedures.
