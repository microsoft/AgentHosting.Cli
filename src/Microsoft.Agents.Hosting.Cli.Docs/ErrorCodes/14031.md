# 14031: Deployment update response was lost

[All error codes](../ErrorCodes.md)

## What happened

The package-revision update was attempted, but a transport failure prevented the CLI from receiving its complete response.

## Why this happens

The initial read succeeded, and the CLI moved to the update request. A connection failure while sending or receiving does not reveal whether the service changed the deployment. The message therefore reports an indeterminate outcome.

## How to fix it

Restore network or service access, but do not blindly resubmit the update. Use the client and service request IDs, when available, to have the service owner inspect the deployment's authoritative revision and operation history.

Retry only if another update is still needed. If another operator has changed the deployment since your attempt, reconcile the intended revision before proceeding. Do not upload a new package as a response to lost deployment confirmation.

## How to avoid it

Coordinate revision changes and use reliable service connectivity. Keep request correlation information until the target deployment's resulting state is confirmed.
