# 17015: Agent attachment has an uncertain cloud outcome

[All error codes](../ErrorCodes.md)

## What happened

Agent attachment failed, and the CLI could not reread the environment to determine whether the agent now exists.

## Why this happens

The original creation or adoption failure was followed by an unsuccessful cloud-state check. The operation may have changed the environment even though it returned an error.

## How to fix it

Do not rerun creation immediately. Run `msagent agent list --environment-id <environment-id>` and look for the schema name printed in the error.

If the agent exists, inspect its identity and recover it through the supported pull or deployment workflow. If it does not exist, resolve the original cause before retrying. If inventory remains unavailable, wait or obtain administrator assistance rather than guessing.

Preserve local files while determining the outcome.

## How to avoid it

Avoid concurrent creation attempts and retain operation output. Treat interrupted creation as uncertain until destination inventory confirms whether anything was created.
