# 18014: An accepted evaluation run has no returned ID

[All error codes](../ErrorCodes.md)

## What happened

Copilot Studio accepted the run request but did not identify the run it created. The CLI cannot address that run directly from the response.

## Why this happens

The service's start response and subsequent identification did not yield a usable run ID. Missing confirmation does not mean no evaluation started.

## How to fix it

Do not immediately submit another run. A charged evaluation may already be in flight.

Run `msagent agent eval list` using the original agent and environment selectors. Inspect recent runs with the name printed in the error and compare their details. If an unexpected run is still active, stop the identified run with `msagent agent eval cancel --run-id <run-id>`.

If you cannot determine the outcome, seek support before creating duplicates.

## How to avoid it

Retain start times, names, and destination context. Treat uncertain run-start responses as requiring inventory inspection, not automatic resubmission.
