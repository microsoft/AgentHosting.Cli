# 19003: Playground tool check timed out

[All error codes](../ErrorCodes.md)

## What happened

The playground tool check exceeded its allowed time.

## Why this happens

The tool probe did not return before its deadline.

## How to fix it

Check that `agentsplayground --version` completes. Resolve blocked executable access or stale PATH entries, then retry.

## How to avoid it

Keep a working tool on PATH; a probe timeout does not prove installation is absent.
