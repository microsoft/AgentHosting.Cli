# 19003: The deployment's stage does not fit its environment

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused a deployment because its stage and its environment don't fit together, so the deployment wasn't created.

## Why this happens

With AMS mode on, `msagent deployment create` creates the deployment in AMS before it records it in `.config`, and `msagent agent init` registers the deployments `.config` holds. An agent has one Dev deployment, in its home environment, and each Test or Prod deployment targets another environment in the same tenant, cloud and geography.

## How to fix it

Create the Dev deployment in the agent's home environment, and give each Test or Prod deployment an `--environment-id` other than the home environment's, in the same tenant, cloud and geography.

## How to avoid it

Plan one environment per stage, and keep the home environment for development.
