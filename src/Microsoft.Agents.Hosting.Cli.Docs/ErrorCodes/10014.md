# 10014: Workspace ownership cannot be verified

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not verify that the cloud agent referenced by this workspace belongs to the selected managed-agent record.

## Why this happens

The local project does not provide a readable schema name. During deletion, the CLI needs that identity to check the connected cloud agent before removing it. A connection alone is not sufficient evidence of ownership.

## How to fix it

Restore the correct `schemaName` in the workspace's project file, preferably from source control, then rerun the command.

If the workspace cannot be repaired and deletion is intentional, verify the exact agent and environment in the Copilot Studio portal before deleting it there. After confirming cloud deletion, move the unreadable workspace to a backup location and retry `msagent agent delete` for the same local record from the original project. An absent workspace allows record-only cleanup; leaving the unreadable workspace in place repeats the ownership failure. Preserve the project configuration until cleanup succeeds.

Do not guess a schema name or alter hidden connection state to force deletion.

## How to avoid it

Retain valid project identity files for as long as the managed-agent record and its cloud resources exist.
