# 17011: The scaffold template is unavailable

[All error codes](../ErrorCodes.md)

## What happened

The requested scaffold template could not be found.

## Why this happens

The classic scaffold ships a single template. An unsupported template name or an incompatible template selection cannot be resolved by this build.

## How to fix it

For classic MCS agent scaffolding, omit `--init-template` or use `--init-template default`. This option applies to classic authoring; confirm that the creation command's authoring-type selection matches your intent.

Check the project directory after any interrupted creation attempt before rerunning it. Preserve existing files and inspect cloud inventory if earlier output indicated an agent was created; a template error should not lead to blindly replacing a project.

## How to avoid it

Use templates listed by the installed build's command help. Do not assume a template from another tool or authoring mode is supported by the classic scaffold.
