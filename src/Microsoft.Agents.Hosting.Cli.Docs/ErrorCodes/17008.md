# 17008: The agent schema name is already in use

[All error codes](../ErrorCodes.md)

## What happened

An agent with the requested schema name already exists in the target environment, so the requested creation could not proceed as a new agent.

## Why this happens

The name may belong to an existing project or an earlier creation attempt. Schema identity is different from a display name.

## How to fix it

List the destination's agents with `msagent agent list` and inspect the existing agent. If it is the agent you want to work on, use `msagent agent pull` with the appropriate selector rather than creating another copy.

If you truly need a separate agent, choose a distinct `--schema-name` on the creation command. Do not delete the existing agent simply to free the name without checking ownership and dependencies.

## How to avoid it

Check destination inventory before creating agents. Record the schema identity of successful or uncertain creation attempts so later retries can inspect what already exists.
