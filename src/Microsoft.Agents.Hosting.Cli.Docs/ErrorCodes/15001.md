# 15001: Package publication target is not configured

[All error codes](../ErrorCodes.md)

## What happened

Package publication could not start because the configured publication target is incomplete or missing.

## Why this happens

Publication needs a known service destination and agent. These are not interchangeable with an agent's runtime messaging endpoint. The failure's accompanying detail and remediation identify the missing configuration; repeatedly sending the same package cannot supply it.

## How to fix it

Verify the intended agent and home environment, then have the service owner correct the deployment's publication configuration. Use only an approved service endpoint: this operation carries delegated credentials and must not be redirected to an arbitrary host.

For the current package workflow, consult `msagent agent package upload --help`; it requires `AmsFeatures`. Uploading a package confirms a Package Revision. It does not create or update a running deployment.

Do not create a replacement agent just to work around absent publication configuration.

## How to avoid it

Complete service target configuration and agent provisioning before uploading artifacts. Keep package upload and deployment selection as separate release steps.
