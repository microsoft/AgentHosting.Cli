# 15017: Package source entry is not a regular file

[All error codes](../ErrorCodes.md)

## What happened

The builder encountered a source entry that it cannot package as an ordinary file or traverse as a directory.

## Why this happens

The deterministic package format expects regular source files. A special filesystem entry, such as one exposed by an unusual mount or development environment, cannot be safely treated as ordinary package content.

## How to fix it

Inspect the path reported in the error. If the entry is needed, produce an ordinary readable file containing the intended deliverable data and use that in the source tree. Otherwise, move the unsupported entry outside the package source.

Do not read special device-like entries indiscriminately or copy unrelated filesystem content. Rerun packaging only after the source has the intended regular-file layout.

## How to avoid it

Build packages from a normal source directory containing regular files and directories, rather than a tree containing special filesystem objects.
