# 17023: Components were pushed but knowledge upload failed

[All error codes](../ErrorCodes.md)

## What happened

Agent components were pushed successfully, but uploading their knowledge file content failed. This is a partial deployment, not a rollback.

## Why this happens

Knowledge bytes are uploaded after components. A file-transfer or service failure at that later stage leaves the component definitions in the cloud without the expected knowledge content.

## How to fix it

Keep the local knowledge files intact. Resolve the transport or service issue described in the error, then rerun the same deployment command to retry the upload. The supported remediation for this failure is to push again.

Inspect knowledge availability afterward before publishing or relying on the agent's answers. Do not assume the agent is complete because its component definitions are current.

Knowledge synchronization can replace content by design; coordinate with other authors before retrying from a changed workspace.

## How to avoid it

Keep knowledge sources available throughout deployment and verify upload results, not just component counts, before releasing the agent.
