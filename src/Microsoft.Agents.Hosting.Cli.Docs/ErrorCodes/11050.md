# 11050: Connection is not a candidate for this connector

[All error codes](../ErrorCodes.md)

## What happened

The connection ID you supplied is not among the candidates available for the selected connector or reference.

## Why this happens

The ID may belong to another connector or environment, be stale, or be incorrect. If there are no candidates, the connector currently has no listed connection that can satisfy this selection.

## How to fix it

Choose a connection from the candidates listed in the error, ensuring that its status is `Connected` and its account is appropriate for the agent.

If no connection exists, create one for the intended connector, complete sign-in, and retry the binding. Use the same environment and deployment selection when inspecting and updating connections.

Do not force an unrelated connection ID or declare another reference to bypass the candidate check.

## How to avoid it

Select connection IDs from the target's current catalog and verify connector, environment, status, and account before binding.
