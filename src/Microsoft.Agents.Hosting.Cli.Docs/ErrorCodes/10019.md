# 10019: Clone would overwrite existing files

[All error codes](../ErrorCodes.md)

## What happened

A clone destination contains workspace content that would be overwritten, so the operation stopped.

## Why this happens

The clone target or one of its component workspace folders already contains files. The clone permits the agent's own `.config` directory, but that exception does not make an existing source workspace safe to overwrite.

## How to fix it

Clone into a fresh destination containing no workspace content. Preserve the existing directory until you understand whether it contains unpublished edits or output from another agent.

If you need to reuse the original path, back up and deliberately relocate the conflicting files first. Do not clear the entire project or remove agent configuration indiscriminately.

Check the exact path in the error; it may identify a component folder rather than the project root.

## How to avoid it

Give each clone its own destination and avoid reusing folders from incomplete or unrelated clones without inspection.
