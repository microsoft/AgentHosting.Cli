# 11047: Created agent response does not match the request

[All error codes](../ErrorCodes.md)

## What happened

The response's tenant, environment, or display name does not match the value requested by the create operation.

## Why this happens

The service returned a result for an unexpected identity or target. Incorrect environment selection or service routing can cause such a mismatch. The error identifies the field and its requested and returned values.

## How to fix it

Do not treat the returned agent as your confirmed creation result or continue operating on it.

Verify the selected environment, tenant, and target service routing with the administrator. Preserve the idempotency key and available correlation information so the service's recorded attempt can be inspected.

Only retry after understanding the mismatch. Recovery of the same attempt must retain its original request and idempotency key; changing targets or options is a different request.

## How to avoid it

Verify environment selection and endpoint overrides before creation, particularly when switching tenants or service deployments.
