# 19056: The Copilot Studio agent or flow was not found

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to register the agent because the Copilot Studio agent or cloud flow a deployment names doesn't exist in the deployment's environment, or you can't read it.

## Why this happens

When msagent registers an agent, it sends the Copilot Studio agent or cloud flow each deployment in `.config` names. AMS checks that it exists and, for an agent, that it carries the agent's schema name. It may have been deleted in Copilot Studio, or it belongs to an environment you can't read. The record a local deploy sends to AMS fails the same way, as a warning.

## How to fix it

Check that the agent or flow exists in the deployment's environment and that you can open it in Copilot Studio, then run the command again.

## How to avoid it

Delete agents and flows of registered agents with `msagent agent delete` rather than in Copilot Studio.
