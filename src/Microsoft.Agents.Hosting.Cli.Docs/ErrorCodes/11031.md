# 11031: Reference declaration did not complete

[All error codes](../ErrorCodes.md)

## What happened

The command could not complete creation of a connection-reference declaration for the requested connector.

## Why this happens

Declaring a reference only writes it to the workspace. The environment gets the reference's record when the reference is bound or the agent is deployed, so a failed declaration leaves nothing behind in the environment. The underlying failure, usually a local-file problem, is included in the error.

## How to fix it

Run the connection-list command printed in the remediation to see what the workspace actually declares before retrying.

Resolve the reported local-file problem, then run the command again.

Do not remove unrelated references or assume all state was rolled back.

## How to avoid it

Ensure the workspace is writable before declaring references.
