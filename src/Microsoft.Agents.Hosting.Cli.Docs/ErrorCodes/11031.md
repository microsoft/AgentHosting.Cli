# 11031: Reference declaration did not complete

[All error codes](../ErrorCodes.md)

## What happened

The command could not complete creation of a connection-reference declaration for the requested connector.

## Why this happens

Reference creation happens in the environment before its declaration is saved to the workspace. A later failure can therefore leave an unused cloud reference even though the local workspace does not declare it. The underlying failure is included in the error.

## How to fix it

Run the connection-list command printed in the remediation to see what the workspace actually declares before retrying.

Resolve the reported service or local-file problem. If cloud creation may have succeeded, inspect the affected environment or involve its administrator before creating more references. Repeated blind retries can leave additional unused references.

Do not remove unrelated references or assume all state was rolled back.

## How to avoid it

Ensure the workspace is writable and target-environment access is available before declaring references. Investigate partial declaration failures before repeating creation.
