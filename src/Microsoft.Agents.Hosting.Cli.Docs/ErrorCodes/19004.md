# 19004: The preceding stage has nothing to promote

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote` to a Test or Prod deployment was refused because nothing was deployed to the stage before it, so there was no commit to promote. Nothing was deployed.

## Why this happens

Without `--commit-id`, a Test deployment takes the commit the agent's Dev deployment deployed last, and a Prod deployment always takes the commit its Test deployment deployed last. A deploy counts once it succeeded, through a remote deploy or through a local deploy of a pushed commit without local changes, and a deploy to Test once it also published. No deployment of the preceding stage has such a deploy yet.

## How to fix it

Deploy to the preceding stage first, for example with `msagent agent deploy --remote --deployment-name <preceding-deployment>`, wait for it to succeed, then run the command again. With AMS mode on, `msagent deployment list` shows each deployment's stage and the commit it deployed last.

## How to avoid it

Promote in stage order, and check that each deploy succeeded before you promote it.
