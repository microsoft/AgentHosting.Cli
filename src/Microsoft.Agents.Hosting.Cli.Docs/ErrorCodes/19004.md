# 19004: Node.js was not found

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not find a usable Node.js executable for playground.

## Why this happens

Node.js is missing, its detected executable disappeared, or PATH does not expose it.

## How to fix it

Install Node.js 22.17.1 or newer with npm. Open a new terminal, verify `node --version`, and retry.

## How to avoid it

Make the supported Node.js installation available on PATH before starting playground.
