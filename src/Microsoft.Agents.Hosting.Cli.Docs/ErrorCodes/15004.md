# 15004: Package changed after it was built

[All error codes](../ErrorCodes.md)

## What happened

The package's SHA-256 digest when read for publication differs from the digest recorded when it was built.

## Why this happens

The archive changed between building and reading. Another build, archive tool, synchronization process, or concurrent writer may have replaced or modified it. The mismatch means the intended artifact and the bytes selected for publication are not the same.

## How to fix it

Do not publish or deploy this unverified artifact. Stop overlapping writers, preserve any needed source changes, and regenerate the package from an idle working copy. Confirm which completed artifact is intended before uploading it.

Use the upload step for package bytes; do not expect `msagent agent deploy` to rebuild or upload the current working tree on the AMS package-revision route. That route selects an existing immutable revision.

## How to avoid it

Give each packaging run a stable artifact location and do not modify its archive after recording the digest. Serialize build and upload steps.
