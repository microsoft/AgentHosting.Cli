# 10009: Agent or workspace is already registered

[All error codes](../ErrorCodes.md)

## What happened

The requested registration or creation conflicts with an existing managed-agent record. The error identifies the existing name, ID, and configuration file.

## Why this happens

All discovered workspaces may already be registered, or the requested agent name may already be used in this project. Repeating initialization is not a way to update an existing record.

## How to fix it

Use `msagent agent show` to review the project's records, then use the existing record if it represents your intended agent.

For a separate agent, choose a distinct name and workspace. If registration genuinely must be replaced, review `msagent agent delete` and its cloud-deletion behavior before removing the selected record. Preserve the configuration and deployment history first.

## How to avoid it

Check existing records before initializing or cloning again. Give separate agents distinct names rather than recreating an already registered workspace.
