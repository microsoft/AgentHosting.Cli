# 11056: Deploy would discard workflow changes made in the environment

[All error codes](../ErrorCodes.md)

## What happened

The workflow changed in the environment after it was last pulled, and deploying would replace those
changes.

## Why this happens

Someone edited the workflow in the environment, for example in Copilot Studio, after your local copy
was pulled. Without an explicit overwrite decision, the CLI protects that cloud work.

## How to fix it

If the cloud changes should be kept, run `msagent agent pull` to get them, then deploy again.

If you intentionally want your local copy to replace the cloud version, repeat the deploy with
`--overwrite`. That option discards the changes made in the environment; it is not a merge.

## How to avoid it

Pull before editing locally, and coordinate cloud and local authoring of the same workflow.
