# 11007: Workflow files were not found

[All error codes](../ErrorCodes.md)

## What happened

The selected source directory does not contain a workflow that can be registered or used.

## Why this happens

A workflow is expected beneath a `workflows` folder, in a folder named for the workflow and its ID, with both `workflow.json` and `metadata.yml`. The source may point at the wrong directory level or be missing required files.

## How to fix it

Point `--mcs-workflow-source` at the directory containing the `workflows` folder, not at an unrelated project or an incomplete workflow file.

Restore missing files from source control or download the intended workflow again. Preserve any local edits before replacing content.

Do not fabricate metadata or reuse another workflow's ID to make discovery succeed.

## How to avoid it

Keep workflow definitions and metadata together, preserving their folder layout when copying, checking out, or archiving a project.
