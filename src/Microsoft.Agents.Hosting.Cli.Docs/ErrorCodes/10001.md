# 10001: Agent configuration not found

[All error codes](../ErrorCodes.md)

## What happened

The command could not find `agent.config.json` at the path shown in the error.

## Why this happens

The command needs a registered agent project. You may be running it from the wrong directory, pointing `--project` at a workspace instead of its project root, or using files whose configuration was not restored.

## How to fix it

- Run the command from the project directory that owns the configuration, or correct `--project`.
- Restore the configuration from source control if it was removed. It can contain deployment records that cannot be recovered by creating an empty file.
- For an existing, unregistered Copilot Studio project, use `msagent agent init`. To create a new project, use `msagent agent create`.

## How to avoid it

Keep the configuration with the project in source control. Use an explicit project path in scripts that can run from different working directories.
