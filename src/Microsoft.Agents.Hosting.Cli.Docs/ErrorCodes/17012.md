# 17012: A Dataverse request targeted the wrong origin

[All error codes](../ErrorCodes.md)

## What happened

A Dataverse request targeted an origin different from the one its credential is bound to. The request was blocked before sending that credential.

## Why this happens

The requested organization and the selected environment's credential audience disagree. Stale targeting or incompatible integration behavior can cause this.

## How to fix it

Verify the intended environment, then run `msagent env select <environment-id>` to refresh its context. Repeat the operation only after confirming the destination.

If the mismatch persists, report the requested and expected origins and CLI version. Do not bypass the check or manually redirect requests to the reported host: a valid HTTPS address is not sufficient evidence that it should receive your credential.

## How to avoid it

Keep environment selection current and use supported targeting commands. Do not copy organization connection details between unrelated environments or modify hidden synchronization state.
