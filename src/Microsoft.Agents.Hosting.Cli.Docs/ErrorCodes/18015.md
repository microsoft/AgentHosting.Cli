# 18015: Test-set replacement could not restore removed conversations

[All error codes](../ErrorCodes.md)

## What happened

The CLI removed conversations to make room for a replacement, the replacement failed, and recovery could not restore all removed content. The test set is incomplete.

## Why this happens

Old and new conversations together would exceed the service's 20-conversation limit. After making space, a write failed; restoration then failed, was incomplete, or lacked readable original content.

## How to fix it

Stop other writers. Run `msagent agent eval testset show --testset <name-or-id>` and compare its actual contents with your source CSV or saved copy.

Resolve the underlying failure, then resend missing conversations or deliberately replace the set with the complete intended input. Account for any new conversations that already landed to avoid duplication.

Do not evaluate the set until verified: runs are charged for what is actually stored.

## How to avoid it

Export important sets before replacement, retain original inputs, and serialize updates. Do not assume replacement is atomic or that every failure can restore the previous contents.
