# 11024: User name could not be resolved

[All error codes](../ErrorCodes.md)

## What happened

The environment could not resolve the supplied user name or sign-in address to a user account.

## Why this happens

Name-based lookup needs an account known to that environment. Sharing itself does not require such an account, so this lookup failure does not necessarily mean the person cannot receive access.

## How to fix it

Check the spelling and intended tenant. Supply the user's Entra object ID through `--user` instead of a name when the user is not known in this environment.

Obtain the ID from your directory or an administrator. If you already use Azure CLI, the error's suggested `az ad user show` lookup can retrieve it. Verify the returned identity before sharing.

Alternatively, perform the operation from an appropriate environment where the user can be resolved.

## How to avoid it

Use verified Entra object IDs for cross-environment sharing automation rather than relying on environment-local name resolution.
