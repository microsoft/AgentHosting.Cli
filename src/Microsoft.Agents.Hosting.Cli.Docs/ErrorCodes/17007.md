# 17007: The Copilot Studio agent was not found

[All error codes](../ErrorCodes.md)

## What happened

The requested agent ID or schema name did not resolve to an agent in the target environment.

## Why this happens

The selector may be incorrect, the environment may be wrong, the agent may not yet be deployed there, or the account may not be able to see it. Agent identities are environment-specific.

## How to fix it

Run `msagent agent list` using the same environment selection. Where supported, `msagent agent list --environment-id <environment-id>` inspects the explicit destination.

Correct the selector or environment. If this agent genuinely has not been deployed to the intended destination, inspect the deployment configuration before using `msagent agent deploy`. Do not deploy a duplicate merely because the original is hidden by an account or environment mismatch.

## How to avoid it

Verify agent and environment identities together. Use IDs from the destination's current inventory rather than assuming an ID from another environment will work.
