# 19051: Dev had edits the deployed commit does not hold

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent deploy --remote` to the Dev deployment of an MCS agent found edits made in Dev's Copilot Studio agent since its last deploy or capture that the requested commit doesn't hold. It saved them on `main` as a new commit and deployed nothing. The message names the requested commit and the saved one.

## Why this happens

A Dev deploy never silently replaces edits made in Copilot Studio. It first saves Dev's edits on `main`. A deploy of `main`'s newest commit then deploys the saved commit, which holds them; a deploy of an older commit stops.

## How to fix it

Run `git pull`, then deploy the saved commit or a later one, or run the command again with `--overwrite`, which replaces the edits in Dev. They stay on `main` either way.

## How to avoid it

Capture edits made in Copilot Studio with `msagent agent capture` before you deploy to Dev, and pass `--overwrite` when you mean to replace them.
