# 11028: Connection reference was not removed

[All error codes](../ErrorCodes.md)

## What happened

The command could not confirm removal of the named connection-reference declaration from the workspace.

## Why this happens

The workspace files may not be writable, or the removal operation may not have removed the declaration as expected. This code can also appear when removal fails and the CLI cannot read enough declaration state to give a more specific diagnosis.

## How to fix it

Check that the workspace declares the exact logical name and that its files are writable. Close applications holding those files and resolve the reported access or service problem.

Use `msagent deployment connection list` with the same deployment selection to inspect the current references, then retry the intended removal.

If components still use the reference, review that dependency before approving removal; do not force deletion merely to bypass a file or state problem.

## How to avoid it

Keep workspace files writable and inspect reference usages before removing declarations.
