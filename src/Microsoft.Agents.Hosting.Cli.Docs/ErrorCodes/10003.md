# 10003: Configuration version is not supported

[All error codes](../ErrorCodes.md)

## What happened

The configuration declares a schema version outside the range this CLI build can read. The error shows the declared and supported versions.

## Why this happens

A newer CLI may have written the file, or an older configuration may lack fields required by the current registry. A malformed version value can also be rejected.

## How to fix it

- If the file is newer than the supported range, upgrade to a CLI build that understands it.
- If the file is too old, restore a compatible version from source control or migrate the missing fields described in the error. In particular, each managed agent needs its correct `agentLocation`.
- Preserve deployment records while repairing or migrating the file. Do not delete it or merely change the version number to suppress the check.

## How to avoid it

Use compatible CLI versions across your team and automation. Commit configuration migrations together with the corresponding workspace layout.
