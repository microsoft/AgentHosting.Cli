# 11069: Some of the agent's resources were not deleted

[All error codes](../ErrorCodes.md)

## What happened

`msagent agent delete --all-resources` deleted the agent, but could not delete some of the flows, AI prompts, connection references, or custom connectors it uses. The error lists each resource left and why. The agent's records were kept.

## Why this happens

Dataverse refuses to delete a resource while another component still depends on it, such as a connection reference a flow uses. A permission or service failure can also stop a delete. The command tries every resource before it reports the ones it could not delete.

## How to fix it

- Resolve the reported cause, then run the same delete again. What is already gone is skipped, and the records are removed once every resource is deleted.
- To keep a resource that something else still needs, run the delete again without `--all-resources`. It removes the records and leaves the resources.

## How to avoid it

Before you confirm the delete, check each resource it lists. When something else still needs one, delete without `--all-resources`.
