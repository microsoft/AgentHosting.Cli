# 19006: Another operation is running on this deployment

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service refused to start a deploy or a capture because another operation on the same deployment is still running. Nothing was started.

## Why this happens

A deployment runs one operation at a time. An earlier `msagent agent deploy --remote` or `msagent agent capture` may have returned early with `--async`, or stopped waiting at Ctrl+C while its operation kept running, or another user started one.

## How to fix it

Wait for the other operation to finish, then run the command again. `msagent agent operation show --agent-id <agent-id> --operation-id <operation-id>` follows an operation whose id a command printed.

## How to avoid it

Wait for an operation started with `--async` before you start another on the same deployment.
