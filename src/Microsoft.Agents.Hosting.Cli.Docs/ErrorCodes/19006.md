# 19006: Node.js is below the required version

[All error codes](../ErrorCodes.md)

## What happened

The detected Node.js release is older than playground requires.

## Why this happens

The selected Node.js version is below 22.17.1.

## How to fix it

Install Node.js 22.17.1 or newer. Open a new terminal and verify which version `node --version` selects.

## How to avoid it

Keep the Node.js version used by playground at or above its minimum.
