# 19025: Playground target resolution failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not resolve the playground target safely.

## Why this happens

Target resolution failed without a more specific typed CLI error.

## How to fix it

Check project, agent, deployment, schema, environment, and tenant selectors. Use `msagent test playground --help` and correct the intended target.

## How to avoid it

Keep selectors consistent with the intended deployment; do not silently substitute another target.
