# 19029: Stopped waiting for the operation

[All error codes](../ErrorCodes.md)

## What happened

You stopped `msagent` while it waited for an operation. The operation keeps running in the Agent Management Service.

## Why this happens

Ctrl+C stops only the wait; the service finishes the operation on its own.

## How to fix it

Run the `msagent agent operation show` command the message prints to follow the operation.

## How to avoid it

Pass `--async` when you do not want to wait.
