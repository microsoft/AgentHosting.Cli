# 12003: The sign-in application is not configured

[All error codes](../ErrorCodes.md)

## What happened

The CLI stopped before constructing an interactive sign-in request because its client application ID is unusable.

## Why this happens

`AH_CLI_CLIENT_ID` is missing, empty, the all-zero placeholder, not a GUID, or identifies the forbidden PAC application instead of a dedicated application for this CLI.

The standard msagent public-client default remains `21fadfba-178a-47f0-8ce6-07c05eb346ca`.
This configuration error is distinct from malformed create tenant/application input, which is usage 99002.

## How to fix it

Ask the person managing your CLI installation or app registration for the correct public-client application ID. Set `AH_CLI_CLIENT_ID` to that GUID in the environment used to launch the CLI, then run `msagent auth create` for the intended cloud.

An application ID is not a client secret. Do not put a secret in this setting or borrow another product's application identity. Repeating the command with different agent selectors cannot repair this configuration.

## How to avoid it

Include the dedicated application registration and its required consent in your installation setup, and verify the setting before distributing scripts.
