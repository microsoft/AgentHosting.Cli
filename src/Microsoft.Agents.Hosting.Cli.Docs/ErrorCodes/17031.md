# 17031: The service refused an existing connection reference

[All error codes](../ErrorCodes.md)

## What happened

The component push could not complete because the service reported that a declared connection reference already exists, even after the baseline was reread.

## Why this happens

The requested declaration conflicts with a reference already held by the destination, or the service and synchronization state still disagree about that reference.

## How to fix it

Inspect `msagent deployment connection list` and the existing reference's connector and binding. Reuse and bind the intended reference with `msagent deployment connection update`, or deliberately rename the conflicting declaration and its usages.

Delete an existing reference only after reviewing dependencies and confirming it is unwanted. Then deploy again.

The agent definition was left as it was by the incomplete component push, but earlier connector, workflow, prompt, or reference operations may already have changed cloud state. Review earlier refusal warnings too.

## How to avoid it

Keep logical reference names unique and consistent across local declarations and the target environment. Coordinate deployments that manage shared references.
