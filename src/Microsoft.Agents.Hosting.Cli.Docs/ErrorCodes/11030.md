# 11030: Reference was declared but binding failed

[All error codes](../ErrorCodes.md)

## What happened

The connection reference was created, but a later step failed before the operation could complete its connection binding.

## Why this happens

Reading connection state, selecting or creating a connection, or saving a binding can fail after declaration succeeds. The error includes the reference name, connector, and underlying failure.

## How to fix it

Do not declare another reference: the named reference already exists.

Resolve the underlying connection, consent, permission, or service problem, then use the exact `msagent deployment connection update` command printed in the remediation to bind the existing reference.

Inspect the deployment's connection listing if you need to confirm its current state. A reference declaration alone does not establish that the dependent action or workflow is ready.

## How to avoid it

Prepare a usable connection for the intended connector and environment, and verify binding readiness after reference creation rather than assuming declaration completed the setup.
