# 11044: Agent creation connection failed

[All error codes](../ErrorCodes.md)

## What happened

The create request encountered a transport failure before the CLI obtained its result.

## Why this happens

A network, TLS, proxy, or connection problem can interrupt communication with AMS. The service may nevertheless have received the request, so the outcome can be uncertain.

## How to fix it

Preserve the exact idempotency key printed in the remediation. Resolve the reported connectivity issue, checking access to the intended service through your supported network or proxy.

Retry the same create request, with the same options and environment, using `--idempotency-key` and that exact value. Quote or escape it for your shell so the key is not changed.

Do not use a new key merely because communication failed; doing so can start a distinct creation instead of recovering the existing reservation.

## How to avoid it

Use reliable service connectivity and keep recovery keys until each creation has a confirmed result.
