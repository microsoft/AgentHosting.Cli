# 11055: Workflow name cannot be used

[All error codes](../ErrorCodes.md)

## What happened

The workflow name cannot be used, so nothing was written. The message states the rule it breaks.

## Why this happens

The name came from `--agent-name`, which also names a workflow copy made by `msagent agent copy`, or
from the workflow's `metadata.yml`. Dataverse would refuse it, or it holds no character a folder name
may use, so no workflow folder could carry it.

## How to fix it

Choose another `--agent-name`, or correct the name in the workflow's `metadata.yml`, then run the
command again.

## How to avoid it

Give workflows names made of ordinary letters and digits, and edit names in `metadata.yml` with care.
