# 19014: Playground installation was not authorized

[All error codes](../ErrorCodes.md)

## What happened

No usable playground was available and global installation was not authorized.

## Why this happens

Interactive installation was declined, or non-interactive/redirected-input use lacked explicit installation consent.

## How to fix it

If installation is intended, rerun interactively and type `install`. For unattended use, explicitly pass `--install-playground`. Installation can execute npm lifecycle scripts.

## How to avoid it

Preinstall a supported playground, or explicitly authorize installation in the intended execution mode.
