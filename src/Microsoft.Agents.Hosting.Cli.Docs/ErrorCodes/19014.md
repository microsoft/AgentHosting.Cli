# 19014: The agent source is not valid

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service rejected the agent's source at the commit it was asked to deploy. The message quotes its findings.

## Why this happens

AMS reads the agent's folder, and each collection folder it declares, at that commit from GRS, and validates them; for example, none of them may hold a `.mcs` folder.

## How to fix it

Fix the problems the message reports in the agent or collection folders, commit and push, then run the command again.

## How to avoid it

Deploy changes from your clone to Dev before you deploy them remotely, and keep `.mcs` folders out of commits.
