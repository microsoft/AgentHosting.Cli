# 17021: Connection declarations cannot be read

[All error codes](../ErrorCodes.md)

## What happened

A workspace connection-reference declaration exists but could not be read or parsed. The error names the file and reason.

## Why this happens

The declaration may be inaccessible or contain invalid YAML or unsupported content. The CLI refuses to silently omit references that agent actions may need.

## How to fix it

Preserve the file, restore access if necessary, and correct the reported declaration error using the supported authoring format. Restore a known-good version from source control if appropriate.

Use `msagent deployment connection list` to inspect the deployment's references once the workspace is readable. Remove a declaration only after confirming it is no longer required by any action or workflow; deleting it simply to silence parsing can break deployment.

## How to avoid it

Review connection declaration changes and resolve merge conflicts before deploying. Use supported connection-management commands and keep connector identities aligned with the actions that use them.
