# 15006: Package upload timed out

[All error codes](../ErrorCodes.md)

## What happened

The package upload timed out before its complete response was received. The remote upload outcome is uncertain.

## Why this happens

The timeout can occur while submitting the archive or reading the response. AMS may already have persisted the package and operation. A missing response is not evidence that the upload never arrived.

## How to fix it

Do not retry blindly. Preserve the agent ID and client request ID from the error and have the service owner inspect AMS package state and request correlation.

If a successful operation and Package Revision already exist for the intended bytes, use that verified result rather than creating another upload unnecessarily. If another upload is required, wait for service or network health to recover and use the same stable artifact.

Package upload itself does not change a running deployment; deployment is a separate action selecting a confirmed revision.

## How to avoid it

Use reliable connectivity and retain upload correlation information until the durable revision is confirmed.
