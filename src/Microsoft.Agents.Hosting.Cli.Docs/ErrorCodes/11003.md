# 11003: Agent selection is ambiguous

[All error codes](../ErrorCodes.md)

## What happened

The command found more than one possible managed agent and could not safely choose a target.

## Why this happens

No selector was supplied in a project containing several agents, or the supplied name matches multiple records. The error lists candidates.

## How to fix it

Specify `--agent-id` for the exact record you intend to use. You can use `--agent-name` when that name uniquely identifies the agent.

`msagent agent copy` has no agent selector: run it from the folder of the agent to copy, or pass that folder to `--project`.

Run `msagent agent show` to inspect local records if you need to confirm the correct ID. Keep the existing agents; deleting unrelated records is not necessary to resolve selection ambiguity.

If both ID and name are present, verify the ID carefully because it takes precedence.

## How to avoid it

Use explicit agent IDs in multi-agent automation and choose distinguishable names when registering additional agents.
