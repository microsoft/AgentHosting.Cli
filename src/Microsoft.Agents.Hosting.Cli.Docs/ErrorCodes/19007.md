# 19007: The service has no free worker right now

[All error codes](../ErrorCodes.md)

## What happened

The Agent Management Service couldn't start the operation because all its workers were busy. Nothing was started.

## Why this happens

The service limits how many operations run at once. `msagent agent deploy --remote` and `msagent agent capture` already retried up to three times, waiting as long as the service asked, at most 60 seconds each time.

## How to fix it

Wait a minute, then run the same command again. Because nothing was started, retrying is safe.

## How to avoid it

Spread large batches of deploys over time instead of starting them all at once.
