# 19007: Node.js probe failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI could not execute or complete the Node.js prerequisite probe.

## Why this happens

The executable cannot start or returned an unsuccessful probe result.

## How to fix it

Check executable access and `node --version`. Repair Node.js or its PATH entry, open a new terminal, and retry.

## How to avoid it

Use a working Node.js installation accessible to the CLI account.
