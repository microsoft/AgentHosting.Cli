# 11049: Connector is not available in the environment

[All error codes](../ErrorCodes.md)

## What happened

The target environment's connector catalog did not contain the requested connector ID.

## Why this happens

The ID may be misspelled or refer to a connector available only in another environment. The CLI checks the target catalog rather than assuming a familiar connector name is available everywhere.

## How to fix it

Use one of the suggested connector IDs if it is the intended connector. Otherwise run the connector-list command printed in the remediation, using the same environment or deployment selection.

Verify the target environment and use the connector's actual catalog ID. If it should be available but is not listed, ask the environment administrator to investigate availability.

Do not substitute an unrelated connector solely because its name is similar.

## How to avoid it

Resolve connector IDs from each target environment's catalog before creating references, connections, or removal requests.
