# 13008: The target rejected the token audience

[All error codes](../ErrorCodes.md)

## What happened

The target API returned HTTP 401 and indicated that the token was issued for the wrong resource or audience.

## Why this happens

The target configuration or authentication integration requested a token for a different API. A token for Microsoft Graph, for example, is not interchangeable with one for Azure Resource Manager.

## How to fix it

Check the target API and resource named in the message. Verify the account, cloud, and destination configuration with the person managing your CLI installation. Correct the resource configuration before retrying.

If you have no supported setting to correct, report the CLI version, target API, and service error code. Do not paste tokens into configuration or repeatedly sign in expecting the wrong resource request to change.

## How to avoid it

Keep target and authentication configuration from the same supported installation. Review resource targeting when changing clouds or upgrading custom integrations.
