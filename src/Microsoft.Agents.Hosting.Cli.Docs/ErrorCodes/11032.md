# 11032: Connection deletion was rejected

[All error codes](../ErrorCodes.md)

## What happened

The service returned an unsuccessful response when asked to delete the named connection.

## Why this happens

You may not own or have permission to delete the connection, or dependencies outside this agent may prevent removal. The error includes the environment, HTTP status, and any usable service detail.

## How to fix it

Verify the connection and environment, confirm that your account owns or can delete it, and check whether other agents or components depend on it.

Resolve the specific service problem before retrying deletion. Repoint legitimate consumers where needed rather than deleting a shared connection indiscriminately.

If a separate error says the reference was already removed, follow that error's connection-only retry guidance rather than repeating reference removal.

## How to avoid it

Review ownership and dependencies before deleting a connection. Treat connections as potentially shared resources, not as disposable workspace files.
