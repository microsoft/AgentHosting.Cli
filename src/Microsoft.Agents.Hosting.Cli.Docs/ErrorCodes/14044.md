# 14044: Channel parameter is read-only

[All error codes](../ErrorCodes.md)

## What happened

Your channel create or update supplied a parameter that the CLI marks read-only. The configuration was rejected before writing to Azure.

## Why this happens

Some returned channel properties describe service state and cannot be assigned through this command. For example, Direct Line's `isV1Enabled` is read-only. Copying every property from a show result into an update can include such fields.

## How to fix it

Remove the assignment named in the error and retry with only writable settings. Inspect the channel-specific help, for example:

```text
msagent deployment channel update --channel directline --help
```

If a service-controlled value must change, consult the channel's supported administration process rather than trying alternate spellings or another parameter format.

## How to avoid it

Treat displayed configuration as information, not as a complete reusable update payload. Build updates from writable parameters in the selected channel's schema.
