# 11070: Agent belongs to a managed solution

[All error codes](../ErrorCodes.md)

## What happened

The selected agent is part of a managed solution in its environment, so the CLI did not clone it.
Nothing was written to the project directory and nothing was registered.

## Why this happens

A managed agent changes only through the solution that installed it. A local copy could never be
deployed back to that environment, and the clone would miss the components the solution does not
let you customize.

## How to fix it

Run the command again against the environment where the agent's solution is unmanaged, usually the
development environment the solution was exported from. Pass that environment as
`--mcs-clone-environment-id` to `msagent agent create`, or as `--environment-id` to
`msagent agent copy`.

## How to avoid it

Clone agents from the environment where you author them, and move them to other environments by
deploying rather than by cloning the installed copy.
