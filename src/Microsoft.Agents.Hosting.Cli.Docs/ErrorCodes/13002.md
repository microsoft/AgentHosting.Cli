# 13002: The account cloud changed during the command

[All error codes](../ErrorCodes.md)

## What happened

The active account was retargeted to another Power Platform cloud after this process created its service clients.

## Why this happens

The process still has clients for its original cloud. Continuing would combine the new account context with the old destination.

## How to fix it

Check the intended account and cloud with `msagent auth status`, then run the command in a new invocation. A new process picks up the current cloud configuration.

If the CLI is embedded in a longer-lived host, restart or rebuild that host's clients after the cloud change. Before repeating a command that can create or delete resources, inspect any work already reported as completed; this error is not a rollback guarantee.

## How to avoid it

Finish in-flight operations before retargeting an account's cloud. Avoid changing shared authentication context while another CLI process is using it.
