# 18002: The test-set name is ambiguous

[All error codes](../ErrorCodes.md)

## What happened

More than one evaluation test set has the requested name. The CLI cannot choose which set to read, change, or run.

## Why this happens

Test-set display names are not unique. Earlier or concurrent creation can leave multiple sets with the same name.

## How to fix it

Run `msagent agent eval testset list` and compare the IDs printed in the error. Inspect the intended set using `msagent agent eval testset show --testset <test-set-id>`, then use that ID for the original operation.

If duplicates are unwanted, inspect or export their conversations before using the supported test-set delete command. Deleting a set removes its conversations, so do not delete every duplicate simply to clear the ambiguity.

## How to avoid it

Use test-set IDs in automation and descriptive names for human review. Coordinate creation rather than assuming a display name identifies exactly one resource.
