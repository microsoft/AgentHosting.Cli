# 17001: Copilot Studio needs an environment

[All error codes](../ErrorCodes.md)

## What happened

The Copilot Studio operation has no environment to target.

## Why this happens

No active environment is selected and the request did not provide an explicit environment. The CLI cannot safely guess where your agents belong.

## How to fix it

Run `msagent env list`, confirm the intended destination, then run `msagent env select <environment-id>`. Repeat the original operation.

On commands that support it, `--environment-id <environment-id>` selects the destination for that request. Check the command's help before using this option. Make sure the account has access and that the environment supports the intended Copilot Studio operation.

## How to avoid it

Set and verify environment context before starting agent work. In scripts targeting multiple environments, supply supported explicit selectors consistently rather than depending on whichever environment was last selected.
