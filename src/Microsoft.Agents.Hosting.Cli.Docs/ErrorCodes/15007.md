# 15007: Package upload transport failed

[All error codes](../ErrorCodes.md)

## What happened

The CLI lost the upload's transport exchange before receiving a usable complete response. It cannot establish whether the package was persisted.

## Why this happens

A connection can fail while the request is sent or the response body is read. Proxy, network, or service failures can interrupt confirmation after the upload has reached AMS. This is not the same as a local package-read error.

## How to fix it

Restore approved network access, but check AMS package state before uploading again. Give the service owner the client request ID and intended agent so the request can be correlated.

If a revision was already created, verify that it represents the intended artifact. If no successful upload exists and another attempt is appropriate, retry the upload step with the unchanged package.

Do not run deployment creation as a workaround for a package whose upload is unconfirmed.

## How to avoid it

Keep completed artifacts stable and retain request IDs so interrupted uploads can be reconciled without unnecessary duplicate operations.
