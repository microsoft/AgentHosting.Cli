# 12018: git could not write the credential helper

[All error codes](../ErrorCodes.md)

## What happened

`msagent auth setup-git` ran `git config --global` to write msagent's credential helper, and git failed. The message ends with git's reason when git gave one.

## Why this happens

git could not write your global git config, for example because the file is read-only, is locked by another git command, or holds content git cannot parse; or git could not start, or did not finish within 30 seconds.

## How to fix it

Fix the problem git reports, then run `msagent auth setup-git` again. The rerun replaces whatever an interrupted run wrote.

## How to avoid it

Keep your global git config writable, and do not change it from another git command while the setup runs.
