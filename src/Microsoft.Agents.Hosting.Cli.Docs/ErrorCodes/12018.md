# 12018: A required directory object ID is missing

[All error codes](../ErrorCodes.md)

## What happened

The PPAPI token lacks a usable directory object ID required to bind the product principal.
The token is rejected. This is exit 1, with error kind `principal-object-id-missing`.

Missing captured context or missing token-provider wiring does not mean a token
object ID is missing. Those internal failures use [99005](99005.md).

## Why this happens

The acquired token cannot identify the required user/service-principal object for this tenant.
An application client ID is not the directory object ID.

## How to fix it

Check `msagent auth who`, the explicit tenant/application, and authorized product principal with
your tenant administrator. Restore the approved credential/registration and recreate the intended
profile if needed. Do not invent an object ID or substitute another identity just to pass validation.

## How to avoid it

Provision and authorize the exact directory principal in the intended tenant before using it.
Report only safe IDs and CLI error metadata, never access tokens or assertions.
