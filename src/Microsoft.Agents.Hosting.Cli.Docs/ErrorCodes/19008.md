# 19008: Node.js probe timed out

[All error codes](../ErrorCodes.md)

## What happened

The Node.js prerequisite check exceeded its deadline.

## Why this happens

The discovered Node.js executable did not return its version in time.

## How to fix it

Check `node --version` and resolve blocked executable access or wrappers. Retry from a refreshed terminal.

## How to avoid it

Keep Node.js version checks fast and independent of network-dependent wrappers.
