# 17010: The operation needs explicit confirmation

[All error codes](../ErrorCodes.md)

## What happened

The requested destructive operation was not confirmed.

## Why this happens

The operation requires an explicit acknowledgment before it can proceed. This prevents an accidental invocation from immediately performing a destructive change.

## How to fix it

Read the operation named in the message and verify its agent, environment, and affected content. Inspect current state and preserve anything you need before continuing.

If you intend that exact action, follow the printed remediation and use the affected command's supported `--force` confirmation option. Check its help before adding options; confirmation does not correct a wrong target or make deletion reversible.

## How to avoid it

Build an explicit review step into destructive workflows. In scripts, confirm the destination and preconditions before opting out of prompts, rather than adding force flags as a general response to errors.
