# 11021: Requested sharing state was not confirmed

[All error codes](../ErrorCodes.md)

## What happened

The service accepted the sharing request but returned a state different from what was requested. The grant cannot be confirmed.

## Why this happens

Sharing is saved as a whole access state. A returned difference can affect the requested recipient, organization-wide access, or other entries. Part of the request may already have taken effect; this is not a guarantee that nothing changed.

## How to fix it

Run `msagent agent share show` for the same agent before issuing another access-changing command. Compare the actual access with the differences reported in the error.

Only after reviewing that state should you retry or correct the specific access change. If the service repeatedly returns unexpected access, inspect it in Copilot Studio and involve the responsible administrator.

## How to avoid it

Avoid concurrent sharing edits. Review current access before broad changes and verify the resulting state after important grants.
