# 17022: One connection reference names different connectors

[All error codes](../ErrorCodes.md)

## What happened

The same logical connection-reference name is declared for two different connectors.

## Why this happens

Declarations can come from the classic connection-reference file and individual infrastructure connection files. When the same logical name has conflicting nonempty connector IDs, the CLI cannot safely choose one based on file order.

## How to fix it

Compare the two paths and connector IDs in the error. If both declarations describe the same intended reference, make them agree on the correct connector. If they describe different connections, assign distinct logical reference names and update the actions that use them.

Inspect existing cloud bindings before deploying the correction. Do not repoint a reference to a different connector without reviewing dependent actions.

## How to avoid it

Use one consistent connector identity per logical reference name across all declaration layouts. Review merged connection files together rather than validating each file in isolation.
