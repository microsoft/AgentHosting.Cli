# 11010: Source workflow does not exist in this environment

[All error codes](../ErrorCodes.md)

## What happened

The source environment did not contain the workflow ID requested by the operation.

## Why this happens

The workflow ID may be incorrect, belong to another environment, or identify a workflow that was deleted. A local managed-agent record ID is not necessarily the Dataverse workflow ID required for cloning or copying.

## How to fix it

Check the workflow ID with `msagent agent list --agent-type MCSWorkflow --environment-id <source-environment-id>`. Correct the selected workflow.

If the source is in another environment, name that environment: `--mcs-clone-environment-id` for `msagent agent create --mcs-clone-workflow-id`, or `--environment-id` for `msagent agent copy --mcs-clone-workflow-id`. Verify both the environment and workflow identity before retrying.

Do not create a replacement workflow merely to make an incorrect source ID resolve.

## How to avoid it

Record workflow IDs together with their source environment IDs. Refresh selections from the environment's current listing instead of reusing stale IDs.
