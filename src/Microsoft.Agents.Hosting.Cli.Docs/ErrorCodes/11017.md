# 11017: Share role is missing or invalid

[All error codes](../ErrorCodes.md)

## What happened

The user-sharing request has no valid `--role` value.

## Why this happens

The role may be omitted, misspelled, or outside the accepted values listed in the error. Sharing requires a supported access level rather than an arbitrary permission name.

## How to fix it

Use `--role use` to grant chat access or `--role edit` to grant collaborative authoring, together with the intended user selection.

Choose the least access the recipient needs. Granting edit access is not required just to let someone use the agent.

If the intent is organization-wide use access rather than a user grant, use the organization-sharing options instead; organization-wide sharing does not take a role.

## How to avoid it

Use documented role values in scripts and review whether each operation grants use or authoring access before running it.
