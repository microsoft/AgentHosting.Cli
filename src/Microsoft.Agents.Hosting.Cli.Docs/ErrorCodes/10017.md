# 10017: Copilot Studio output directory is not empty

[All error codes](../ErrorCodes.md)

## What happened

The operation requires an empty output directory, but the selected directory already contains files.

## Why this happens

An existing workspace, unrelated files, or output from an earlier attempt occupies the destination. The operation refuses to overwrite content.

## How to fix it

Choose a new, empty output directory using the output option supported by the command. If the command exposes `--output-dir`, point it at that empty directory.

Inspect the existing directory before deciding what to do with it. Move or back up valuable files if you intentionally need to reuse the same path. Do not delete an existing workspace or deployment configuration simply to satisfy the empty-directory requirement.

## How to avoid it

Use separate destinations for downloads and clones. Check for earlier output before rerunning an operation that writes a new working copy.
