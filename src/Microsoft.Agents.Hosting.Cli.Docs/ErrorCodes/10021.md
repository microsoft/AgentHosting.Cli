# 10021: Project cannot be reattached

[All error codes](../ErrorCodes.md)

## What happened

The workspace's authoring shape does not support connecting or reconnecting it to a cloud agent through this operation.

## Why this happens

The CLI checks the project's authoring capabilities before attempting reattachment. Not every Copilot Studio project shape supports that workflow. The error includes the specific reason the project was rejected.

## How to fix it

Open the project in Copilot Studio and use its supported authoring workflow, or convert the project to a supported authoring shape before retrying.

Use the reason in the message to identify the limitation. Preserve the original project and its edits before any conversion. Changing hidden connection files will not add support for the authoring shape and can make the workspace inconsistent.

## How to avoid it

Check that the project's authoring model supports CLI reattachment before planning a cross-environment or reconnect workflow.
