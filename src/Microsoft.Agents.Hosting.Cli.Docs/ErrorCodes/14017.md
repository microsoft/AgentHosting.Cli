# 14017: Package file could not be read

[All error codes](../ErrorCodes.md)

## What happened

The package upload command could not open or hash the file selected by `--package`. It has not uploaded that file.

## Why this happens

The path may be invalid or missing, access may be denied, another process may hold an incompatible lock, or an I/O failure may occur while hashing. The CLI opens the file for reading and computes its digest before reading the target agent or sending the upload.

## How to fix it

Check the reported path relative to the CLI's current directory. Confirm that it names a readable regular file, not a directory. Wait for the process producing the archive to finish, restore unavailable storage, or correct access to the intended artifact.

Then repeat `msagent agent package upload` with the original agent and the correct `--package <file>`. This command is gated by `AmsFeatures`.

## How to avoid it

Finish producing the archive before uploading and keep the file unchanged throughout the operation. Uploading bytes is separate from deploying a Package Revision.
