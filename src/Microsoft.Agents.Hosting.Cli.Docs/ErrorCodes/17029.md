# 17029: A deleted connection reference remains in the local baseline

[All error codes](../ErrorCodes.md)

## What happened

The connection-reference declaration and its cloud record were deleted, but the workspace's cached cloud baseline could not be updated.

## Why this happens

A local file access or update failure interrupted the last retirement step. The cached baseline still describes a record that no longer exists.

## How to fix it

Do not deploy from the stale state: the next deployment can recreate the deleted record.

Preserve unrelated local edits, resolve workspace access or locking problems, then run `msagent agent pull` to reread the agent from the environment. Review the pulled state and confirm the retired reference is absent before deploying again.

Do not repair hidden synchronization metadata manually or repeat cloud deletion without checking current state.

## How to avoid it

Keep the workspace writable throughout reference removal and avoid concurrent writers. After any partial removal failure, refresh the baseline before sending local content back to the cloud.
